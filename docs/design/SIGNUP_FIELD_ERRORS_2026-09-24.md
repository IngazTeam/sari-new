# أخطاء خانات إنشاء الحساب — 24 سبتمبر 2026

## النتيجة

- تظهر رسائل مستقلة أسفل الاسم، واسم النشاط، والبريد، والجوال، وكلمة المرور وتأكيدها، والموافقتين الإلزاميتين.
- يعرض الخادم البريد المستخدم والرقم المستخدم معًا عند تعارضهما، وتعود واجهة التسجيل ذات الخطوتين إلى الخانة المناسبة مع حفظ البيانات.
- تظهر الأخطاء بالعربية والإنجليزية، وترتبط بالخانات عبر `aria-describedby` و`aria-invalid`، ويُركَّز أول حقل يحتاج تصحيحًا.
- توحّدت قواعد التحقق بين واجهتي التسجيل والخادم. تُطابق أرقام الجوال المكتوبة برمز `+` أو `00` والمسافات والأقواس، والرقم السعودي المحلي.
- تبقى حماية معدل التسجيل ورسائل الدخول العامة كما كانت. أخطاء الشبكة والتشغيل تعرض رسالة على مستوى النموذج.

## تنفيذ الخادم

تُرسل رموز أخطاء محددة في `data.signupFieldErrors` لمسار `auth.signup` فقط، دون عرض رسائل SQL في الواجهة. يُفحص الرقم قبل إنشاء الحساب، ويمنع قفل MySQL الخاص بالرقم إنشاء حسابين عبر التسجيل العام بالتزامن. يبقى فهرس البريد الفريد مسؤولًا عن تعارض البريد المتزامن. لم تتغير قواعد إنشاء الحسابات عبر تكاملات provisioning.

لا يتطلب هذا التعديل ترحيل قاعدة بيانات جديدًا. عند إعادة تشغيل بيئة الاختبار كان ينقصها جدولا إشعارات الحجز من تحديثات أخرى في المشروع؛ طُبقت ملفات الترحيل الموجودة 0095–0097 على `sari_ux_test` المحلية فقط لتشغيل الخادم الحالي.

## التحقق

- **55 اختبارًا ناجحًا:** أخطاء التسجيل وسلوك الواجهة، تفاعلات الصفحات العامة، الوصول والترجمة، الموافقات والخصوصية، وعقد provisioning.
- **4 اختبارات MySQL ناجحة:** التعارض المزدوج، صيغ الأرقام المخزنة القديمة، التسجيل المتزامن بالرقم نفسه، والتسجيل المتزامن بالبريد نفسه. نُظفت الحسابات التي أنشأتها الاختبارات.
- طلبات HTTP إلى الخادم المحلي الفعلي أعادت `400` مع أخطاء البريد والرقم وكلمة المرور، و`409` مع `emailUsed` و`phoneUsed` لحساب تجريبي موجود.
- فحص المتصفح على سطح المكتب والجوال بعرض 390 بكسل: رسائل الخانات ظاهرة، دون تجاوز أفقي أو أخطاء console. أُصلح تحرك زر التسجيل نتيجة ظهور خطأ عند مغادرة الحقل أثناء الضغط عليه، ثم جُرّب نجاح الضغط من المرة الأولى.
- نجح `tsc --noEmit --incremental false`، وفحص مفاتيح الترجمة دون مفاتيح ناقصة أو أخطاء interpolation، وبناء الإنتاج مع فحص حجم الحزمة.

الخادم المحلي يعمل على `http://127.0.0.1:3017`. لم يتم رفع التعديل أو نشره أونلاين ضمن هذه المهمة.
