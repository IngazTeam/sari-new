# فحص تأهيل المحادثات من لوحة المخ — 25 سبتمبر 2026

استكمال بعد `09351a46` للبنود B045 وB062 وB063. أصبح بالإمكان اختيار آخر رسالة واردة في محادثة فعلية وفحصها وفق شروط التأهيل المثبتة، من داخل سجل خطة المقارنة دون إدخال معرفات تقنية يدويًا.

## التنفيذ

- لوحة قراءة تُفتح عند الطلب بعد تثبيت الشروط. البحث باسم العميل أو الهاتف حرفي، بحد 100 حرف، وصفحات من 10 محادثات في الواجهة وبحد خادمي 20. الترتيب حسب معرف المحادثة الأحدث، لا حسب نشاط الرسائل. المحادثة بلا رسالة واردة لا تظهر، وتبقى المغلقة أو غير المؤهلة ظاهرة لمعرفة سبب استبعادها.
- قائمة مقيّدة بالنشاط وبخطة مسجلة ما زالت نسخة المقارنة والقطاع فيها حاليين. تُقرأ آخر رسالة واردة لكل محادثة من SQL، دون الوثوق بالنص أو الهاتف أو وقت العميل. المسار الجديد `listSalesExperimentCohortSources` مقصور على صلاحية `bot_settings.manage` مثل الفحص نفسه.
- بحث SQL بقيم مربوطة ومعالجة حرفية لـ `%` و`_` و`!`. الصفحات تعتمد على حد معرف المحادثة لمنع التكرار عند وصول محادثات جديدة. لا عدّ شامل مكلف ولا تصفية مسبقة بالمؤهلين.
- المعاينة النصية حتى 320 نقطة Unicode، مع التنبيه إلى الاختصار؛ الفحص يستخدم النص المخزن كاملًا. للوسائط يُعرض النوع فقط، دون روابط أو تحميل أو تشغيل.
- لكل اختيار بصمة تربط النشاط والمحادثة واسم العميل ورقمه والرسالة ونوعها ونصها الكامل ووقتها. يرسل المستخدم البصمة مع المعرفات فقط. تغيّر المحتوى أو الهوية يمنع اعتماد معاينة قديمة؛ وصول رسالة أحدث يعطي سبب الاستبعاد المناسب. إعادة التصنيف تقرأ المرحلة والتدخل البشري والتاريخ والنافذة من الخادم.
- يحتفظ مسار الفحص القديم بالتوافق للطلبات التي تحتوي المعرفات المملوكة فقط. تضيف الواجهة دائمًا `expectedMessageDigest`. تعيد النتيجة معرفات الاختيار وبصمته حتى لا تُنسب لرسالة مختلفة.
- عرض النتيجة اللحظية ووقت الفحص وتصنيف التاريخ المسجل، وترجمة أسباب الاستبعاد الأربعة عشر. لا تعني «مؤهلة لحظة الفحص» إذن إرسال أو انضمام للتجربة؛ `assignmentCreated` و`activationAllowed` يبقيان `false`.
- الفحص لا يبدأ عند فتح القائمة أو اختيار صف؛ يحتاج زرًا صريحًا. تُمسح النتيجة عند تغيير البحث أو الصفحة أو الاختيار أو تحديث البيانات. تُتجاهل الردود المتأخرة بعد الإخفاء أو تغير المصدر أو فقد الصلاحية، وتُرفض الإيصالات المخالفة للرسالة أو العقد. حارس متزامن يمنع النقر المكرر.
- حقول 16px ومساحات تفاعل 44px، دعم لوحة المفاتيح والعربية والإنجليزية وRTL/LTR، وعرض نصوص العملاء كنص React دون تنفيذ HTML. فشل القراءة لا يُعرض كقائمة فارغة أو أهلية مؤكدة، ولا يكشف تفاصيل SQL.
