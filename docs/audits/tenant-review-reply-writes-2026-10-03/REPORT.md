# المرحلة 403 حفظ ردود التقييمات دون الكتابة فوق التغييرات

التاريخ: 2026-10-03. فحص محلي دون إرسال أو نشر.

أضيف مسار حفظ مشترك لرد تقييم الطلب أو الحجز. يفحص التيننت المختار والعضوية الحالية وصلاحية الرد وحالة حساب المالك والمستخدم، ثم يقفل التقييم ومراجعه حتى إتمام المعاملة. يتطلب نسخة التقييم التي شاهدها المحرر؛ إذا تغير التعليق أو الرد أو الرابط أثناء التحرير يُرفض الاستبدال حتى قراءة النسخة الحالية.

الحفظ يحد النص إلى 1000 حرف بعد إزالة الفراغات الطرفية ويكتب وقتًا صالحًا بتوقيت UTC. وجود النص المطلوب نفسه يعيد «موجود حاليًا» دون تغيير التوقيت، حتى لو أُعيد الطلب بعد فقد الاتصال. هذا يثبت حالة الحقل الحالية، ولا ينسبها إلى طلب أو شخص معين. عند ضياع إقرار الالتزام ترجع حالة غير مؤكدة ويُتلف الاتصال؛ يجب قراءة الرد الحالي قبل أي محاولة جديدة. تنافس ردين مختلفين على النسخة نفسها يقبل أحدهما فقط.

الحفظ عملية محلية؛ لا يستدعي واتساب ولا يعد بتسليم. لا يحتاج إلى ترحيل أو جدول إيصالات لأن إعادة العملية المتطابقة لا تنشئ حدثًا أو رسالة أخرى. الإرسال الخارجي يحتاج مسارًا مستقلًا وصريحًا بدليله، ولا يجوز إضافته كأثر جانبي لهذه العملية.

## التحقق والحدود

نجحت 51 حالة للعقود والقراءة والأخطاء والصلاحيات، و30 حالة MySQL للقراءة والكتابة والتزامن دون فشل أو تخطي. نجح فحص الأنواع وبناء العميل والخادم. تشمل الاختبارات الردود المتزامنة، وإعادة الحفظ، والنسخة القديمة، والتقييم الأجنبي، وتغير المراجع، وصلاحية المشاهد والمشرف، والحساب المعطل، وفقد إقرار الالتزام.

المداخل القديمة لم تُغلق بعد والصفحتان لم تُستبدلا بهذه المرحلة. التالي ربط التصميم الجديد بالقراءة والحفظ، وإغلاق الرد القديم الذي يحتوي خلل التاريخ ومحاولة إرسال عامة. لا تزال أتمتة طلب التقييمات القديمة وتحقق المبيعات والفحص الفعلي على Safari وiPhone ضمن العمل المتبقي.
