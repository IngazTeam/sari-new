# المرحلة424: استعادة طلب تحليل الموقع في الواجهة

يحفظ التطبيق مرجع التحليل قبل إرساله ويستعيد حالته بعد التنقل أو تحديث الصفحة في علامة التبويب نفسها. يظهر زر متابعة واضح بدل بدء تلقائي أو فتح نافذة مفاجئة، ويُعزل المرجع بالحساب والتيننت ويُمسح عند تسجيل الخروج.

## التجربة والإصلاحات

- تخزين رقم الطلب فقط في sessionStorage؛ لا نصوص أو أسماء ملفات أو نتائج أو رموز تنفيذ. فشل التخزين يمنع إرسال طلب جديد ويتيح إعادة فحصه.
- استعادة الطلب الغامض أو الجاري للقراءة فقط. إذا لم يوجد السجل، تستخدم إعادة البدء اليدوية المرجع نفسه لحماية الطلب المتأخر من التكرار.
- اعتماد مرجع المهمة الجارية الذي يعيده الخادم وحفظه قبل متابعتها. لا يُستبدل المرجع بمرجع جديد إلا بعد نتيجة نهائية معلومة وإجراء صريح.
- حالات منفصلة للتوقف، وفشل المعالجة، ونتيجة محفوظة غير قابلة للقراءة، وتعطل التخزين، وانقطاع قراءة الحالة. تحديث قراءات المعرفة عند النهاية المتعثرة أيضًا لأن أجزاء منها قد تكون حُفظت.
- تعديل النصوص العربية والإنجليزية وتوسيع الموك أب بأربع حالات، مع استعمال نافذة التطبيق وشريط متابعة الطلب الفعليين.

## التحقق

نجحت76 حالة واجهة وتخزين، بما فيها حفظ المرجع قبل الإرسال، وإعادة التحميل، وعزل الحساب والمتجر، وسحب الجلسة، ورفض الكتابة فوق مرجع تغير، وفشل التخزين، واستعادة المرجع الذي أعاده الخادم، وعدم بدء طلب عند الاستعادة. نجحت أنواع التطبيق والموك أب وبناؤهما. فحص13447 استدعاء ترجمة و854 مفتاحًا ديناميكيًا دون مفتاح مفقود أو خطأ تعويض.

جُرّبت الواجهة الفعلية على تيننت17070 في قاعدة محلية مع مهمة اختبار محفوظة سلفًا؛ التقطتها الواجهة عند60% ثم استعادتها بعد إعادة التحميل مع تعطيل بدء تحليل آخر. بعد إنهاء إذن العامل ظهرت رسالة التوقف وروابط المراجعة. لم يتصل الاختبار بمزود خارجي. حُذفت المهمة الاصطناعية المحددة وأعيد رابط التيننت السابق بعد التحقق.

فُحصت نافذة تعطل التخزين بالعربية والإنجليزية على320/390/768/1440 دون تجاوز أفقي وبزر إغلاق44×44. فُحص ارتفاع550 مع التمرير وإجراء إعادة الفحص بلوحة المفاتيح وإغلاقEscape، وحالة الاستعادة والتوقف بعرض320. قياسات9حالات في responsive.json ولقطات مرفقة. فحص Chromium لا يساوي Safari أو iPhone فعليين.

تحديث الجرد:126مسارًا،470ملفًا متصلًا،2665عنصر تحكم و1467شرطًا؛ لا مسار محذوف. الأعداد جرد ساكن وليست نسبة اكتمال. ما زالت30صفحة بموك أب عام، ولم يثبت اختبار شامل100%.

## المتابعة

الاستعادة في علامة التبويب الحالية فقط؛ لا سجل مهام عبر الأجهزة بعد تسجيل الخروج أو إغلاق التبويب. مراجعة التحليل الكامل في سجل تقارير المواقع مستقلة عن تحليل عقل ساري. الحالة التالية: تثبيت علاقة طلب ثانٍ انضم إلى مهمة جارية، بحيث لا يبدأ تحليلًا جديدًا إذا أعيد نفس المرجع بعد انتهاء المهمة الأولى. لا دفع Git ولا نشر.
