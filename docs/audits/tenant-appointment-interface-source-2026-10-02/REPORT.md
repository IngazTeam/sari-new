# مصدر واجهة إنشاء الموعد — المرحلة 283

أضيفت عقود صريحة لنتائج اقتراح الأوقات، وإيصال إنشاء الموعد، وقراءة نتيجة الطلب. تحمل الردود هوية الحساب والتيننت ووقت القراءة، ويحمل التوفر اختياره الكامل وتحمل الإيصالات معرّف الطلب نفسه. يرفض الراوتر الإيصال المختلف أو الناقص أو المتضمن حقولًا غير متوقعة بدل تسريبه إلى الواجهة. يرفض عقد الأوقات القيم غير الصالحة والتكرار.

تظل الحالات منفصلة: طلب غير موجود حتى وقت القراءة، وطلب محفوظ لكن موعده لم يعد متاحًا، وموعد مسجل بحالة مزامنته الفعلية. وجود موعد مسجل لا يتحول إلى ادعاء نجاح Google؛ يحتفظ بحالات إنشاء الحدث غير المحسومة. بقيت إعادة الطلب بنفس المعرّف خاضعة لمنع التكرار وبصمة الحقول في الكاتب القائم.

- نجحت142حالة معزولة، تشمل صلاحيات الراوترين والنطاق والبيانات غير الموثوقة وعقد Google والتوفر والتحقق من الإيصالات.
- نجحت77حالةMySQL للطلبات والسعة والتزامن وإعادة الطلب، مع تنظيف بيانات الفحص.
- نجح TypeScript وبناء الإنتاج؛ لا تغيير في قاعدة البيانات أو الترحيلات لهذه المرحلة، ولا اتصال خارجي أو نشر.

التالي توصيل هذه العقود بنموذج الموعد الفعلي ومراجعة الحفظ واستعادة معرّف الطلب، ثم فحص الموبايل والموك أب. اختبار المنطق الخلفي لا يُعد فحصًا مكتملًا لهذه الواجهة قبل تنفيذها.
