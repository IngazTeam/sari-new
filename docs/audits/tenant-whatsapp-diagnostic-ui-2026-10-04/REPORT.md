# المرحلة507 — شاشة اختبار واتساب المشتركة

استُبدلت صفحة الاختبار القديمة بمكوّن التطبيق نفسه في الموك أب المركزي، مع اختيار اتصال صريح وفحص الاتصال ورسالة نصية أو صورة. لا مستلم أو رسالة أو مفتاح افتراضي. الموك أب يعلن أن بياناته محلية ويستخدم مفتاحًا وهميًا دون اتصال خارجي.

## ما تغيّر

- مصدر قراءة جديد للمالك الحي والتيننت المختار: إسقاط صريح لبيانات الاتصال دون المفتاح أو بيانات المزود، وحد100 مع علامة اكتمال، والتحقق من عقد النتيجة. يعمل في الراوترين الفعلي والمستقل.
- أخطاء بجانب الخانات وتركيز على أول خطأ وحفظ المدخلات، ومراجعة رقم المستلم والنص أو رابط الصورة قبل التنفيذ. لا جلب لصورة الرابط عند المعاينة ولا كشف للمفتاح في المراجعة.
- قبول المزود منفصل عن التسليم. النتيجة غير المؤكدة تمنع التكرار التلقائي وتطلب قرارًا صريحًا قبل اختبار آخر. الإرسال المعلق يمنع ضغط التأكيد مرتين.
- الحفظ يتطلب تحققًا للرقم الحالي؛ الحفظ والحذف يحتاجان مراجعة ثم قراءة تؤكد الأثر. هذه حماية واجهة وإقرار، وليست ادعاء اكتمال ذرية المداخل القديمة.
- أُصلح زر إغلاق المراجعة إلى44px، وفُصل اسم رقم حساب واتساب عن رقم المستلم، وأوقف ملء بيانات الدخول غير المناسب في المتصفح المختبر باستخدام new-password لحقل المفتاح. هوية الاتصال تستخدم لوحة أرقام.
- مصدر الموك أب يحاكي الفشل والفراغ والتحميل والصلاحيات والحفظ المعلق والرد المفقود. صُححت مطابقة أسماء الحالات بعد تصفية قائمة الحالات الخاصة بهذه الصفحة وبالدليل.

## التحقق

- **216 حالة وحدة مميزة ناجحة** عبر واجهة الاختبار22 ومصدر القائمة9 وحدود التنفيذ62 والدليل8 وجسر الموك أب115. شُغلت مجموعات متداخلة بعد الإصلاحات؛ لا تجمع مرات التشغيل كحالات جديدة.
- **18 حالة MySQL ناجحة**: عزل المالك والتيننت، سحب الصلاحية، تعارض المفتاح، حدود الإرسال، مصدر القائمة دون أسرار، قائمة فارغة وحد100. المزود محاكى والعينات أزيلت.
- **104 قياسات معاينة نهائية ناجحة**: العربية والإنجليزية على320/390/768/1440، للصفحة والنص والصورة والتحقق والفراغ والتعذر والصلاحية والتحميل والنتيجة غير المؤكدة ومراجعات الإرسال والحفظ والحذف. كشف القياس الأول8 أزرار إغلاق صغيرة؛ أُصلحت وأُعيد القياس. الدليل في [responsive.json](responsive.json).
- صفحتا التطبيق المحلي الفعلي بعرض320 و390 اجتازتا القياس دون تجاوز أفقي أو حقول أصغر من16px أو أهداف لمس أصغر من44px في المكوّن. مصدر المتجر التجريبي فارغ؛ لا مفاتيح أو حفظ أو حذف فعلي أو رسائل خارجية. [لقطة الهاتف](actual-mobile.png).
- TypeScript وبناء الإنتاج وفحص مفاتيح الترجمة ناجحة. تحذيرات أحجام بعض الحزم موجودة؛ الميزانية الرئيسية ناجحة. أُزيلت صفحاتQA المؤقتة قبل البناء.
- الحصر المتجدد: **126 مسارًا،523 ملفًا،2780 موضع تحكم**، دون مسارات محذوفة أو روابط حرفية غير مطابقة أو ملفات يتيمة. إشارات46 قراءة لا يكشف المحلل معالجة خطئها ليست46 عطلًا مثبتًا.

## نتيجة إضافية تستلزم المرحلة التالية

اختبار الحفاظ على الخصائص الكامل كشف28 إخفاقًا في سجل انتقالات APIs. المقارنة بملف الحصر فيHEAD أثبتت أن27 منها موجودة قبل هذه المرحلة؛ الجديد كان عدم تتبع المحلل لإعادة تصدير صفحة الاختبار. استُخدم غلاف استيراد صريح ووُثق استبدال قراءة الرقم الأساسي بمصدر الاختيار المعزول. لا يُعلن الاختبار العام ناجحًا حتى مراجعة البدائل الـ27 في المرحلة508، دون حذف خط الأساس أو إسكات الاختبارات.

بقيت9 صفحات بموك أب عام، ومراجعة أمان وذرية حفظ/حذف الربط القديم وإيصال دائم لاستعادة الإرسال. اختبارات العرض أجريت علىChromium المحلي؛ لم يُختبرSafari أوiPhone فعلي ولا مزود حي، ولا تم push أو نشر. هذا الفحص لا يثبت نسبة احتراف المبيعات ولا جودة معرفة المساعد.
