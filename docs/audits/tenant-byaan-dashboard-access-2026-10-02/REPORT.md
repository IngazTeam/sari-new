# صلاحيات بيانات بيان — المرحلة 292

كانت مسارات الحالة والمتدربين والأسئلة ومحتوى الموقع وإعادة المزامنة تعتمد إجراء تسجيل الدخول العام، دون التحقق من صلاحية الميزة. أصبحت تستخدم التيننت المحدد بعد التحقق من عضوية الحساب: الحالة للأعضاء، المتدربون لصلاحية العملاء، الأسئلة ومحتوى الموقع لصلاحية إعدادات المساعد، وإعادة المزامنة لصلاحية التكاملات. بقيت مسارات مراجعة المبيعات واستعادة التسجيل مستقلة بصلاحياتها السابقة.

تقرأ حالة الربط لقطة المصدر المعزولة، وتعيد هوية الحساب والتيننت والأعداد الكاملة المخزنة حتى بعد تعطيل الربط. لا تُستدعى قراءة أسرار الربط أو فك تشفيرها لعرض البيانات. صار انتظار إثبات الملكية حالة محددة، وتعذّر قراءة محتوى الموقع خطأ واضحًا بدل قائمة فارغة. أضيفت حدود معرّفات صحيحة ورفض حقول الإدخال الزائدة وإخفاء أخطاء قاعدة البيانات والمزود عن الرد.

تعديل حالة السؤال واستخدامه في المعرفة عملية واحدة مقفلة: التيننت، الحساب، العضوية، الربط، ثم السؤال المملوك للتيننت. يعاد التحقق بعد الانتظار، ويُرفض الحساب غير النشط والعضوية المسحوبة والربط المعطل، حتى للمالك إذا كان له سجل عضوية مسحوب صراحة. لا يستخدم SQL اسم حقل مرسلًا من العميل. تُتلف وصلة قاعدة البيانات عند عدم التأكد من نتيجة الالتزام أو فشل التراجع.

## التحقق

- نجحت 96 حالة معزولة، تشمل الموجه المباشر والمسارات المركبة في موجه التطبيق، أدوار الفريق، عزل التيننت، رفض حقن النطاق، أخطاء البيانات، الإسقاطات المحددة وحدود أسماء الدورات.
- نجحت 31 حالة MySQL عبر المصدر الجديد ومصدر الربط السابق. أُعيدت الحالات الـ12 الجديدة بعد تصحيح قيمة حساب الاختبار من حالة غير موجودة في المخطط إلى `deletion_pending`. شملت القراءة دون فك أسرار، سؤال تيننت آخر، المالك المسحوب، وانتظار القفل مع سحب العضوية أو تعطيل الربط أو الحساب أو التيننت. أُزيلت البيانات المؤقتة تلقائيًا.
- نجح TypeScript وبناء التطبيق خلال 13.56 ثانية؛ حزمة البداية 424176 بايت و126793 مضغوطة. الأدلة المحلية في `.tmp/tenant-ux/phase292-*`.

## المتابعة

هذه مرحلة مصدر وصلاحيات؛ واجهة البيانات القديمة ستُستبدل بعد مصدر القوائم الكاملة. ما زال مطلوبًا بحث وفلاتر وصفحات متسقة للمتدربين والأسئلة ومحتوى الموقع، ومراجعة تغيير السؤال ببصمة النسخة، وتدقيق طلب إعادة المزامنة ونتيجته عند التنافس وتبديل الربط. لم يُرسل طلب خارجي للمزود، ولا نشر أو ادعاء فحص اختراق شامل أو Safari فعلي.
