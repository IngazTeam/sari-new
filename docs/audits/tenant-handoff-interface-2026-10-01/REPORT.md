# المرحلة 220 — نافذة التسليم ومصادر المحادثة

رُبطت نافذة التسليم بلقطة المرحلة 219 مع فحص الحساب والمتجر والمحادثة. لا يظهر كاش الفتح قبل القراءة الجديدة. أثناء التحديث الدوري تظل الأدلة الحالية مقروءة وتتعطل إجراءات المسؤول حتى تنتهي القراءة؛ لا تنطوي الأقسام أو يختفي النص كل عشر ثوانٍ. الخطأ أو اختلاف الهوية يخفي الحالة القديمة ويعرض إعادة المحاولة.

تأكيد المراجعة مرتبط بكامل الأدلة والصلاحية؛ تغير آخر رسالة أو الإصدار أو المحتوى يلغي التأكيد فورًا. حُميت العملية من النقر المتكرر والنتائج المتأخرة، وتُفحص هوية نتيجة الكتابة وإصدارها. بعد نتيجة غير محسومة يلزم تحديث الملخص قبل إعادة المحاولة. الخادم يحتفظ بتحقق الإصدار وآخر رسالة داخل معاملة تغيير المسؤول.

تُقرأ الرسالة المصدر عند فتح نافذتها فقط. تتطابق هوية الحساب والمتجر والمحادثة ورقم الرسالة، وتظهر حالة تحميل أو تعذر مع زر إعادة المحاولة. الإغلاق يعيد التركيز للرابط الأصلي. فُصل فتح النافذة عن رقم المصدر لمنع ومضة عنوان بلا رقم أثناء حركة الإغلاق التي كشفها المتصفح.

- نجحت 94 حالة للعقود والواجهة وصفحة المحادثات و136 لحصر الميزات؛ المجموع 230، بلا فشل أو تخطٍ. بعد تعديل الإغلاق أُعيدت 26 حالة للواجهة ونجحت؛ هي ضمن العدد السابق وليست 26 حالة إضافية مميزة.
- نجح TypeScript والبناء، ثم أُعيد البناء بعد تعديل الإغلاق. الترجمة العالمية: 11316 استدعاءً و883 مفتاحًا ديناميكيًا محسومًا، صفر أخطاء وصفر مفاتيح ناقصة أو غير محسومة.
- أُعيد تشغيل الخادم المحلي المحمي على 3018. فُتحت إجراءات المحادثة 51 ثم الأدلة ثم مصدر الرسالة الفعلي. تطابق النص والمرجع، وعاد التركيز إلى رابط #conversation-message-51 بعد الإغلاق.
- القياس الفعلي للهاتف 480×844، عرض الصفحة والتمرير 480، ونافذة الدليل ضمن الحدود. حُفظت وفُحصت mobile-source.png. يظهر حول العرض فراغ في صورة أداة الالتقاط؛ ليس تجاوزًا أفقيًا في الصفحة. أُعيد العرض الطبيعي 2560، وعرض المحتوى والتمرير 2530.

بقيت المصادر القديمة متاحة وسُجل انتقال الواجهة مع أدلته في سجل API. لا اختبار Safari/iPhone فعلي، ولا إرسال خارجي أو نشر. لا تعني هذه المرحلة إكمال تصميم صفحة المحادثات كلها؛ التالي مراجعة التصعيد والعروض، ثم الاقتراحات والمرفقات والاتصال والتصميم والموك أب الفعلي.
