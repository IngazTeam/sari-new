# المرحلة169 — تقاعد الواجهة القديمة للمصادر والتحليل

التاريخ2026-10-01. أُغلقت المرحلة168 بالكوميت cdaa9233 قبل هذه المرحلة.

حُذفت بطاقات المصادر القديمة وتأكيدات حذفها وإعادة ضبطها وأعدادها المنفصلة، ومداخل التنفيذ القديمة نفسها. المجموعات الحالية تعتمد مكوّن التطبيق، ومراجعة الحذف الحالية وإيصالها موجودان في البديل الفعلي. بقيت مكتبة الملفات والاستخراج ومراجعة المحتوى والأقسام وتجارب البيع كما هي. أزيلت نافذة متابعة الموقع اليدوية وأزرار التقدم القديمة واستُبدل مدخلها بالشاشة الفعلية لنتائج التحليل. أزيل CSS المتقاعد، مع الحفاظ على نتائج مراجعات التعلم المحفوظة عند قراءة نموذج التخزين السابق.

## مشكلة إضافية أصلحها الفحص

الإطار الطويل للمجموعات كان يجعل نافذة الحذف تتمركز حسب كامل محتواه، خارج شاشة الهاتف. أصبح فتح نافذة فعلية يضبط ارتفاع الإطار حسب نافذة المتصفح ويجلبه إلى موضع العرض؛ تعود أبعاد المحتوى عند الإغلاق. رسائل الإطار تمر بالتحقق نفسه من المصدر والنافذة والمسار، ولا تقبل حالة نافذة غير منطقية.

في عرض480×844 قيس ارتفاع الإطار680px وموضعه122px، وارتفاع الحوار648px وموضعه16px داخله؛ بعد الإغلاق عاد ارتفاع المصادر3472px. قُرئت المراجعة وأُغلقت دون تنفيذ حذف. قياسات DOM هي مرجع الحجم؛ لقطة IAB للصورة الصغيرة تلتقط مساحة إضافية وتُقص بصريًا، فلا تثبت جهازًا حقيقيًا.
