# المرحلة 441 — مصدر المقارنة بالبيانات المحفوظة

2026-10-04، main، محلي دون دفع أو نشر.

أضيفت قراءة معزولة لاختيارات تقارير الموقع والمنافسين المكتملة ببحث حرفي وصفحات25، ثم مقارنة تقرير موقع مع1–5تقارير منافسين في لقطة قاعدة واحدة وبصلاحية التحليلات الحية. يُرفض التقرير الجاري أو الفاشل أو المفقود أو التابع لتيننت آخر، ولا تُحذف اختيارات غير متاحة بصمت من النتيجة.

تتضمن المقارنة درجات المصدر وفروقها الحسابية، مع إبقاء القيم غير الصالحة غير متاحة وحفظ الصفر الحقيقي. تبين التواريخ وأعداد المنتجات الفعلية والمراجع المستبعدة؛ الأسعار منفصلة حسب العملة والمنتجات غير المطابقة لا تنتج ادعاء فرق سعر أو احتراف مبيعات. تُعاد بصمة الدليل المختار تمهيدًا للمراجعة. لا تقرأ الأداة النص الخام أو رسائل المزود ولا تستدعي نموذجًا أو تكتب من طلب قراءة.

نجحت75حالة وحدة ورواتر وعقود و25حالة MySQL، تشمل العزل والأدوار والقيم المشوهة والصفر والعملات وبصمة التغيير والاختيارات الكاملة دون تكرار الصفحات. نجح TypeScript وبناء التطبيق، وتنظف البيانات الاصطناعية بعد الاختبارات.

هذه مرحلة مصدر؛ الشاشة والموك أب في المرحلة التالية. المقارنة الحسابية لا تستبدل الادعاء بوجود توصيات جديدة مولدة بالذكاء الاصطناعي؛ يبقى توليد التوصيات بإجراء مفوض ذي إيصال مستقل. لا Safari/iPhone فعلي أو مزود حي أو نشر.
