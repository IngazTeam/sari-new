# المرحلة 266 — تصنيفات الخدمات والباقات الفعلية

استُبدلت واجهتا التصنيفات والباقات القديمتان بمكونات لوحة التاجر الجديدة. تشمل المرحلة القائمتين والإنشاء والتعديل والتعطيل وإعادة التفعيل من التعديل؛ لا تغييرات على مخطط قاعدة البيانات أو صلاحيات الحسابات.

## تغطية الحقول والتفاعل

| النطاق | التنفيذ |
| --- | --- |
| التصنيف | الاسم، الاسم الإنجليزي، الوصف، الرمز، اللون الاختياري، ترتيب العرض، الحالة؛ الرمز المركب لا يُقص إلى حرفين |
| الباقة | الاسم، الوصف، خدمات الباقة، السعر الأصلي، سعر الباقة، الخصم المشتق، الحالة |
| القوائم | إجمالي كامل وحالات نشطة/معطلة/مجهولة، بحث وصفحات 24، فلاتر محفوظة بالرابط، تفاصيل واضحة وروابط تعديل تحافظ على الفلاتر |
| اختيار خدمات الباقة | خدمات نشطة من التيننت الحالي، بحث وصفحات، أسماء الاختيارات المحفوظة خارج الصفحة، حتى 200 اختيار، إظهار العلاقات غير المتاحة |
| الأسعار | تحويل دقيق إلى أصغر وحدة، أرقام عربية وفارسية وفاصلة عشرية عربية، قبول الصفر، رفض أكثر من منزلتين ورفض سعر باقة يتجاوز الأصل، خصم صفر عند الأصل صفر |
| الأخطاء | أخطاء عند الحقول وتركيز أول خطأ وفتح الخيارات الإضافية عند الحاجة؛ JSON تالف لا يتحول إلى اختيار فارغ صالح |
| الحفظ | مراجعة كل القيم، بصمة النسخة الحالية، منع الضغط المكرر، تجاهل اكتمال الطلب بعد تغيير الحساب أو الصفحة، الاحتفاظ بالمدخلات عند فشل القراءة |
| التعطيل | تسمية صحيحة بدل «الحذف»، تأكيد ببصمة السجل، بيان أثر التعطيل على العلاقات، تحديث الحالة قبل إعادة المحاولة غير المؤكدة |

المحرر صفحة داخل المسار نفسه عبر `?edit=new` أو معرّف موجب صارم. الخروج يعيد فلاتر القائمة. تتطلب استعادة النسخة الأحدث تأكيد استبدال المدخلات. فقدان إذن الإدارة يعطل الحقول والحفظ؛ فشل مصدر البيانات لا يعرض رسالة الخادم الخام أو بيانات حساب آخر. القوائم الثلاث تستخدم مكون عرض واحد مع أوامر تعطيل مستقلة لكل كيان.

## التحقق المنفذ

- **312 اختبارًا معزولًا**: عقود المحررين، تفاعل صفحات التصنيف والباقة الفعلية، رجوع قائمة ومحرر الخدمات، المصدر والكتابة وعزل الوصول. تشمل اختبارات الواجهة العربية والإنجليزية والمشاهدة دون صلاحية والتعارض وفشل الاتصال ونتائج الطلبات المتأخرة.
- **32 اختبار MySQL** محلي: كتابة الكتالوج وقراءة اللقطات وعزل التيننت والصلاحيات. لم تُستخدم قاعدة الإنتاج.
- TypeScript كامل: ناجح. بناء الإنتاج: ناجح (16.68 ثانية) مع تحذير حجم الحزم القائم؛ حزمة البداية 424052 بايت، gzip 126773.
- بوابة الترجمة: **11839 استدعاء، 883 مفتاحًا ديناميكيًا، صفر مفاتيح مفقودة أو استدعاءات غير محلولة أو أخطاء interpolation**. النسخة الفعلية معلنة بالعربية؛ اختبار الإنجليزية هنا في React.
- تجربة محلية عبر المتصفح: إنشاء التصنيف 406 مع `🧑‍💻` واللون والترتيب صفرًا، وإنشاء الباقة 42 بسعر أصلي 100.50 وسعر 80.40 وخصم 20%. ثم مسح الوصف وتصفير السعرين، ورفض حفظ نسخة قديمة، وتعطيل الباقة. تحقق مستقل من القيم المحفوظة في MySQL ثم تنظيف التصنيف والباقة المخصصين للفحص فقط. الخدمة المرجعية 28 بقيت دون تعديل.
- شاشات فعلية داخل إطارات 480×900 و390×844 و320×568: قائمة ومحرر التصنيف مع الخيارات الإضافية، قائمة ومحرر الباقة مع اختيار الخدمات، وحوارا المراجعة. العرض المتاح بعد شريط التمرير 450/360/290؛ عرض المحتوى مطابق دون تجاوز أفقي. الحقول 16px وأهداف القوائم 44px فأكثر.
- حوارا المراجعة عند 320×568: من أعلى16 إلى أسفل552، عرض داخلي226 بلا تجاوز أفقي، ارتفاع534؛ محتوى التصنيف754 والباقة817 بتمرير رأسي. يبدأ التركيز من العنوان وموضع التمرير صفرًا.
- جرد المسارات: 126 مسارًا، 371 ملفًا، 2289 عنصر تحكم، 316 استعلامًا؛ لا روابط غير صالحة أو مسارات محذوفة. هذا جرد مصدر، لا ادعاء تغطية كل خاصية بنسبة100%.

أدلة محلية في `.tmp/tenant-ux/phase266-{tests,mysql,translations,ui}.json` وسجلات الأنواع والبناء وصور `phase266-category-saved.png` و`phase266-package-saved.png` و`phase266-category-responsive.png` و`phase266-package-responsive.png`. حُذف مضيف الإطارات المؤقت قبل البناء.

## حدود النتيجة والتالي

الفحص المرئي في Chromium المحلي، وليس Safari فعليًا أو جهاز iPhone. لم يُنفذ نشر أو اختبار اختراق شامل. الموك أب المركزي للخدمات وتفاصيل الخدمة القديمة ما زالا المرحلة التالية. لا يتضمن الحفظ إيصال idempotency دائمًا؛ يمنع المحرر تكرار الطلب غير المؤكد في الجلسة الحالية ويطلب مراجعة القائمة، والمدخلات غير المحفوظة ليست مسودة دائمة عند إعادة التحميل أو مغادرة الصفحة. مفاتيح ترجمة الصفحات القديمة محفوظة للتوافق؛ مكونا الواجهة القديمان أزيلا من التنفيذ.
