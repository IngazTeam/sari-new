# المرحلة 255 — حدود المحتوى والتعديل المتزامن

وُحد حارس النص النهائي بين المعاينة والخادم: يُحتسب إشعار إلغاء الاشتراك ضمن حد 4096 للنص أو 1024 لتعليق الصورة، وفق قياس UTF-16 المستخدم في خدمة النقل الحالية. تُرفض الرسالة الفارغة والصورة غير الصالحة أو غير HTTPS أو المتضمنة بيانات دخول. لا يُقص النص صامتًا.

يعمل التحقق عند الإنشاء، وعند الإرسال قبل قراءة القناة والجمهور، وعند الإدراج النهائي في طابور الإرسال بعد قفل الحملة. يحمي المسار الأخير أيضًا الحملات القديمة أو المولدة بواسطة الوظائف الخلفية. لا يُدرج مستلم ولا تتغير حالة الحملة إذا فشل المحتوى.

أصبح تعديل الحملة يقرأ حقولها الحالية داخل معاملة وقفل، ثم يدمج التغييرات ويتحقق من الرسالة والصورة معًا. يمنع ذلك تسابق إضافة صورة مع إطالة الرسالة. يقبل التعديل بصمة التعريف المعروض، ويرفض تغير أي جزء منه منذ المراجعة. البصمة اختيارية مؤقتًا للتوافق مع المحرر القديم، وسيُوصلها المحرر الجديد؛ حتى عند غيابها تُطبق حماية الحالة والملكية وصلاحية المحتوى المدمج. لا تسمح الدالة الجديدة بتعديل الملكية أو العدادات أو نقل الحالة إلى الإرسال.

نجحت 832 حالة انحدار معزولة و85 حالة MySQL، بإجمالي 917. شملت الحدود الدقيقة وبعدها بوحدة واحدة، النص العربي والإنجليزي والإيموجي، الصورة المضافة إلى نص محفوظ، الإصلاح بإزالة الصورة، التعديل المتزامن، بصمة قديمة لكل جزء من التعريف، انتظار القفل، التراجع عند فشل الكتابة، والملكية والحالات غير القابلة للتعديل. تضمنت MySQL اختبارات النقل السابقة؛ لم يُستدع مزود خارجي. نجح TypeScript والبناء. حدث الجرد بعد رصده بصمة الملف القديمة؛ نجح اختبار حفظ الخصائص بعد التحديث. لا مفاتيح ترجمة جديدة.
