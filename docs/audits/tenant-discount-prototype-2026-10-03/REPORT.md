# المرحلة 354 — موك أب الخصومات الفعلي

التاريخ: 2026-10-03. main محلي فقط، دون push أو نشر.

استُبدل موك أب الخصومات العام بالصفحة والمكونات الفعلية نفسها. يعمل ضمن الموك أب المركزي أو المعاينة المستقلة، مع تيننتين ولغتين و14 حالة مناسبة للخصومات، وتبقى أكواد المثال وعملياته في الذاكرة فقط.

- 31 سجلًا لكل تيننت، قوائم25 وبحث كامل وفلاتر الحالة والمصدر وعدادات كاملة. أضيف اختبار تطابق القيم والتصنيفات والمرشحات مع إسقاط مصدر التطبيق، باستثناء بصمة المثال المحلية التي ليست SHA-256 للخادم.
- الإنشاء بالقوالب والأخطاء والمراجعة، والتعديل والتعطيل والحذف ببصمة محلية، وحالات التأخير والتعارض والنتيجة غير المؤكدة. إعادة القراءة بعد الحفظ الملتبس لا تعيد الكتابة.
- ربط المسار والفلاتر واللغة والتيننت بالغلاف المركزي، مع بقاء التحقق من مصدر iframe وorigin والمعلمات المسموحة ومنع النطاق أو المعلمات الغريبة.
- أضاف الاختبار بالمحول الحقيقي كشف سباق تركيز خانة الكود المكرر. استُبدلت محاولة التركيز المبكرة بتأثير بعد رسم النموذج في مكوّن DiscountEditor المشترك. أُثبت تركيز code في المتصفح بعد ظهور الخطأ.

## نتائج التحقق

المجموعة النهائية **366/366 ناجحة، 0 حالات أو مجموعات فاشلة، success=true وexit=0** في `.tmp/tenant-ux/phase354-acceptance.json`. تشمل صفحة الخصومات الفعلية ومحاكاتها، حالات الخدمة وCalendly، جسر الرسائل، الحصر وحفظ الخصائص. المحاولة الأولى كشفت خطأ التركيز وسجل عقود المعاينة القديم؛ أُصلحا ثم نجحت المجموعتان اللاحقتان.

نجحت أنواع المشروع والمعاينة، وبناء المعاينة وبناء التطبيق (**21.10 ثانية**؛ تحذير الحزم الكبيرة مع نجاح الميزانية). الترجمة بلا مفاتيح مفقودة أو ديناميكية غير محلولة أو أخطاء interpolation. لا تغيير لقاعدة البيانات أو منطق خادم الخصومات في هذه المرحلة.

فحص Chromium تضمن إنشاء مثال وتصحيح الكود المكرر، وعودة التركيز، وتغيير اللغة والتيننت، والقراءة فقط والفشل مع بيانات قديمة والفراغ. نجح ربط فلتر expired + automatic بعنوان الغلاف المركزي. [15 قياسًا](responsive.json) للعربية/الإنجليزية بعروض CSS 320/390/768/1440 وارتفاع844 أو550، دون تجاوز أفقي أو تحكم ظاهر في الخصومات دون44px أو مفاتيح ترجمة خام في الحالات المقاسة. ## الحدود والمتابعة

الصفحة المركزية تمنع تضمينها في iframe اختباري؛ استُخدمت معاينة الصفحة الفعلية المسموح تضمينها لقياسات الهاتف، واختُبر الربط بالغلاف المركزي مستقلاً. لا Safari/iPhone فعلي أو نشر. الأمثلة وإصداراتها في الذاكرة، وليست إيصالات أو إثباتات خادم دائمة؛ إعادة التحميل أو تغيير الحالة/التيننت تعيدها. لا إنشاء أكواد في قاعدة بيانات فعلية أو رسائل خارجية. أُزيلت ملفات أداة قياس العرض من مجلد الموقع بعد الفحص.

التغطية الآن **50 تفصيليًا، 29 تفصيليًا جزئيًا، 39 موك أب عامًا، 8 تحويلات** من126مسارًا. هذا وصف للتغطية الموثقة وليس اكتمال النظام بنسبة100%. التالي: صفحة الإحالات وخصائصها وصلاحياتها، ثم بقية السجل.
