# قراءة مجموعات مصادر المعرفة — المرحلة162

تاريخ2026-10-01، main، محلي فقط.

أضيف قارئ موحد في معاملة REPEATABLE READ للقراءة فقط، مع هوية تيننت وعقد صارم يمنع الأعداد المتناقضة. يحصي الملفات وحالات استخراجها، المنتجات المحفوظة والمخفية بالربط والظاهرة والمفعلة، جميع تحليلات الموقع وصفحاته، الأسئلة بما فيها المؤرشفة، وأقسام المعرفة بما فيها اليدوية. لا يجمعها في رقم يوهم بأنها مصادر مستقلة؛ القسم قد يكون مشتقًا من ملف أو صفحة.

يعيد تواريخ الرفع والتعديل والتحليل من سجلاتها الفعلية؛ لا يستخدم تاريخ اليوم للمنتجات أو بديلًا للتاريخ المفقود. تاريخ حساب التاجر منفصل عن تاريخ المصادر. ملخص الرد لا يحمل نص الملفات أو عناوينها أو روابط الموقع أو مفاتيح الربط. النطاق المفقود والقراءة الفاشلة لا ينتجان أصفارًا؛ تُرفض القراءة كاملة ويُغلق الاتصال عند تعذر التراجع.

نجحت22 حالة معزولة و5MySQL، والأنواع. شملت5 حالات قاعدة البيانات الملفات الخالية أو الفاشلة، المنتجات المخفية لربط سابق، صفحات دون تحليل، عدة تحليلات، الأسئلة المؤرشفة، الأقسام اليدوية، عزل التيننت والتواريخ الثابتة. كشف التشغيل الأول اسم SQL محجوزًا في alias الخاص بالملفات الخالية؛ صُحح وأعيدت جميع حالات MySQL بنجاح. لا تغيير قاعدة أو خدمات خارجية.

هذه طبقة قراءة لم تُربط بالشاشة بعد؛ المرحلة التالية تستبدل getSources القديم ومجموعاته بواجهة تستخدم هذا العقد والموك أب المطابق، ثم تستمر بقية مراحل سجل المتابعة. لا نشر.
