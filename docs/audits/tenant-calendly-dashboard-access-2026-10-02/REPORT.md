# المرحلة 335 — صلاحيات ومصدر شاشة Calendly

بتاريخ 2026-10-02، main، دون رفع أو نشر أو اتصال بمزوّد Calendly.

## الحصر والإصلاح

المسار /merchant/integrations/calendly يستدعي ثمانية إجراءات: getConnection وconnect وdisconnect وsyncNow وupdateSettings وgetUpcomingEvents وgetEventTypes وgetStats. الصفحة تتضمن الربط، المواعيد، الإعدادات، التحديثات الفورية وروابط الحجز.

- تشترط الإجراءات الثمانية integrations.manage وتستخدم ctx.merchantId الذي تثبته العضوية المختارة. المالك والمدير مسموحان؛ المشاهد ومشرف المبيعات لا يديران هذا التكامل. لا يُقبل معرّف متجر أو فاعل من المدخلات أو سياق مزور.
- تتوقف القراءات والكتابات عند تعذر قاعدة البيانات، وتُخفى أخطاء SQL والمزوّد الخام. المدخلات التي كانت بلا عقد أصبحت صارمة.
- لا تُرسل قراءة خارجية عبر ربط غير نشط. تعذر قراءة المواعيد والأنواع ليس قائمة فارغة، وتعذر مخزن الإحصاءات ليس صفرًا.
- الواجهة تعرض فشل المصدر، تخفي بياناته القديمة ونموذج الربط عند فشل قراءته، تعرض مؤشرات غير متاحة للإحصاءات، وتزيل مسودة الاعتماد عند تغيير هوية المستخدم/المتجر المؤكدة. أخطاء الإجراءات العامة لا تعرض message الخام.
- صححت سبعة توقعات نصية قديمة في مجموعة الأمان لتتحقق من تقاعد إجراءات زد واستخدام مسار اللغة المراجع الحالي، مع تشغيل اختبارات سلوكهما الفعلية.

## التحقق

304 حالات ناجحة وصفر فشل: Calendly API والواجهة وأمن webhook ومجموعة الأمان العامة وصلاحيات زد وخيارات المساعد وعقود المشروع. أربع حالات MySQL إضافية بتيننتات مؤقتة تثبت الاختيار والعضويات وتوقف العمليات بعد السحب أو التعليق وعدم تغيير متجر آخر. فحص الأنواع النهائي والبناء ناجحان؛ 12714 استدعاء ترجمة و880 مفتاحًا ديناميكيًا بلا نقص أو أخطاء interpolation.

فتحت الصفحة الفعلية محليًا بحساب الاختبار الموجود، بلا إدخال اعتماد أو اتصال بمزوّد: عنوان h1 واحد ولا مفاتيح ترجمة ظاهرة. فحص قواعد الصلاحيات الجديدة تم في عمليات الاختبار المستقلة. الصورة .tmp/tenant-ux/phase335-calendly-local.png.

## ما يتطلب المرحلة التالية

هذه مرحلة ضبط دخول ووضوح قراءة، وليست اكتمال تصميم Calendly. لا تزال عمليات الربط والفصل والمزامنة بحاجة إلى مراجعة بصمة، استعادة نتيجة غير مؤكدة، وإعادة تحقق من الصلاحية بعد انتظار القفل وأثناء الاتصال/الحفظ. يلزم أيضًا معالجة احتمال حذف الاشتراك الجديد بعد حفظ ملتبس، وعدم اعتبار مزامنة محدودة مكتملة، وتوفير مصدر كامل لجدول المواعيد وسجل التحديثات، والتحقق من روابط الحجز الخارجية ثم الواجهة والموك أب الفعلي.

لا اختبار Safari/iPhone فعلي أو ضمان فحص اختراق شامل؛ خطأ المراقب في الغلاف المركزي المسجل في334 ما زال مفتوحًا.
