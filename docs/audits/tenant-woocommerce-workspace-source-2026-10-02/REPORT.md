# المرحلة318: مصدر حالة WooCommerce وسجل المزامنة الكامل

أضيفت قراءتا `getWorkspace` و`getLogsWorkspace` بصلاحية إدارة التكامل في التيننت المحدد. تستخدم كل قراءة معاملة قراءة فقط بلقطة متسقة. تعرض هوية الحساب والتيننت ووقت الفحص، وتتوقف بخطأ عام عند تعذر البيانات؛ لا تحول فشل التخزين إلى حالة فارغة.

حالة الربط هي الحالة المحفوظة، وليست فحص توفر حي للمزود. تُقرأ أعلام وجود المفاتيح وبصماتها من SQL دون فك التشفير أو إعادة قيمها. رابط العرض يخلو من الاستعلام والجزء الملحق وبيانات المصادقة. ترتبط بصمة المراجعة بالهوية والمفاتيح والحالة وإعدادات الربط وتسجيلات webhook؛ لا تغيرها أوقات تقدم المزامنة أو الفحص وحدها.

تُحسب المنتجات والطلبات والسجلات المحلية كاملة حتى عند غياب الربط. تفصل الأحداث المعلقة والمراجعات القديمة عن نتائج آخر سبعة أيام. جاهزية webhook المحلية تتطلب الهوية وستة موضوعات صحيحة مختلفة ومعرفات مزود صالحة؛ لا تعني إثبات وصول المزود الآن.

يوفر السجل صفحات25 وبحثًا حرفيًا بمعرف السجل ونوع العملية واتجاهها وحالتها. تتفق العدادات والصفحة ضمن اللقطة نفسها، وتظهر الأعداد أو التواريخ غير الصالحة بوضوح. لا يعيد المصدر نص أخطاء المزود أو محتوى details. الحالة running تبقى وصف السجل المحفوظ، ولا تثبت وجود عامل نشط.

## التحقق

- نجح194اختبارًا معزولًا: عقود البيانات والمرشحات، عدم كشف الأسرار، تراجع المعاملة، التخلص من اتصال ذي التزام غير محسوم، صلاحيات المسارين المباشرين والمثبتين في الراوتر، واستمرار سلطة WooCommerce.
- نجح26اختبار MySQL: عزل التيننت والعضوية،1003سجلات بصفحات كاملة،2003منتجات وطلبات دون قص، فساد تاريخي، غياب الربط، جاهزية webhook، وتزامن إدراج بين قراءة الإجمالي والصفحة مع بقاء اللقطة متسقة.
- نجح TypeScript وبناء المشروع16.19ثانية. فشل الاستعلام الأول بسبب اسم SQL محجوز؛ صُحح وأُعيدت المجموعة كاملة بنجاح.

الأدلة المحلية: `.tmp/tenant-ux/phase318-{tests,mysql}.json` و`phase318-types.log` و`phase318-build.log`. لا اتصال بمزود خارجي أو إرسال فعلي أو نشر.

## التالي والحدود

التالي مصادر قوائم المنتجات والطلبات والإحصاءات، ثم مراجعة الكتابات واستعادتها الدائمة والصفحات الأربع والموك أب. أضيف المصدر دون تغيير الواجهات القديمة في هذه المرحلة. لا يثبت العمل اختبار Safari/iPhone فعليًا أو اكتمال كل لوحة التيننت.
