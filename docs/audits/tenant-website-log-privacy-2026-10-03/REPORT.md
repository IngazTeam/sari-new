# حماية بيانات تقارير المواقع في السجلات

المرحلة 428 بتاريخ 2026-10-03. أزيلت من السجلات التشغيلية روابط الصفحات وخرائط الموقع وواجهات المتاجر، ومعرّفات المتاجر المستخرجة، وعناوين التقارير والمنتجات وأسماء الشركات وبيانات التواصل والأخطاء الخام. قد تحتوي الروابط على معاملات خاصة، لذلك لا يطبع المسار رابطًا مختصرًا أو كاملًا.

## نطاق الإصلاح

شمل الإصلاح محلل المواقع والزحف والاستخراج واستكشاف واجهات المنصات وقراءة التقارير ومراحل التحليل في الموجّه. بقيت أسماء المراحل وأعداد الصفحات والمنتجات وأطوال النصوص ونوع المنصة ومعرّف التقرير الداخلي. بقيت روابط المصادر ونتائج التحليل وبيانات التواصل المحفوظة في مواضعها الأصلية دون تغيير وظيفي.

## التحقق

أثبتت 8 حالات قبل الإصلاح ظهور البيانات المصطنعة الخاصة في السجلات. نجحت بعد الإصلاح اختبارات النجاح والفشل للزحف، واستخراج الشركة والأسئلة الشائعة، واستخراج منتجات JSON-LD، وفشل التحليل، ومسار التقرير مع بيانات التواصل وأخطاء حفظ المنتجات. يتفحص الاختبار كائنات الأخطاء ومكدسها ولا يكتفي بتحويل Error إلى JSON فارغ. أضيف فحص سجل فشل قراءة التقرير أيضًا.

نجحت 91 حالة مع تراجع حماية طلبات المواقع العامة والاستخراج والفهرسة ومحرك المعرفة. نجح فحص الأنواع وبناء التطبيق وفحص فروق Git. الشبكة الخارجية محجوبة في الاختبارات.

## المتابعة والحدود

لا تغيير واجهة أو مفاتيح ترجمة أو بيانات قديمة أو نشر. تعديل السجلات لا يثبت وحده اكتمال أمان المسار؛ يبقى ربط مسار تقارير المواقع المنفصل بتفويض تنفيذ دائم، ومراجعة أخطاء المنافسين المعادة للعميل والمحفوظة في التقرير، ضمن العمل المتبقي. تليها مراجعة طبقة نقل الذكاء الاصطناعي وأخطاء تسجيل الاستخدام.
