# المرحلة 519 — مركز الخصوصية الفعلي والموك أب

التاريخ: 2026-10-04. تنفيذ محلي على main؛ لا دفع إلى الريموت أو نشر.

## النتيجة

استُبدلت صفحة الخصوصية القديمة بمكوّن مشترك مع الموك أب، بأربع بطاقات: الموافقة التسويقية، طلب الخصوصية، نسخة البيانات، وحذف الحساب. العربية والإنجليزية كاملتان، وسجل آخر 20 طلبًا يعرض النوع والحالة والمرجع والمواعيد وسبب الرفض المتاح. لا تعرض أخطاء القراءة كموافقة مرفوضة أو سجل فارغ.

نطاق الإجراءات هو الحساب الشخصي وكل متاجره المملوكة، بصرف النظر عن التيننت المفتوح. قائمة أثر الحذف تعرض المتاجر المملوكة، ويُمنع التأكيد عند ملكية مشتركة أو حساب إدارة أو غياب كلمة مرور أو تجاوز 50 متجرًا في عرض المراجعة. صلاحية الحذف النهائية تبقى في الخادم.

| الخاصية | ما تم تحسينه وفحصه |
| --- | --- |
| الموافقة التسويقية | احترام السحب، مراجعة قبل الحفظ وإقرار يطابق الحساب والاختيار |
| الوصول/التصحيح/الاعتراض | أخطاء حقول وتفاصيل 3–1000 حرف؛ التصريح بوجود طلب مفتوح من النوع نفسه وعدم استبدال تفاصيله بصمت |
| التصدير | كلمة مرور وجلسة حية، بيانات صاحب الحساب فقط، استبعاد محتوى العملاء والأسرار، مطابقة الحساب قبل التنزيل |
| السجل | حالات مترجمة وترتيب حاسم، تصريح بحد آخر 20؛ الموعد هدف للرد لا ضمان اكتمال |
| الحذف | كلمة مرور وعبارة حرفية وأثر كل المتاجر؛ إيقاف الوصول بعد القبول دون ادعاء اكتمال المحو؛ غموض النتيجة يمنع الإعادة في الزيارة نفسها |
| الموك أب | المكوّن الفعلي مع بيانات وإجراءات في الذاكرة؛ لا تغيير حساب أو إرسال طلب دعم أو تنزيل بيانات شخصية أو حذف حقيقي |

## حدود التنفيذ

- فحص الجلسة داخل المعاملات وحد MySQL مشترك: 5 محاولات كلمة مرور لكل 15 دقيقة، و20 كتابة أخرى لكل دقيقة، لكل حساب.
- التصدير يرفض تجاوز 100 متجر أو 5000 سجل لأي مجموعة أو 8 MiB للحمولة؛ لا يصدر نسخة مبتورة بوصفها كاملة. تُقترح مراجعة عبر طلب وصول عند التجاوز.
- تحقق إقرار إدراج الطلبات وإيصالات الموافقة. اتصال انتهى بغموض عند تثبيت المعاملة يُتلف ولا يعاد إلى التجمع. لا إعادة تلقائية للكتابات.
- اختبارات تسجيل الهوية اجتازت التحقق الجديد من إيصالات الموافقة. لا تغيير لعامل المحو أو سياسة الاحتفاظ، ولا ترحيل قاعدة جديد.
- عقد الإصدار الجديد: privacy-account-session-workspace-v1.

## نتائج التحقق

- نجحت 207 اختبارات وحدة/واجهة/حفاظ، و15 اختبار MySQL للخصوصية و4 للتسجيل، و72 اختبار إصدار.
- نجح فحص الأنواع وبناء الإنتاج والمعاينة؛ أخطاء الترجمة والاستيفاء والمفاتيح الديناميكية غير المحلولة: صفر.
- شاهدنا الصفحة في التطبيق على 3025 بحساب الفحص وفي الموك أب 4329. الكتابة عبر المتصفح كانت محاكاة؛ اختبارات الحذف البرمجية اقتصرت على حسابات مؤقتة معزولة ونُظفت بعد الاختبارات.
- 16 قياسًا: صفحة ومراجعة حذف × لغتين × إطارات 320/390/768/1440. العرض الداخلي المقاس 290/360/738/1410 بسبب إطار المعاينة؛ لا تجاوز أفقي، الحقول 16px وأزرار العمل لا تقل عن 44px. النافذة تتمرر داخليًا عند ضيق الشاشة.
- الجرد: 126 مسارًا، 602 ملف، 2808 عناصر تحكم؛ لا مسارات محذوفة من خط الأساس. بقيت خمس صفحات بموك أب عام: الفريق وأربع صفحات الولاء.

## حدود الإثبات والمتبقي

الفحص في Chromium المحلي لا يثبت Safari/iPhone حقيقي أو لوحة مفاتيحه. اختبارات الأمان محدودة بالمسارات المذكورة وليست شهادة اختراق شاملة أو ضمانًا بنسبة 100%. لا محو آلي لحساب فعلي أو مراجعة قانونية جديدة. لا تصفح لما قبل آخر 20 طلبًا؛ يشملها التصدير ضمن حدوده. لا إيصالات عمليات دائمة موحدة لكل الإجراءات؛ تظهر النتيجة الشبكية غير المؤكدة بوضوح. التالي: حدود إدارة الفريق ثم شاشته المشتركة والولاء.
