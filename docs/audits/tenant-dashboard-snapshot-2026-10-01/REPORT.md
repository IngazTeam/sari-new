# المرحلة 192: لقطة بيانات الرئيسية

أضيف المسار `dashboard.workspace` بعقد صارم وهوية التيننت المحلولة من الجلسة وصلاحية analytics.read. يجمع العملة والفترتين والاتجاه وعينة المنتجات في معاملة قراءة واحدة بمستوى REPEATABLE READ، وبنهاية زمنية حصرية وتواريخ UTC مستقلة عن منطقة اتصال MySQL.

القيم السالبة مستبعدة من إجمالي القيمة والمتوسط مع إظهار عددها، ولا تحسب نسبة نمو القيمة عند نقص البيانات أو انعدام أساس المقارنة. عناصر الطلبات التي لا توضح وحدة السعر تستبعد بدل افتراض هل السعر بالريال أو الهللة. ترتيب المنتجات محدود بأحدث 250 طلبًا مسلّمًا ويعيد عدد الطلبات المستبعدة وغير المفحوصة، ومتوسط سعر موزون بالكميات.

التحقق: 82 اختبارًا للعقد والحساب والصلاحيات وحدود التيننت، و8 اختبارات MySQL محلية تشمل الطلبات الأجنبية والعملات والحد الزمني وعينة 251 طلبًا والإدراج المتزامن والمنطقة +03:00. نجح فحص TypeScript والبناء الإنتاجي؛ بقي تحذير أحجام بعض الحزم المعروف. عولج خطأ تركيب SQL الذي أنتجه الجمع بين خيارات Drizzle للّقطة والقراءة فقط، وأثبت اختبار الإدراج المتزامن ثبات اللقطة باستخدام معاملة REPEATABLE READ للقراءة فقط.

هذه إضافة مصدر بيانات؛ الواجهة ما زالت تستخدم المصدر السابق وتربط بالعقد الجديد في المرحلة التالية. لا ادعاء اكتمال تصميم الرئيسية أو فحص Safari فعلي أو نشر.
