# المرحلة 369 — موك أب حملات المناسبات الفعلي

رُبط المسار المركزي بالمكونات الفعلية للوحة، مع تيننتين ولغتين و31 سجلًا وصفحات من25 سجلًا. يمكن تجربة التجهيز غير المفعّل والتفعيل والإيقاف ومراجعة العرض والجمهور والرسالة، والقراءة فقط والبيانات القديمة والصلاحيات والانقطاع وتعارض الحفظ والحفظ المعلّق أو غير المؤكد. كل تغييرات المعاينة في الذاكرة، دون خصومات أو إرسال أو كتابة على قاعدة البيانات.

نُقل التقويم وتوليد النص إلى shared/occasion-calendar.ts ليستخدمهما التطبيق والمعاينة معًا، مع إبقاء صادرات العامل السابقة متوافقة. يقارن الاختبار إسقاط سجلات المعاينة بالمصدر الفعلي، ويتحقق من التقويم والنص. استدعاء المراجعة لا يمسح سيناريو الفشل، وإعادة الطلب بعد تغيّر التيننت أو النسخة مرفوضة. لم يتغير سلوك العامل الخلفي في هذه المرحلة.

يدعم الجسر المركزي فلاتر السنة والحالة الخاصة بالمناسبات، ويتحقق من المصدر والإطار والمسار، ويرفض السنوات غير الصالحة والحقول التابعة لمسارات أخرى. أصلح بناء المعاينة كتابة CSS دفعة واحدة ثم استبداله، بعد فشل Windows عند تكرار قطع الملف المفتوح.

## التحقق

نجحت332 حالة في مجموعة المرحلة و24 حالة MySQL، وفحص أنواع التطبيق والمعاينة. نجح بناء المعاينة والبناء الرئيسي في14.02 ثانية؛ ملف الدخول425160 بايت و127085 مضغوطًا. تحذير الحزم الكبيرة السابق باقٍ. لم تتغير مفاتيح ترجمة التطبيق؛ فحص المرحلة368 السابق ناجح، ويختبر التصيير هنا اللغتين. نجحت أيضًا اختبارات حصر وحفظ الخصائص بعد إعادة توليد الحصر:126 مسارًا و447 ملفًا و2583 عنصر تحكم، دون روابط غير صالحة أو ملفات يتيمة.1040 تسمية لم يحلّها التحليل الساكن، وليست إثباتًا لعناصر بلا وصف.

فُحصت المعاينة عبر Chromium بالمقاسات320 و390 و768 و1440، وبنافذة ارتفاع550. القياسات محفوظة في browser-evidence.json؛ لا تجاوز أفقي أو أهداف زر/اختيار أصغر من44 بكسل أو مفاتيح خام في العينات. شريط التمرير يستهلك30 بكسل. إحدى العينات أُخذت أثناء انتقال تغيير الارتفاع؛ القياس المستقر للحوار518 بكسل داخل550 مع تمرير داخلي. تم التحقق من25 سجلًا ثم6، وتبديل التيننت إلى270 والإنجليزية، وعرض تفاصيل العرض والرسالة. نص الرسالة المولّد عربي كما في العامل الفعلي حتى مع واجهة إنجليزية.

في سيناريو الحفظ غير المؤكد تعطلت إعادة التفعيل حتى التحديث، ثم عُرضت الحالة المحفوظة مفعّلة. واجهت أداة الفحص مرتين تسمية مخفية أو متغيرة بعد تبديل اللغة/القائمة؛ أُعيد تحديد العنصر من الحالة الحالية بنجاح. الصورة review-mobile.png توثق نافذة المراجعة العربية. نُقلت ملفات إطار الاختبار المؤقتة إلى .tmp.

## المتابعة والحدود

المرحلة التالية إغلاق المداخل القديمة التي تتجاوز المراجعة، وفحص العامل الخلفي واستمرار الصلاحية وشروط الخصم عند التنفيذ. الحفظ غير المؤكد يستعيد السجل الحالي ولا يقدم إيصالًا تاريخيًا دائمًا. المعاينة ليست محاكاة لكل فشل ممكن في الشبكة أو قاعدة البيانات. لا اختبار Safari/iPhone فعلي، أو اختبار اختراق شامل، أو نتيجة مبيعات مثبتة، أو دفع أو نشر.
