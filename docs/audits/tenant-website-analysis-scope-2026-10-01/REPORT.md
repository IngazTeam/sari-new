# عزل محاولة تحليل الموقع — المرحلة166

2026-10-01، main، محلي فقط. مبدّل المتجر الحالي يعيد تحميل الصفحة؛ لم يثبت الفحص تسريبًا فعليًا في هذا المسار. الفجوة كانت غياب هوية التيننت والمحاولة في عقد التتبع، واستخدام حالة صفحة غير مرتبطة بالنطاق، وإمكان استبدال حالة محاولة أحدث من عامل قديم.

أصبحت صفحة عقل ساري تُركّب بمفتاح الحساب والتيننت المؤكدين من API. ملخص الموقع وطلب التحليل وقراءة الحالة تحمل هوية التيننت، والخادم يطابقها مع صلاحية العضوية قبل القراءة أو التشغيل. يحدد المتصفح UUID قبل إرسال الطلب؛ يرد الخادم بمرجع المحاولة أو مرجع المهمة الجارية. القراءة تحمل المرجع نفسه، وتفصل مفاتيح التخزين المؤقت بين التيننتات والمحاولات. لا تقبل الواجهة ملخصًا قديمًا أو أجنبيًا أو نتيجة بلا هوية مطابقة، وتخفي معلومات التيننت السابق عند إعادة التركيب. صلاحية الإدارة تصل من الخادم وتمنع زر البدء للمشاهد.

تعالج الواجهة النقر المكرر بقفل فوري، والاستجابة المتأخرة بحارس عمر المكوّن وحقبة تسجيل الدخول. فقدان تأكيد البدء يحتفظ بالمرجع ويتيح قراءة الحالة فقط قبل تكرار العملية. تحديث العامل للتقدم/النتيجة/الفشل يتحقق من رقم المحاولة ومن كونها ما تزال جارية؛ العامل المتأخر لا يستبدل حالة محاولة أحدث ولا يعيد إحياء حالة انتهت مهلتها. أضيفت حالة «تعذر تأكيد المحاولة» بالعربية والإنجليزية إلى الشاشة الفعلية والموك أب.

نجحت217 حالة مميزة: عقد الهوية وعزل API والصلاحيات وعدم التكرار، استجابة متأخرة بعد تغيير النطاق أو تسجيل الخروج، استبعاد البيانات المخزنة غير الطازجة، النتائج والحالات والتنقل والإتاحة والحصر. نجحت أنواع التطبيق والموك أب وبناء التطبيق والخادم والموك أب. فحص10908 استدعاءات ترجمة و517 مفتاحًا ديناميكيًا بلا فقد. الحصر126 مسارًا و329 ملفًا و2176 عنصرًا بلا مسارات محذوفة أو روابط غير صالحة.

في التطبيق المحلي قُرئت4 صفحات محفوظة وأمكن فتح مراجعة بدء التحليل ثم إلغاؤها؛ لم يُشغّل تحليل موقع أو LLM. في الموك أب ظهر رفض النتيجة غير المطابقة ثم نجح مسار قراءة الحالة في المثال. الأدلة: [مراجعة القراءة الفعلية](scoped-confirmation-ar.png)، [النتيجة غير المطابقة](unverified-attempt-ar.png).

## حدود باقية

سجل الحالة ما يزال process-local، وليس سجل وظائف دائمًا: إعادة التشغيل وتعدد العمال وفقد الصفحة قد تفقد التتبع. حارس النتيجة يحمي سجل الحالة؛ لا يلغي عمليات مزود أو كتابات معرفة بدأت قبل انتهاء المهلة. ضمان عدم تداخل معالجة المعرفة عبر العمال يحتاج تخزين وظائف وحجزًا دائمين وتنسيقًا عند الحفظ؛ لا يدعي هذا التقرير إنجازه. لا نشر أو ترحيل قاعدة بيانات، ولا اختبار Safari/iPhone فعلي.

التالي: مطابقة واجهة عقل ساري المركزية في الموك أب مع التبويبات ومكونات التطبيق، ثم متابعة سجل التغطية وحدود التتبع الدائم.
