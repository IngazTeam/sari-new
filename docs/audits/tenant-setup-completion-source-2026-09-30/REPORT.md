# اعتماد إعداد التيننت — المصدر الذري

المرحلة 143 — 2026-09-30، محلي على main، دون نشر.

## النتيجة

أضيف عقد مراجعة واعتماد مستقل يحفظ ملف النشاط والمساعد والمنتجات والخدمات وعلامات الإعداد وعداد استخدام القالب والإيصال في معاملة واحدة. هذه المرحلة تختبر المصدر الجديد؛ تحويل API والشاشة من المسار القديم هو المرحلة التالية مباشرة.

- المراجعة قراءة واحدة متسقة، مرتبطة بالحقول المقصودة وملف التاجر والمسودة والمساعد وأسماء الكتالوج وحالة القالب.
- إعادة فحص المالك وحالة الحساب والتيننت داخل المعاملة؛ العضوية الملغاة لا تستعيد صلاحية المالك التاريخية.
- رقم طلب ثابت وإيصال خاص بالتيننت والمستخدم. تكرار الطلب يعيد النتيجة نفسها، وتغيير محتواه بنفس الرقم مرفوض.
- تغير المصدر بعد المراجعة يمنع الاعتماد. الأسماء المتكررة تظهر تعارضًا؛ لا تسقط منتجات أو خدمات بصمت.
- سعر المنتج يحفظ بوحدة minor المؤكدة، والخدمة تحتفظ بمدتها وفئتها. كمية المنتج غير المدخلة تبقى مجهولة. لا يفعّل هذا المسار الرد الآلي.
- رابط الموقع مجرد مرجع للاقتراح الذي راجعه التاجر. لا يغيّر analysis_status ولا يسجل معرفة مستخرجة أو يدّعي اكتمال تحليلها.
- حذف ذاكرة الإجابات وإبطال سياق المحادثات الدائم جزء من المعاملة نفسها.
- يزداد عداد القالب عند الاعتماد مرة واحدة؛ لا يزداد أثناء المعاينة أو إعادة الطلب.

## التحقق

- 54 حالة عقد: أسعار دقيقة وصفر صريح وحدود ومدد وروابط ومنع الحقول غير المسموحة والتكرار المطبّع، مع رجعية الكتالوج والقوالب.
- 26 حالة MySQL بحسابات مؤقتة تنظف بعد كل حالة: نجاح كامل؛ إعادة متزامنة؛ طلبان مختلفان لنفس المراجعة؛ تغير الملف والعملة والمصدر والمسودة والمساعد والكتالوج والقالب؛ عزل التيننت والمستخدم؛ إلغاء العضوية؛ غياب الصفوف وفساد إعداد المساعد؛ تراجع كامل عند فشل الإيصال؛ واستعادة فقدان إقرار COMMIT.
- `tsc --noEmit` ناجح. بناء التطبيق ناجح، وتحذير حجم ExcelJS السابق باقٍ ضمن قياس البناء الحالي.
- الترحيل 0182 أضيف إلى سجل الترحيلات وطبق على sari_pages_test المحلي فقط. سجل تاريخ قاعدة العينة القديمة لم يتقدم.
- لا اتصال بخدمة خارجية ولا اختبار اختراق شامل مزعوم؛ هذه اختبارات تنفيذية للعزل والتلاعب والتزامن ضمن نطاق الإعداد.

## المتابعة

ربط المراجعة والإيصال في API والشاشة، حفظ المسودات بتعارض واستعادة، إعادة البداية بعقد واضح، مراجعة الموقع واختيارات الدمج، ثم مطابقة الموك أب وفحص العرض. تغطية جميع صفحات النظام وفحص Safari/iPhone الفعلي لم يكتمل بعد.
