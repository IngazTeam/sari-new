## التغيير

- فترة 7/30/90 يومًا لجميع الأقسام؛ بداية ونهاية اللقطة وUTC ظاهرة. عدادات الرسائل الواردة والصادرة والمحادثات النشطة وأنواع الرسائل الأربعة.
- ثلاثة تبويبات: الرسائل، التصنيفات المحفوظة، المنتجات والطلبات. جداول كاملة للأيام والساعات بجانب الرسم. أسماء المنتجات كاملة والأسعار الحالية بوحداتها المراجعة.
- تغطية التصنيف وغير المصنف واضحة. ثقة النموذج ليست دقة مثبتة، وارتباط الهاتف بطلب ليس إسناد بيع أو دفعًا؛ احتراف المبيعات غير مقاس بهذه البيانات.
- فصل التحميل والفشل عن الصفر الحقيقي. التصدير مرتبط باللقطة المعروضة، ويُلغى تنزيله إذا تغير المتجر/الفترة/اللقطة أو بدأت إعادة القراءة قبل انتهاء تجهيزه.
- CSV وExcel وPDF تشمل الأقسام الثمانية كاملة. Excel تسع أوراق مع الالتفاف وRTL؛ النص الذي يشبه الصيغ يبقى نصًا. PDF يتضمن خطًا عربيًا محليًا، ورؤوس جداول متكررة وتباينًا واضحًا وترقيم صفحات. لا اتصال بخدمة تصدير خارجية.
- رسائل النجاح تصف تجهيز الملف وطلب تنزيله، ولا تزعم اكتمال حفظه على الجهاز.

## التحقق

- 34 اختبارًا: واجهة وتصدير وبيانات API (tests.json)، بينها تبديل الفترة/التيننت أثناء التصدير، الفشل والتحميل، 90 يومًا كاملة، وثلاث صيغ للملف.
- فحص الترجمة: لا مفاتيح مفقودة ولا استدعاءات ديناميكية غير محسومة ولا أخطاء استيفاء. الإنجليزية هنا كتالوج مرشح؛ التطبيق الحالي يتيح العربية وحدها، ولم نغير بوابة اللغات.
- بناء Vite نجح. ظهر خطأ TypeScript وحيد في تعديلات متزامنة خارج هذه المرحلة: server/db/learning.ts:622 يستخدم spread على Map مع target القديم. خطأ Uint8Array الخاص بالتصدير أُصلح. فحص الأنواع الكامل لا يُعلن ناجحًا قبل زوال الخطأ الخارجي.
- تشغيل محلي محمي على 3018، التيننت «متجر نواة · تيننت الفحص». المسارات الستة نجحت. تبويبات الرسائل والمشاعر والمنتجات تعمل، والفترة 90 تعرض 90 صف يوم و24 صف ساعة.
- المتصفح المتاح IAB: العرض الفعلي 480 و640 و2560 بكسل، بلا تجاوز لعناصر main. طلب 320 أعاد قياسًا مختلفًا، لذلك لا يُسجل نجاح 320 أو390. Chrome لم يكن متصلًا في هذه المرحلة. Safari/iPhone الحقيقي غير مختبر.
- أُنشئ نموذجا PDF من بيانات اختبار صريحة، عربي وإنجليزي، أربع صفحات لكل منهما؛ رُندرت الصفحات الثماني وفُحصت بصريًا بعد آخر تغيير. عينتا output/pdf لا تمثلان بيانات التيننت الفعلي.
- محاولة التقاط تنزيل PDF من المتصفح انتهت بمهلة؛ ملفات PDF المولدة واختبارات Blob/XLSX نجحت، لكن حفظ تنزيل المتصفح على جهاز المستخدم غير مؤكد.
