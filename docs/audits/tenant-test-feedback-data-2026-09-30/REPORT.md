# مصدر سجل التجارب والتقييمات المحفوظة — 2026-09-30

أضيفت واجهات سجل الجلسات ونصوصها وحفظ تقييم الرد إلى الراوتر الفعلي `testSari`. هذه مرحلة المصدر؛ توصيل الشاشة والموك أب يأتيان بعدها، ولا يعني وجود الواجهة أن زر التقييم القديم أصبح يحفظ بالفعل.

- `listSessions`: جلسات التيننت المحدد بترقيم keyset وحد افتراضي 20 وأقصى 50، وتاريخ UTC وعدد الرسائل المحفوظة ووجود علامة اتفاق تجريبي.
- `transcript`: أحدث صفحة رسائل بترتيب زمني ثابت ورابط للرسائل الأقدم، دون قطع صامت. يعيد عدد الرسائل وملخص التقييمات للجلسة كلها والاتفاق المحفوظ. التحقق من الملكية داخل المعاملة قبل قراءة المحتوى.
- `rateReply`: يحتاج إدارة المساعد؛ يربط القرار بالرد والجلسة والتيننت وهوية المراجع ونسخة التقييم ورقم طلب. يحفظ التغيير وإيصاله ذريًا، ويسمح بإلغاء التقييم دون حذف الرد. إعادة الطلب نفسه لا تكرر السجل، والطلب السابق الذي تجاوزه تعديل آخر يعيد الحالة الحالية مع علامة `superseded` دون الكتابة فوقها.
- الرسائل التي أرسلها المستخدم وتنبيهات الحماية ليست قابلة للتقييم. `replySource` هو تصنيف محفوظ أرسله عميل الاختبار، وليس إثباتًا مستقلًا لاستدعاء النموذج؛ الرسائل القديمة بلا تصنيف تظل ظاهرة دون اختلاق مصدر لها.

## قاعدة البيانات والتوافق

الترقية المسجلة **166** تضيف `replySource` و`ratingRevision` وجدول `test_message_feedback`، وتحافظ على التقييمات القديمة. جرى تطبيقها على قاعدة الاختبار المحلية فقط. التحقق عند التشغيل يرفض مخططًا قديمًا قبل الكتابة؛ يجب نشر الخادم والواجهة مع الترقيات بالطريقة المعتادة. لا تغيير لأمر تحديث الخادم المعتمد.

إيصالات التقييم تشير إلى الرسالة؛ تنظيف تيننت الاختبار يزيلها بالتتابع. واجهات القراءة تحتاج `conversations.read`، والكتابة `bot_settings.manage`. الحقول الزائدة ومحاولات فرض هوية المراجع أو التيننت مرفوضة. فشل قاعدة البيانات لا يتحول إلى نجاح وهمي أو سجل فارغ.

## الفحص

نجحت **69 حالة وحدة** للصلاحيات والمدخلات وتجربة المساعد الحالية، و**24 حالة MySQL** للتزامن والتعارض والملكية والترقيم وإعادة فتح المحتوى وتكرار الترقية والمحافظة على المصدر والمقاييس السابقة. أُعيدت حالة ربط الإيصال بعد إضافة التحقق من هوية المراجع، دون احتسابها حالة جديدة. نجح TypeScript وبناء الواجهة والخادم والعامل.

التالي: الواجهة المبسطة، حفظ التقييم بعد إقرار الخادم، مراجعة التعارض، فتح الجلسات القديمة دون فقد المسودة، واستعادة الجلسة للحساب والمتجر نفسيهما، ثم الموك أب. التقييم هنا تقييم صاحب التجربة للرد؛ لا CSAT/NPS أو احتراف مبيعات. لا مزوّد حي أو Safari/iPhone فعلي أو دفع أو نشر، وتغطية المسارات لم تتغير.
