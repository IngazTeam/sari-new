# مطابقة اختبارات انحدار المحادثات

المرحلة 421، 2026-10-03. عولجت14 نتيجة فشل من المجموعة القديمة كانت تبحث عن نصوص SQL والفلاتر في ملفات المسارات الرئيسية رغم نقلها إلى إجراءات ومصادر مشتركة. أُزيل أيضًا فحص ملكية كان يمكنه النجاح بسبب عبارة غير مرتبطة في الملف الكبير. لم تُعد الشيفرة القديمة للتطبيق من أجل إنجاح هذه الاختبارات.

أصبحت اختبارات conversations.test.ts تعمل على المسارين الرئيسي والمستقل، مع إثبات اشتراكهما في إجراءات القائمة والرسائل والتاريخ. تشمل إعادة حل عضوية التيننت المختار رغم سياق مزور، إلغاء العضوية، تزوير معرف التيننت أو المؤشر، إخفاء تفاصيل قاعدة البيانات، وفشل القراءة دون اختراع قائمة فارغة. التحقق من مراحل المبيعات ينفذ عقد API ومحلل روابط الواجهة؛ API يرفض المرحلة غير الصالحة والواجهة تتجاهلها عند تحليل الرابط.

| الحماية السابقة | دليلها الحالي |
| --- | --- |
| روابط المراحل والبحث والحاجة لتدخل بشري | conversation-navigation.test.ts وconversations.test.ts للمسارين |
| عزل الصفوف والإجمالي، البحث الذي يشبه SQL، التصعيد الأجنبي | conversation-inbox.mysql.test.ts |
| حد48ساعة، استبعاد الوقت المستقبلي والخسارة المعروفة | conversation-inbox.mysql.test.ts |
| ترقيم ثابت وقراءة العدد والصفحة من لقطة واحدة | conversation-inbox.mysql.test.ts |
| ملكية المحادثة والمؤشر، الوصول لكل الرسائل القديمة | conversation-history.mysql.test.ts وconversation-history.test.ts |
| فهرسة موقع عقل ساري مع forceAll | website-analysis-indexing.test.ts والعقد الحديث في مجموعة المبيعات |

نجحت321 حالة في مجموعة الانحدار والواجهة والحدود والعقود، و12 حالة MySQL فعلية، وفحص الأنواع. لا تغيير لسلوك التطبيق أو البناء أو الترجمة أو قاعدة بيانات الإنتاج. هذه اختبارات أمنية محلية محددة وليست تقرير اختبار اختراق شامل للنظام أو إثبات صلاحية مزود خارجي.
