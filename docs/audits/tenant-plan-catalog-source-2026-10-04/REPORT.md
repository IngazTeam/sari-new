# المرحلة 487 — مصدر الباقات والمقارنة

أضيف `subscriptionPlans.workspace` كمصدر قراءة لتيننت محدد، بهوية الحساب والتيننت ووقت قاعدة البيانات وصلاحية إدارة منفصلة. العضو يستطيع قراءة الباقات، بينما `canManage` لا يُمنح إلا وفق صلاحية المالك الحية. المصدر يعمل داخل معاملة القراءة المحروسة ويعرض جميع الباقات النشطة بترتيبها المسجل، دون افتراض أن عددها ثلاثة أو الاكتفاء بصفحة أولى.

تُنقل الأسعار المسجلة إلى وحدات صحيحة بدقة منزلتين دون parseFloat أو إكراه قيمة مفقودة إلى صفر. الصفر الصحيح يبقى صفرًا، والسعر السالب أو غير الصالح يبقى مجهولًا. عملتا الاشتراك المدعومتان في مسار الدفع الحالي SAR وUSD؛ القيمة غير المدعومة محفوظة للتفسير لكن لا تمنح سعرًا صالحًا للدفع. هذه قراءة أسعار وليست عرض دفع نهائيًا أو فحص جاهزية المزود.

تظهر حدود جهات الاتصال وواتساب والمحادثات والرسائل والصوت بالقواعد المشتركة للصفر وغير المحدود والمجهول. تبقى الباقة ذات الحقول غير الصالحة في القائمة مع `invalidFields` حتى لا تختفي دون تفسير. تُحفظ النصوص العربية والإنجليزية والمزايا النصية، وتُعلّم المزايا البنيوية غير الصالحة بدل تفسيرها ادعاءات صحيحة. لا توجد نسبة توفير ثابتة في المصدر؛ الواجهة التالية تستطيع حسابها من السعرين الصالحين.

## التحقق

- **101/101** اختبارًا تشمل الأسعار، العملات، البيانات القديمة، المصدر الفارغ، وقت القراءة، صلاحية العضو والتيننت والمدخلات المزورة، وتراجع الاستخدام والإلغاء وبوابة الدفع.
- **14/14 MySQL**: المصدر الجديد ومصدر الاستخدام، مع أسعار دقيقة و32باقة نشطة خاصة بالاختبار وباقة معطلة وحقول غير صالحة، وفصل صلاحية القراءة عن الإدارة وسحب العضوية وغياب نشاط الحساب. نُظفت كل الباقات والمتاجر الخاصة بالاختبار بشروط معرفاتها وأسمائها. فشل أولي كان بسبب استخدام حالة حساب لا يدعمها enum في العينة؛ صُححت إلى deletion_pending وأعيدت الحزمة بنجاح.
- TypeScript كشف أن نشر Set لا يوافق هدف الترجمة الحالي؛ استُبدل بـArray.from دون تغيير المنطق. نجح فحص الأنواع وبناء التطبيق وفحص فروق Git.

هذه مرحلة المصدر فقط. صفحتا الباقات والمقارنة والموك أب ستُربط به في المرحلة التالية. `listPlans` العام ما زال مطلوبًا لواجهات عامة وقديمة ولم يُغلق، ولم تتغير عمليات الاشتراك أو الترقية أو الدفع أو الإلغاء. لا مفاتيح ترجمة جديدة أو ترحيل أو إرسال مزود أو push أو نشر.
