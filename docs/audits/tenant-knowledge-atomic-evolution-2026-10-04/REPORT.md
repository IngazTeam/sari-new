# المرحلة 479 — حفظ نتائج تطور المعرفة كوحدة واحدة

أصبح مسار `evolveKnowledge` و`ingestContent` يجهز قرارات النموذج قبل فتح المعاملة، ثم يحفظ الأقسام والأبناء وسجل التغييرات وذكاء المبيعات وفرص التطوير في معاملة واحدة. فشل أي كتابة أو إقرار يعيد الكتابات السابقة في هذه المعاملة. تشمل المعاملة إبطال الإجابات المحفوظة وسياقات الجلسات، وتستخدم حراسة التنفيذ الحالية للملفات والمواقع.

تُقرأ نسخة محددة من معرفة التيننت قبل قرارات التطوير، وتُقارن تحت القفل قبل الكتابة. تعديل التاجر أو إضافة قسم أو حذفه أو تغيير استخدامه أو مصدره أو دليل نسبته أثناء التحليل يمنع تطبيق الخطة القديمة. نشر embedding وحده لا يبطل خطة النص، لكن تغير النص يبطل embedding القديم. لا توجد مكالمة نموذج تحت قفل قاعدة البيانات، ولا إعادة تلقائية لنتيجة commit مجهولة.

المعرفات المؤقتة داخل الخطة تربط الأبناء بآبائهم الجدد، وتُستبدل بمعرفات الإدراج المثبتة. لا يقبل الكاتب مرجع قسم/أب أجنبي، ويحمي الأقسام المعدلة يدويًا. يتعامل حفظ المبيعات مع الأقسام الجذرية فقط، ويسجل تغييراتها الآن أيضًا. بقي عداد `evolveResult` خاصًا بالأقسام المصنفة كما كان؛ لا يضيف أقسام الإرشادات إلى عداد الأقسام المكتشفة.

## الدليل

- قبل الإصلاح: **10 إخفاقات من11** في اختبارات MySQL. ثبت بقاء حفظ جزئي، واستبدال تعديل حديث، وعدم تسجيل تغييرات المبيعات.
- بعد الإصلاح: **364/364** حالة للمخرجات والأبناء والتسجيل الخاص والعزل والحراس. أثناء التنفيذ التقط TypeScript اسم استيراد تغير خطأ؛ أُصلح ثم أُعيدت الاختبارات.
- **110/110 MySQL**، منها20 حالة جديدة للحفظ الذري، و90 حالة تراجع للإدخال وحراسة المواقع والمبيعات وتحرير الأقسام ومراجعة التعارضات. شملت فشل إقرار الإدراج في مواضع مختلفة، فشل حفظ المبيعات بعد تعديل سابق، التزامن على نسخة واحدة، التيننت الآخر، انتهاء صلاحية الملف والموقع، وإبطال الكاش عند الالتزام فقط. العينات مؤقتة ونُظفت.
- TypeScript وبناء التطبيق ناجحان؛ تحذير حجم بعض حزم البناء بقي كما هو. لا تغيير ترجمة أو واجهة أو ترحيل قاعدة بيانات.

## الحدود والعمل التالي

هذا ضمان لحفظ نتائج هذا المسار، وليس ضمانًا لصحة استنتاج النموذج أو اكتمال معرفة النشاط أو نسبة احتراف المبيعات. استخدمت الاختبارات استجابات نموذج مضبوطة دون مزود مدفوع. الأرشيف، وسجل تنفيذ الموقع، والفهرسة، وإيصال نتيجة العامل خطوات مستقلة؛ فشل لاحق لا يعني التراجع عن نتائج معرفة ملتزمة بالفعل. المصدر المراجع لإضافة الملفات يملك مسار حفظ مستقلًا قائمًا ولم يُستبدل هنا.

يبقى فحص قراءات المعرفة التي قد تعرض قائمة فارغة عند غياب قاعدة البيانات، ثم بقية الصفحات في سجل التغطية. لا ادعاء بفحص Safari/iPhone فعلي في هذه المرحلة، ولا push أو نشر.
