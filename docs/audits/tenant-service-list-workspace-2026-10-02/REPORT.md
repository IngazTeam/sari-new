# المرحلة 264 — قائمة الخدمات الفعلية

استُبدلت قائمة الخدمات القديمة بمساحة متجاوبة تستخدم المصدر المعزول، مع بحث وحالات وصفحات محفوظة بالرابط. تعرض الأعداد الكاملة والنشط والمعطّل والحالة غير المعروفة، والسعر المجاني والنطاق السعري والاتفاق المخصص والمدة ومتطلبات الموعد. بقيت روابط الإضافة والتعديل والتفاصيل والتصنيفات والحزم. أضيف اسم التصنيف من المصدر نفسه مع فحص ملكيته وتوافره؛ لا تُكشف أسماء التصنيفات الأجنبية.

تُعرض الحقول والعلاقات غير الصالحة بوصفها تحتاج مراجعة. فشل القراءة أو اختلاف الحساب أو التيننت أو الفلاتر يخفي البيانات السابقة ولا يتحول إلى نتيجة فارغة. تظهر الإدارة للمصرح لهم فقط. سُمي الإجراء «تعطيل» بدل «حذف» مطابقًا للكتابة اللينة الحالية، مع توضيح بقاء الحجوزات والسجلات وإمكان التفعيل من المحرر.

يرسل التأكيد بصمة النسخة التي عُرضت للتاجر. يمنع تغير النسخة أو الصفحة التأكيد، ولا تظهر استجابة متأخرة في حساب أو عرض آخر. عند فشل الطلب أو غموض نتيجته، يلزم تحديث ناجح لنفس نطاق القراءة قبل إتاحة التعطيل مجددًا. لا تُعرض رسائل SQL الخام.

نجحت 179 حالة معزولة، منها21 تفاعلًا على صفحة React الفعلية، و9 حالات MySQL لمصدر القائمة والعلاقات. نجحت الأنواع بعد إضافة المجموعة الجديدة إلى مخطط الترجمة. نجح فحص مفاتيح الترجمة دون مفاتيح مفقودة أو أخطاء متغيرات، والبناء النهائي. الجرد126مسارًا و362ملفًا و2302عنصر تحكم و314استعلامًا؛ لا مسارات محذوفة أو روابط غير صالحة. لا يمثل الجرد الآلي ضمانًا لتجربة كل عنصر.

جُرب التطبيق فعليًا على خادم التطوير المحلي3025 في تيننت الفحص1. أُنشئت ثلاث خدمات خاصة بهذه المرحلة، ونجح تعطيل930من الواجهة وبقي سجلها ظاهرًا. اختُبرت أسعار0والنطاق100–250والسعر حسب الاتفاق. نُظفت الخدمات930و931و932بعد الاختبار دون المساس بالخدمة السابقة28.

فُحصت إطارات480و390و320بكسل، بعرض محتوى450و360و290بعد شريط التمرير. تساوى عرض المحتوى والتمرير، وأقل ارتفاع للأزرار والحقول44بكسل. حوار320×568 بعرض256وارتفاع360، وحدوده الرأسية103–465، بلا تجاوز أو تمرير داخلي؛ زرا التأكيد والإلغاء44×208. نجح إلغاء الحوار والبحث عن نص غير موجود. أُزيلت صفحة الإطارات قبل البناء النهائي. الفحص Chromium محلي، وليس Safari أو iPhone فعليًا. لم تُستخدم صفحة البناء الإنتاجي علىHTTP لإثبات العرض؛ بقيت فارغة في هذه البيئة، واستُخدم خادم التطوير المعتاد للفحص الحي.
