# تفاصيل الخدمة الفعلية — المرحلة 268

استُبدلت صفحة التفاصيل القديمة بمكونات التصميم الجديد ومصدر اللقطة المتسقة للمرحلة267. تشمل الصفحة تعريف الخدمة والأسعار والمدة والتصنيف والحالة، إحصاءات الحجوزات الست والحالات المجهولة، آخر عشرة حجوزات، توزيع التقييمات، وجميع إعدادات الخدمة ومقدميها. الإعدادات الإضافية قابلة للفتح لتبسيط القراءة، مع تحديث البيانات وروابط التعديل وإدارة الحجوزات.

## دقة العرض وحماية البيانات

- تثبت الواجهة هوية الحساب والتيننت والخدمة واكتمال عقد البيانات؛ لا تعرض نتيجة مخزنة عند فشل القراءة أو اختلاف الهوية.
- السعر حسب الاتفاق لا يتحول إلى صفر. القيم القديمة غير الصالحة تظهر غير متاحة. عدم وجود تقييمات لا يتحول إلى تقييم صفري.
- قيمة الحجوزات المكتملة والمدفوعة موضحة بوصفها مجموع الأسعار المسجلة، وليست تحصيلًا أو تسوية مالية. نسبة الإكمال ليست نسبة تحويل مبيعات.
- التقييمات العامة الصحيحة تعرض مع عدد السجلات المستبعدة؛ العد لسجلات التقييم، وليس عدد العملاء الفريدين.
- تاريخ الموعد لا يتحول بسبب المنطقة الزمنية. آخر الحجوزات مرتبة بتاريخ الموعد ثم المعرّف وقد تشمل مواعيد مستقبلية.
- رابط الحجوزات يفتح الصفحة العامة دون اختراع فلتر غير مدعوم. التعديل مرتبط بصلاحية الإدارة، والمعرّفات غير القانونية مرفوضة.

الأدلة المحلية: `.tmp/tenant-ux/phase268-tests.json` و`phase268-ui.json` و`phase268-translations.json` وسجلات الأنواع والبناء وصورة`phase268-responsive.png`. حُذف مضيف الإطارات المؤقت قبل البناء. اختبارات MySQL الخاصة بالمصدر موثقة في المرحلة267؛ لا تغيير للخادم في هذه المرحلة.

## الحدود والتالي

الفحص المرئي Chromium محلي؛ لا Safari فعلي أو جهاز iPhone أو نشر أو اختبار اختراق شامل. اللغة الفعلية المعلنة بالعربية؛ الإنجليزية اختُبرت في React. مفاتيح الترجمة القديمة محفوظة للتوافق، والواجهة القديمة أزيلت من التنفيذ. التالي ربط المسارات الست للخدمات والتصنيفات والباقات بالمكونات الفعلية في الموك أب، ثم متابعة بقية سجل الصفحات.
