# المرحلة 341 — ربط Calendly وفصله بالمراجعة

2026-10-02، main. طلبات المزوّد محاكاة محلية فقط؛ لا رفع أو نشر.

## التنفيذ

أضيفت معاينة للحساب تقرأ الهوية عبر API دون تسجيل اشتراك أو حفظ اعتماد، وتعيد بصمة الربط وأعداد النسخ المحلية وما إذا كان الحساب سيتغير. أمر الربط يثبت الهوية التي راجعها المستخدم؛ تغيرها لدى المزوّد يمنع POST. استبدال الحساب يحتاج موافقة صريحة على حذف النسخ المحلية، والفصل يحتاج clearLocalCopies صريحًا بسبب علاقات cascade الموجودة.

تستخدم أوامر الربط والفحص والفصل سجل0192؛ تكرار الطلب لا يعيد الشبكة. يتكرر فحص الصلاحية ونسخة الربط والمحاولة قبل الشبكة وبعد الرد وبعد قراءة الجسم، وداخل الحفظ. النجاح محفوظ مع اعتماد الربط المشفر أو حذفه في معاملة واحدة. الانقطاع بعد commit لا يحذف الاشتراك الجديد ولا يخفض نجاحًا مثبتًا.

فحص الحساب يثبت صلاحية API والهوية فقط؛ لا يدعي فحص توصيل webhook. الفصل يفصل إثبات الحذف المحلي عن تنظيف التسجيل البعيد، الذي قد يكون غير مؤكد. يمكن معالجة اعتماد قديم تالف مع بيان عدم تأكد تنظيفه. إعادة الربط توقف خيار تأكيد واتساب تلقائيًا للمراجعة، وتحافظ على المواعيد وإعدادات JSON الأخرى عند بقاء الحساب نفسه.

نُقل قفل الربط المشترك إلى وحدة واحدة؛ تُتلف الجلسة إذا تعذر تأكيد امتلاك القفل أو تحريره، فلا يعاد اتصال يحتمل احتفاظه بقفل مسمى إلى المسبح. يحجب حارس الطلب الرد ويُلغي جسمه غير المقروء إذا تغيرت الصلاحية أو المراجعة أثناء الشبكة. عنوان الاستقبال يرفض البروتوكولات غير HTTP/HTTPS ومعطيات URL والاعتماد المضمّن.

## التحقق

232 اختبارًا معزولًا و53 اختبار MySQL ناجحة بلا فشل مجموعات؛ فحص الأنواع والبناء ناجحان. تشمل الحالات القبول المتزامن، تغير الهوية، استبدال الحساب، السجل المحلي، تنظيف404أو503، سحب الصلاحية أثناء الشبكة، فشل حفظ النتيجة، فقد تأكيد commit، الاعتماد التالف، وتجديد أو انتهاء مراجعة الطلب. عُدّل محاكي fetch ليستقبل كائن URL كما يمرره العميل الفعلي، ثم أعيدت المجموعة كاملة.

## الحدود والتالي

المداخل الجديدة متاحة للخادم، والواجهة القديمة لم تُرحل بعد. تبقى كتابات connect/disconnect القديمة حتى النقل النهائي؛ لا يُدّعى إغلاقها في هذه المرحلة. التالي المزامنة الذرية وفحص التحديثات والإشعارات الخلفية عند تغيير الربط، ثم الواجهة والموك أب والإغلاق القديم. قد يبقى اشتراك بعيد بلا ربط محلي إذا فشل التنفيذ بعد إنشائه؛ النتيجة غير محسومة وتحتاج مراجعة، دون حذف تعويضي أعمى. لا Safari/iPhone فعلي.
