# واجهة مراجعة الكلمات — 2026-09-29

أضيفت نافذة «مراجعة سجل الكلمة» إلى بطاقات الكلمات في المسارات المشتركة للرؤى. تعتمد على عقد القراءة والكتابة المحمي في [المرحلة السابقة](../tenant-keyword-review-2026-09-29/REPORT.md).

## ما ينفذه التاجر

يفتح سجلًا لقراءة النص المقترح كاملًا وأمثلة الرسائل والتصنيف والتكرار والتواريخ والحالة. تُفسر حالة المراجعة كعلامة تنظيم فقط، ولا يُعرض حفظها كإنشاء رد أو تفعيله. يظهر السجل للمشاهد، وتظهر الكتابات وفق صلاحية إدارة المساعد.

يحفظ التاجر تغيير الحالة باستخدام النسخة التي قرأها. الإغلاق مع اختيار مختلف يعرض متابعة المراجعة أو تجاهله صراحةً. أثناء القراءة البطيئة يمكن إغلاق النافذة؛ أثناء الكتابة تُقفل الأزرار لمنع التكرار. إغلاق النافذة أو تغيير نطاق المتجر يلغي تأثير نتيجة قراءة متأخرة على العرض.

عند التعارض يبقى اختيار التاجر، ويتوقف الحفظ والحذف حتى قراءة النسخة الحالية بنجاح. تُعرض النسختان كاملتين، ويطلب اختيار الحالة عند اختلاف تعديل الطرفين. اعتماد النسخة الجديدة لا يكتب شيئًا، ويتبعه حفظ مستقل. فشل القراءة لا يعتمد القيمة المخزنة، وفقدان السجل لا يعيد إنشاءه، وتُحدَّث الصلاحية من النسخة الحالية.

الحذف له مراجعة للأثر وصندوق تأكيد مستقل؛ يُصفّر التأكيد بعد الفشل أو مراجعة نسخة أحدث. يوضح أن حذف سجل التحليل لا يحذف ردودًا سريعة أو محادثات، وأن الكلمة قد تظهر من رسائل جديدة. الأمثلة القديمة التي ليست JSON صالحًا تظهر نصًا قابلًا للمراجعة ولا تُفقد أو تنفذ كـHTML.

## الفحص

- نجحت **92 حالة** للنافذة والرؤى وعقود الكلمات والقراءة، مع نجاح فحص TypeScript الكامل وبناء الإنتاج. انتهى فحص 8948 استدعاء ترجمة و410 مفاتيح ديناميكية دون مفاتيح مفقودة أو أخطاء إحلال.
- فُحص التطبيق المحلي المحمي على Chrome عند 320 و390 بكسل. عرض محتوى النافذة/عرض التمرير 271/271 و341/341 دون تجاوز أفقي، مع تمرير داخلي وأزرار ثابتة في الأسفل.
- حفظ حي لحالة سجل الفحص، وتنبيه الإغلاق دون حفظ، وتعارض حقيقي بين تبويبين، وقراءة النسخة الحالية واختيار الحالة ثم الحفظ المنفصل. أُعيد سجل «فحص الرؤى · الشحن» إلى «جديد» وتاريخ مراجعة فارغ. لم تُغير النصوص أو التكرار.
- جُربت مراجعة الحذف وصندوق التأكيد ثم أُلغي الحذف؛ لم يُحذف السجل الحي. الحذف الفعلي وعزل المتاجر والتزامن مختبرة ببيانات MySQL المؤقتة في المرحلة السابقة.
- اختبارات الواجهة تغطي فقدان الصلاحية والسجل، ونتيجة متجر/معرف مختلف، وفشل إعادة القراءة، ومنع الحفظ المكرر، ونتائج القراءة بعد إغلاق النافذة، والنصوص غير الآمنة والقديمة.
