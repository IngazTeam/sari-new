# المرحلة 111 — قراءة ملف المخزون الصادر دون فقد العملة أو الكمية

أضيفت قراءة السعر بصيغة «12.34 USD» أو «12.34 SAR» إلى محلل الملفات وGoogle Sheets المشترك. تُعرض الخلية الأصلية كما هي في الدليل، ويُراجع السعر الرقمي والعملة في الحقول. إذا وُجد عمود عملة صريح مخالف للّاحقة يُرفض الصف؛ لا يُتجاوز التعارض. تبقى القيم غير الدقيقة والمعادلات والسعر الفارغ ممنوعة. أضيف العنوان «الكمية المتاحة» إلى الربط التلقائي حتى لا تتحول كمية الملف الصادر إلى قيمة مجهولة عند إعادة القراءة.

تُصحح هذه المرحلة قيد إعادة قراءة السعر المذكور في تقرير110. نجحت143 حالة للمحلل وخطط الاستيراد، منها17 لتوافق ملف التصدير. أُعيد بناء الموك أب بالمحلل نفسه ونجحت166 حالة رجعية له، وأنواع التطبيق والموك أب وبناء التطبيق والخادم والعامل. لا كتابة منتجات أو اتصال Google أو ترحيل قاعدة بيانات في هذه المرحلة. بعد ذلك تحسين استعادة محاولة التصدير غير المؤكدة ثم الموك أب وشاشات الربط وبقية الحصر.
