# المرحلة323: بنية إيصالات عمليات WooCommerce الدائمة

أضيف الترحيل0191 لجدول `woocommerce_operations` وعقود النتيجة. يحفظ الجدول هوية الحساب والتيننت والطلب ونوعه وبصمة المراجعة وبصمة المحتوى ومعرّف محاولة داخليًا. لا يحفظ المفاتيح أو الرسائل أو بيانات اتصال العملاء. النتائج مقيدة بعقود للربط والمزامنة وتحديث الطلب وقبول الإشعار.

الحجز مقفل على التيننت ويعيد التحقق من العضوية والحساب والصلاحية. التكرار المطابق يعيد الإيصال ولا يمنح محاولة تنفيذ أخرى، حتى بعد فقدان تأكيدcommit. تغيير المحتوى أو المراجعة أو الحساب لنفس المعرف يُرفض. توجد عملية حية واحدة للتيننت، وحد6عمليات تكامل و30عملية طلب خلال5دقائق، مع استمرار استعادة الطلب نفسه.

يُثبت بدء التنفيذ قبل الأثر؛ إذا انتهت مهلة120ثانية دون بدء فالحالة «مرفوض»، وإذا بدأ التنفيذ فالنتيجة «غير محسومة». نقطة التحقق تجدد المهلة وتمنع العمل المتأخر أو ذي محاولة مختلفة. لا يبدأ الطلب مرتين. تُكتب النتيجة الناجحة في معاملة التغيير المحلي نفسها؛ فشل المعاملة يتراجع معها، وفقدان تأكيدcommit بعد نجاحه يسمح باسترجاع النجاح دون تخفيضه.

تمنع النتيجة غير المحسومة قبول طلب جديد حتى مراجعتها صراحة. المراجعة لا تعيد تنفيذ الطلب. يستطيع زميل مخول مراجعة العملية إذا فقد صاحبها الأصلي الصلاحية؛ يحمل الرد هوية المراجع منفصلة عن صاحب العملية. تبقى استعادة الإيصال الخاص مقيدة بالحساب والتيننت.

## التحقق

-110اختبارات معزولة للعقود، النتائج المتعارضة، عدم كشف تفاصيل التخزين، فشلcommitوrollback، تسجيل الترحيل ومصادر البيانات السابقة.
-39اختبارMySQL، منها16للسجل الدائم: ازدواج متزامن، حظر عملية أخرى، تغير الطلب، عزل الحساب، صلاحيات الأدوار، انتهاء المهلة، مراجعة مدير آخر، التراجع الذري، فقدان تأكيد حجز الطلب ونتيجته، وعدم تجاوز الحدود بالعمليات القديمة.
-نجحTypeScript والبناء13.21ثانية. طُبق0191على قاعدة الاختبار المحلية وحدها، دون تغيير سجل ترحيلها التجريبي أو بيانات التيننت السابقة.

الأدلة `.tmp/tenant-ux/phase323-{tests,mysql,migration}.json` و`phase323-{types,build}.log`. صُححت بيانات اختبار حقلenumوتسمية متغير في الاختبار، ونوع معاملاتSQL فيTypeScript، ثم أُعيدت الفحوص بنجاح.

هذه بنية داخلية لم تُوصل بعد بإجراءات WooCommerce الحالية أو واجهتها. لا تدعي حماية الأزرار القديمة بالإيصالات الجديدة. التالي ربط المراجعة والمهلة والحفظ الذري بالأفعال الفعلية، ثم استبدال الصفحات الأربع والموك أب. الحجز وحده لا يرسل إلى أي مزود. لا نشر ولاSafari/iPhoneفعلي.
