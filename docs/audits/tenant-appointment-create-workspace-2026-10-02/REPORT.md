# إنشاء الموعد واستعادة نتيجة الطلب — المرحلة 284

استُكمل نموذج إنشاء الموعد داخل التقويم الفعلي: خدمة ومقدم اختياري، وقت وبيانات العميل، مراجعة واضحة قبل الحفظ، واقتراح أوقات من المصدر المعزول. تُحسب النهاية من مدة الخدمة، وتظهر أخطاء الخانات بجانبها. الاقتراح لا يحجز الوقت؛ يُفحص التعارض عند الحفظ.

## حماية النتيجة

- يُحفظ معرّف طلب عشوائي فقط في sessionStorage، مقيدًا بالحساب والتيننت، قبل الإرسال. لا تُخزن بيانات العميل هناك.
- لا يظهر النجاح حتى تُقرأ نتيجة الطلب مجددًا وتطابق الحساب والتيننت ومعرّف الموعد. حالة مزامنة Google مستقلة عن تسجيل الموعد.
- عند الغموض يتوقف التحرير والإرسال التلقائي، ويستطيع المستخدم فحص النتيجة. إعادة المحاولة داخل النموذج تستخدم الطلب والمدخلات نفسيهما. إعادة التحميل تستعيد فحص الطلب دون إعادة إنشائه.
- تُرفض نتائج التوفر أو الإيصالات المخالفة للنطاق، ويتوقف حفظ الطلب عند تعذر التخزين، وتُهمل النتائج بعد مغادرة الشاشة أو تبديل الهوية.
- حوار مغادرة النموذج يحمي العودة الداخلية؛ تنقلات الغلاف الرئيسية لا تزال خارج حارس المسودة، بينما يبقى معرّف الطلب المرسل قابلًا للاستعادة.

## التحقق

- نجحت 199 حالة معزولة، ثم 258 حالة بعد إصلاح الهاتف، تشمل النموذج الحقيقي والتنقل والتوفر ونطاق الإيصالات والحجوزات وحارس مساحة العرض.
- نجح TypeScript والبناء خلال 14.30 ثانية. حزمة البداية 424176 بايت، و126795 مضغوطة. فحص الترجمة: 12188 استدعاء و880 مفتاحًا ديناميكيًا، بلا أخطاء.
- أُنشئ الموعد المحلي 1665 للتيننت 1 بالخدمة 28، ثم استُعيد من رابط الطلب بعد إعادة التحميل وفتحت تفاصيله دون نسخة إضافية. حالة المزامنة محلية فقط. تحقق تنظيف قاعدة الاختبار من الإيصال الوحيد والموعد وخصائص بيانات الاختبار قبل حذفهما؛ لا تغيير لخدمة الاختبار الأصلية.
- فحص 12 حالة عرض عربية: النموذج وأخطاء الحقول والمراجعة عند 480/390/320، بالإضافة إلى رجوع نموذج الحجز عند المقاسات نفسها. المحتوى بلا تمدد أفقي، الحقول 16px والأزرار 44px، وحوار المراجعة بارتفاع 536 داخل شاشة 568.
- كشف الضغط الفعلي أن شريط التنقل السفلي يغطي زر المراجعة. أُصلح شريط الحفظ المشترك للحجز والموعد ليرتفع فوق التنقل، مع إزاحة مستقلة عند ظهور لوحة المفاتيح. التحقق بعد الإصلاح: نهاية الشريط y=494، وبداية التنقل y=506، والضغط يظهر أخطاء النموذج بدل الانتقال إلى المحادثات.

الأدلة المحلية في `.tmp/tenant-ux/phase284-tests-reviewed.json` و`phase284-responsive.json` و`phase284-created-final.png` و`phase284-cleanup.json`. أُزيلت صفحة قياس الإطارات المؤقتة.

## الحدود والمتابعة

الاختبار المحلي في متصفح Chromium عبر إطارات ذات عرض CSS محدد؛ ليس اختبار Safari أو iPhone فعليًا. الإنجليزية مغطاة باختبارات الترجمة والوحدات، وفحصها البصري يأتي مع الموك أب. لم يحدث تفويض Google أو إرسال خارجي أو نشر. المرحلة التالية: توصيل شاشات التقويم وإعداداته والإنشاء بالمحاكاة التفاعلية الفعلية، ثم متابعة بقية سجل الصفحات والخصائص.
