# المرحلة 480 — فصل تعذر قراءة المعرفة عن الفراغ الحقيقي

لم تعد قراءة الأقسام أو سجل التغييرات تعيد قائمة فارغة عند فشل المصدر. تشمل حدود معالجة الخطأ قراءة هوية المتجر أيضًا، وتعيد رسالة ثابتة دون SQL أو محتوى المصدر أو stack. بقي رفض التيننت المفقود والصلاحيات المسحوبة منفصلًا، وتبقى القائمة الفارغة نتيجة صحيحة فقط عند نجاح الاستعلام وعدم وجود سجلات.

توقفت مساعدات قراءة القسم المفرد والمقترحات والسجل والتعارضات غير المحسومة عن إرجاع null/[] عند غياب الاتصال. استُبدل SELECT * بقائمة حقول محددة في قراءتي السجل، وصار حد السجل عددًا صحيحًا في العقد والمساعد بدل السماح بكسر عشري أو قيمة غير محدودة داخل SQL.

## التحقق

- ثبت **10 إخفاقات من33** قبل الإصلاح: خطأان أعادا فراغًا، وثلاثة أخطاء هوية بلا معالجة ثابتة، وحد كسري، وأربع قراءات دون اتصال.
- نجحت **254/254** حالة بعد الإصلاح، تشمل37 حالة جديدة للمسارات والمساعدات، وفحوص الأقسام والتعارضات والإدخال والعزل.
- نجحت **42/42 MySQL**: ثلاث حالات قراءة جديدة لفراغ حقيقي وعزل المقترحات والقسم والسجل والتعارضات، مع39 حالة تراجع لحفظ المعرفة وتطورها وإرشادات المبيعات. نُظفت العينات.
- TypeScript وبناء التطبيق ناجحان. لا تغيير واجهة أو مفاتيح ترجمة أو ترحيل قاعدة بيانات، ولا مكالمة مزود خارجي أو نشر.

هذه المرحلة تخص مداخل القراءة المذكورة. لا تدعي التحقق من كل مؤشر قديم أو من صحة المعرفة. يبقى استكمال صفحتي الاستخدام ثم بقية الصفحات الـ20 ذات الموك أب العام، و47 ذات التغطية الجزئية، وفق سجل التغطية الحالي. لا اكتمال100% أو اختبار Safari/iPhone فعلي.
