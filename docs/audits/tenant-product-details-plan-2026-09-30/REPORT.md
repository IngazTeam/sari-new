# قواعد خيارات ومتغيرات المنتجات — 2026-09-30

فُحصت جداول الخيارات والمتغيرات ومداخلها القديمة ومستهلكوها. لا توجد شاشة عميل حالية تستدعيCRUD المتغيرات أو إدارة الخيارات. أسعار المتغيرات ومخزونها وتكلفتها تُستخدم فعليًا في عرض البيع ومراجعة الهامش؛ لا تُعامل هذه الحقول كزينة تصميمية.

أضيف عقد لقطة معزولة للمستخدم والتيننت والمنتج، وستة أنواع تغييرات للمراجعة مع بصمة وUUID وموافقة وإيصال. القراءة محدودة500 سجل لكل نوع؛ إنشاء الخيارات حتى20 و100 قيمة للخيار، والمتغيرات حتى500. لا توليد تلقائي لضرب جميع الخيارات ولا تغيير قاعدة بيانات في هذه المرحلة.

تشمل القواعد الاسم والاسم الإنجليزي وقيم الخيار وترتيبه، وجميع حقول المتغير الحالية: الاسم وSKU والأسعار والكمية والباركود والوزن والصورة والاختيارات والتفعيل والترتيب. تُمنع الأسماء والقيم وSKU والتركيبات المتكررة والمدخلات خارج الحدود؛ تبقى الكمية المجهولة والتكلفة المفقودة منفصلتين عن الصفر. السعرnull يرث سعر المنتج؛ التكلفةnull لا ترث تكلفته.

اختيارات المتغير الجديدة تربط بمعرّف الخيار وقيمته. تُقرأ الصيغة القديمة التي تربط اسم الخيار بقيمة فقط عندما تكون الهوية غير ملتبسة والقيمة موجودة. البيانات غير المقروءة لا تُمسح ولا تتحول إلى مصفوفة فارغة؛ يمنع تعديل بنية الخيار أو حذفه عند عدم إمكانية إثبات سلامة المراجع. يظل تعديل الحقول المستقلة ممكنًا، مع إصلاح الاختيارات لاحقًا بمراجعة صريحة.
