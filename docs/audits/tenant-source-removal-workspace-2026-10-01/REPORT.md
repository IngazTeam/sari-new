# واجهة مراجعة حذف المعرفة — المرحلة158

التاريخ2026-10-01، main، محلي فقط.

استُبدلت تأكيدات الحذف وإعادة الضبط القديمة بنافذة واحدة تعرض اسم المتجر ونطاق المجموعة وأعداد المصادر والأقسام والعلاقات المتأثرة. تتطلب تأكيد الاسم وموافقة صريحة جديدة. فتح المراجعة لا يحذف شيئًا. أصبح الوصول لإعادة الضبط ممكنًا عند وجود أقسام يدوية فقط، بدل الاعتماد على عدد مجموعات المصادر القديمة.

يحفظ التبويب مرجع العملية وملخص المراجعة المعزول للمستخدم والتيننت؛ لا يحفظ نص المعرفة أو يستعيد الموافقة. عند فقد الرد يمكن قراءة الإيصال أو استئناف الطلب نفسه بعد تأكيد جديد، مع منع الطلبات المتكررة والنتائج المتأخرة بعد تبديل الحساب. تُعرض أخطاء القراءة والتعارض والتخزين والصلاحيات دون تفاصيل الخادم. جميع مسارات الحذف الثلاثة القديمة تعيد PRECONDITION_FAILED بدل تنفيذ حذف غير مراجع.

الموك أب يستخدم مكوّن التطبيق نفسه في knowledge-removal.html مع عشر حالات وخمس مجموعات وبالعربية والإنجليزية، دون خادم أو حذف معرفة فعلية. البيانات المخزنة فيه توضيحية فقط.

## سجل التحقق

-288 حالة لعقد الحذف والواجهة وتقاعد المسارات والصلاحيات وحصر الخصائص نجحت (156+132).
-27 حالة MySQL نجحت، منها الاستخدام الفعلي لمسارات المراجعة والتنفيذ والإيصال بصلاحية مدير، وتراجع المعاملة واستعادة فقد الرد.
-نجح TypeScript للتطبيق والموك أب والبناء وحد الحزمة. فحص10780 استدعاء ترجمة و515 مفتاحًا ديناميكيًا بلا نقص أو مفاتيح غير محسومة أو أخطاء interpolation. كُشفت ست عبارات ديناميكية في البداية وحُولت إلى خريطة استدعاءات ثابتة قابلة للتحقق.
-حصر126 مسارًا و325 ملفًا و2175 عنصر تحكم؛ لا مسار محذوف أو رابط غير صالح أو صفحة يتيمة. أُصلح انتقال فحص وظيفة الحذف الموصولة من الإعدادات إلى المسار الجديد بدل المرجع المتقاعد، مع بقاء خط الأساس دون تعديل.751 تحذير تسمية و124 استعلامًا بلا إشارة خطأ مكتشفة آليًا في الحصر العام ليست شهادة اجتياز لبقية النظام.
-المتصفح الفعلي عرض مراجعة التيننت:29 ملفًا و10 منتجات و3 تحليلات و4 صفحات و3 أسئلة و18 قسمًا. مراجعة الملفات وحدها شملت29 ملفًا و8 أقسام. أُغلقت المراجعات دون كتابة أو حذف.
-في الموك أب نجحت الموافقة الناقصة برسالة حقل، ومحاكاة فقد الرد ثم استعادة إيصال بالمراجع نفسها. فحص الإنجليزية بعرض480×844 أظهر نافذة ضمن الحدود (418px) دون تجاوز أفقي، ووصلت الحقول وأزرار التحقق بالتمرير. عولج تداخل زر الإغلاق مع العنوان العربي.
-صور الأدلة: live-review-ar.png وrecovered-receipt-ar.png وmobile-validation-en.png. أُعيد viewport إلى الافتراضي. فحص التطبيق المتصل جرى بعرض2560؛ إعداد العرض الضيق في أداة المتصفح طُبق على تبويب الموك أب فقط، ولذلك لا يُنسب هذا القياس للتبويب المتصل.

## حدود الاستعادة

مرجع المتصفح خاص بالتبويب ويُمسح عند تسجيل الخروج. يبقى الإيصال في قاعدة البيانات مرتبطًا بمستخدمه. إغلاق النافذة لا يلغي عملية أُرسلت، وعدم وجود إيصال عند القراءة لا يثبت فشل طلب ما زال جاريًا. إعادة الاستئناف تستخدم نفس المعرّف ونفس المراجعة وتحتاج موافقة جديدة. لا نشر ولا اختبار Safari أو iPhone فعلي.
