# المرحلة 98: خطة تغييرات منتجات Google Sheets

أضيفت خطة نقية قابلة للمراجعة لكل صف: إضافة، تحديث، دون تغيير، أو منع مع سبب. تعتمد لقطة القارئ المشتركة، وتحفظ القيم الحالية والمقترحة والحقول المتأثرة وبصمة المصدر والمنتج والخطة. لم يُربط اعتماد قاعدة البيانات أو الشاشة بعد؛ المرحلة التالية تنفذهما تباعًا.

- أوضاع مستقلة: إضافة فقط، مطابقة SKU، أو مطابقة الاسم باختيار صريح. المطابقة تخفض حالة الأحرف وتزيل المسافات الطرفية فقط؛ لا تفترض مساواة لهجات أو علامات أو ترتيب كلمات.
- منع تعدد المطابقات، وتوجيه صفين إلى المنتج نفسه أو المفتاح الجديد نفسه، وتصادم SKU بما فيه المنتجات الخارجية، وغياب SKU عند اختياره، والأسعار/الصفوف غير الصالحة.
- التحديث يغيّر الأعمدة المربوطة فقط. لا تمسح القيم الافتراضية الوصف أو المخزون أو النوع أو الحالة أو الفئة المرتبطة عند غياب أعمدتها. الفراغ الصريح في عمود قابل للإفراغ يبقى تغييرًا معلنًا.
- منع تحويل العملة الضمني، والمنتج الذي تديره منصة أخرى، والحقول الحالية غير الصالحة، وتغيير اسم فئة يخالف فئة مرتبطة. تنسيقات السعر المتساوية مثل 12.34 و12.3400 لا تظهر كتغيير.
- فهرس محدود إلى 20 ألف منتج، مع تحديد المرشحين أولًا دون تحميل جميع الأوصاف. يمنع تكرار هوية المنتج وتناقض بيانات الفهرس مع حقوله.

## التحقق

نجحت 93 حالة: 31 للخطة، و30 للقارئ، و19 للمزود، و13 لحدود API. شملت عدم تغيير المدخلات، ثبات البصمة وتغيرها مع النسخة، أرقام الصفوف الفعلية، الأعمدة الغائبة، العملات والفئات والتصادمات. نجح TypeScript بعد إصلاح تكرار Map ليتوافق مع إعداد المشروع.

لا كتابة منتجات، ولا اتصال فعلي بـGoogle، ولا تغيير واجهة في هذه المرحلة؛ لذلك ليست دليلًا على اعتماد ذري أو توافق Safari/iPhone. لم تتغير أعداد تغطية الصفحات. المسار القديم باقٍ حتى ربط البديل واختباره ثم إغلاقه. كوميت محلي على main؛ لا رفع ولا نشر.
