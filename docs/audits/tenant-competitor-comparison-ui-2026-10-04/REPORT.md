# المرحلة 442 — مقارنة التقارير في التطبيق والموك أب

التاريخ: 2026-10-04. الفرع: main. فحص محلي فقط.

أُضيفت مقارنة تقرير الموقع مع حتى خمسة منافسين إلى شاشة المنافسين بمكونات التطبيق نفسها في الموك أب. اختيار تقرير الموقع ينقل إلى المنافسين، وتبقى الاختيارات أثناء البحث والتنقل بين الصفحات. تُطوى أدوات الاختيار بعد ظهور النتيجة ويمكن فتحها لتعديلها. أُضيف بحث وصفحات 25 وحد اختيار خمسة وعناوين مؤرخة وفروق المقاييس الخمسة وأسعار كل عملة مع عدد الأسعار غير المؤكدة.

تُحجب النتيجة المخالفة للحساب أو المتجر أو الاختيار أو المصحوبة بخطأ. المقارنة قراءة للتقديرات المحفوظة، ولا تشغّل النموذج ولا تعطي نسبة مبيعات أو تدعي مطابقة المنتجات. التوصيات المولدة حديثًا تبقى بندًا منفصلًا لم يُنجز بعد.

## التحقق

- 99 حالة ناجحة في المجموعة النهائية: الموك أب الفعلي باللغتين، حد الخمسة وصفحات الاختيار، الحجب عند الحساب والمتجر والاختيار المخالف أو الخطأ، عقد المقارنة، عزل التنسيق والمسارات واستعادة الطلبات. مجموعة واجهة سابقة متداخلة: 50 حالة ناجحة. فشل أولي واحد كان افتراض شكل الأرقام العربية؛ صُحح ليتبع Intl الفعلي ونجحت الحالة.
- TypeScript والبناء النهائي ناجحان. فحص 13,531 استدعاء ترجمة و854 مفتاحًا ديناميكيًا: صفر مفتاح مفقود أو خطأ interpolation.
- فحص متصفح Chromium بالموك أب العربي والإنجليزي، وبالتطبيق المحلي العربي: 320 و390 و768 و1440 CSS px. أُصلح تجاوز عرض 320، وحد ارتفاع قائمة الاختيار لتسهيل الوصول إلى زر النتيجة. لم يبق تمرير أفقي للصفحة أو النافذة في المقاسات المقاسة، بما فيها تفاصيل الأسعار المفتوحة في التطبيق.
- بيانات محلية مؤقتة: تقرير موقع ومنافس وستة منتجات. ظهرت 75 مقابل 85 بفارق -10، وفُصل SAR عن USD، وأُظهر سعر غير مؤكد لكل تقرير. حُذفت فقط هذه السجلات المملوكة للاختبار وملفا صفحة QA بعد الفحص.
- [صورة التطبيق المحلي بعرض 390](mobile-ar.png). الفحص بالمقاسات ليس Safari أو iPhone فعليًا.
- الحصر المحدث: 126 مسارًا، 476 ملفًا، 2703 عناصر تفاعل، 1500 شرط عرض، دون مسارات محذوفة. بقيت 59 قراءة لا يثبت الحصر الساكن إشارة خطئها؛ الحصر لا يعني اكتمال UX أو كل الاختبارات.

## المتبقي

مراجعة اتساق بيانات المقارنة الداخلية، ثم توليد توصيات جديدة بتفويض واضح ومراجعة مسار تقارير الموقع المنفصل، وبقية البنود في REMAINING. لا اختبار مزود خارجي أو اختراق شامل أو نشر في هذه المرحلة.
