# المرحلة 380 — واجهة العروض الجديدة

استُبدلت شاشة العروض القديمة بمكتبة كاملة: البحث والفلاتر والصفحات، حالات النشاط والجدولة والانتهاء، والتفاصيل المحفوظة دون إسقاط القيم الصفرية أو الشروط. أزيل معدل التحويل الافتراضي؛ تُعرض المبيعات بوصفها غير مثبتة، والعدادات القديمة بدلالتها الفعلية.

النموذج يضم العنوان والوصف والنوع والقيمة، مع خيارات النطاق والمواعيد والبانر. يُظهر الأخطاء بجانب حقولها وينقل التركيز لأول خطأ، ويقبل الأرقام العربية، ويحفظ توقيت الرياض دون تغيير المواعيد التي لم يعدّلها التاجر. الإنشاء والتعديل والتفعيل والإيقاف والحذف تمر بالمراجعة. تعرض التفاصيل أثر القرار على الكود المرتبط وتوضح أنه يبقى مستقلًا.

عند نتيجة غير مؤكدة يُحفظ معرّف الطلب في جلسة المتصفح مع عزل المستخدم والتيننت. يمكن استعادة الإيصال دون إعادة الكتابة؛ تتوقف الكتابة الجديدة حتى تتأكد النتيجة. إذا لم يوجد إيصال، تبقى حالة الطلب معلقة؛ تحسين حسم الغياب دون خطر إنشاء نسخة مؤجلة مطلوب في المرحلة التالية. اختيار أهداف العرض بالأرقام موجود، وتبسيطه باختيار الأسماء مطلوب أيضًا.

نجحت 138 حالة وحدة وواجهة وصلاحيات دون فشل أو تخطي، وفحص TypeScript والترجمة (13148 استدعاء و854 مفتاحًا ديناميكيًا بلا مفاتيح مفقودة). نجح البناء النهائي في17.59ثانية ضمن الميزانية. قاعدة MySQL أُعيد تشغيلها بعد توقف البيئة دون إعادة تهيئة البيانات.

فُحص الإنشاء بقيمة عربية، والتعديل من15إلى20، والإيقاف والتفاصيل في المتصفح المحلي بحساب الفحص17071/متجر17070؛ ثم نُظف العرض التجريبي325 وإيصالاته فقط. قياسات إطار الصفحة الفعلية320و390و768و1440 بلا تجاوز أفقي، ونافذة518بكسل داخل ارتفاع550بعد استقرار تحديث الارتفاع. قياسات الأداة المباشرة كانت مضاعفة ومقيدة، لذلك اعتمد التقرير قياسات CSS داخل الإطار. أُزيل ملف إطار الاختبار من المسار العام قبل البناء النهائي.

دليل الصور والقياسات بجانب التقرير. العربية فُحصت في المتصفح، والإنجليزية باختبارات المكونات؛ التطبيق الحالي يعلن العربية فقط. لم يحدث فحص Safari/iPhone فعلي أو نشر. التالي حسم الطلب غير المحفوظ، تبسيط اختيار الأهداف، الموك أب، إغلاق المداخل القديمة وتصحيح استخدام العروض في عقل ساري.
