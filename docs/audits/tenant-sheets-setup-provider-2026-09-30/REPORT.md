# المرحلة 116 — إنشاء أوراق Sheets وعناوينها بطلب واحد

أضيف محول داخلي يجهز أوراق الطلبات والعملاء المحتملين والمحادثات والمخزون وعناوينها الحرفية في طلب إنشاء واحد، بمعرّفات ثابتة للأوراق واسم ملف يحتوي معرّف المحاولة. استند بناء الطلب إلى [spreadsheets.create](https://developers.google.com/workspace/sheets/api/reference/rest/v4/spreadsheets/create) ومخطط [Sheet وGridData](https://developers.google.com/workspace/sheets/api/reference/rest/v4/spreadsheets/sheets) الرسميين؛ لم يختبر على Google الحقيقي.

يُعاد فحص المصدر قبل وبعد إعداد OAuth في الذاكرة، ثم يُطلب من المستدعي حفظ تصريح الإرسال قبل خروج طلب الإنشاء. لا إعادة تلقائية للطلب أو تحويلات شبكة، بمهلة20 ثانية وحد رد128KiB. لا يصبح الرد إيصالًا إلا بعد مطابقة عنوان الملف والأوراق الأربع ومعرّفاتها وأنواعها والعناوين والمواضع والقيم الحرفية. الرد المفقود أو الناقص يظل غير مؤكد، مع الاحتفاظ بمعرّف الملف إذا كان صالحًا للمراجعة لاحقًا.

نجحت24 حالة تغطي طلب الإنشاء الواحد وحدود الشبكة والحجم ورد OAuth والحواجز وتلف الأدلة وفقد الرد، ونجح فحص أنواع المشروع. لم تتغير مسارات التطبيق في هذه المرحلة؛ المحول غير مربوط بعد. التالي حفظ محاولة إنشاء دائمة واستعادتها وربط المصدر والراوتر، ثم تحويل الشاشة والموك أب وإغلاق منشئ الجدول القديم. لا اتصال Google أو نشر أو ادعاء إتمام إعداد خارجي.
