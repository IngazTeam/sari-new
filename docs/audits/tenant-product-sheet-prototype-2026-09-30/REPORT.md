# المرحلة101 — موك أب Google Sheets المطابق

اكتمل ربط شاشة `ProductSheetWorkspace` الفعلية بالموك أب في `/merchant/products/upload`، مع قارئ الخلايا وخطة المطابقة الفعليين وبيانات محلية مستقلة. لا اتصال بـGoogle ولا كتابة خارجية ولا تغيير بالمعرفة. لا نشر.

| السطح | التغطية |
| --- | --- |
| الاتصال | جاهز/غير مربوط/تعطيل التفويض/منصة مرتبطة/تحميل/فشل/دون اتصال/صلاحية/جلسة/تيننت خاطئ |
| اختيار المصدر | تحميل صريح، ورقتان وهوية مستقرة، ورقة مخفية ونطاق محدود معلن، قائمة فارغة أو من ربط آخر |
| المراجعة |25 صفًا،20 بالصفحة، أربعة أنواع إجراءات، ثلاث طرق مطابقة، ربط الأعمدة والقيم الافتراضية، قيم أصلية وحالي/جديد |
| سلامة المطابقة |SKU مكرر، غموض، منتج خارجي، سعر تاريخي غير مثبت، اختلاف العملة، سعر مفقود وصفر حقيقي |
| الاعتماد | موافقة على اللقطة، تغيير الربط أو الخيارات يبطلها، اعتماد كامل أو رفض، إيصال واحد لكل طلب |
| الاستعادة | فقد رد القراءة/الاعتماد، طلب لم يصل، تعذر قراءة الإيصال أو إيصال خاطئ، مراجعة مفقودة/منتهية، الرجوع بعد التنقل |
| العرض | عربية/إنجليزية، نصوص طويلة، أسعار بعملتها، مؤشر فتح وإغلاق الصف، RTL/LTR |

29 حالة Sheets مستقلة عن22 حالة الملفات و12 حالة نصائح الملف. المطابقة بـSKU في المثال الأساسي تنتج23 إضافة وتحديثًا واحدًا وصفًا دون تغيير. إعادة الطلب تعيد الإيصال نفسه دون زيادة العدادات. الوضع الافتراضي إضافة فقط يمنعSKU الموجود ولا يحوّله إلى تحديث ضمني.

أصلح فحص التكامل شرطًا زائدًا لمعالجة الورقة الفارغة، وربط وضع النطاق المحدود فعليًا ببيانات الورقة. كشف الفحص البصري أن سعر التحديث لا يذكر العملة؛ أصبح السعر الحالي والجديد يعرضان العملة في التطبيق والموك أب، وأضيف سهم واضح لتفاصيل الصف.

## التحقق

-132 اختبارًا ناجحًا:46 نموذجSheets و49 نموذج/واجهة الملفات المشتركة و17 مساعدة الملف و20 واجهةSheets. تشمل اختبارات الحزمة المبنية عدم إجراء أي `fetch`، الإيصال بعد التنقل، إخفاء البيانات عند فقد الصلاحية وفشل القراءة، إبطال الموافقة عند تغيير الربط، وعدم إعادة القراءة عند استعادة طلب التجهيز.
- TypeScript للتطبيق والموك أب ناجح، وبناء التطبيق والخادم والعامل والموك أب ناجح. حزمة البداية337710 بايت خام/103449gzip ضمن الميزانية. يبقى تحذير حزمةExcelJS الكبير المعروف.
- في IAB: اختيار SKU، مراجعة23/1/1، فقد رد الاعتماد واستعادة الإيصال مع بقاء23/1؛ اختيار الورقة المخفية يكشفA1:BH5001 وحد5001صفًا/60عمودًا؛ الإنجليزيةLTR بلا مفاتيح ترجمة ظاهرة. لا تجاوز أفقي لعناصرSheets عند `innerWidth=480` وارتفاع860؛ `documentElement.scrollWidth=450`.
- [لقطة العرض](review-480.png) يظهر بها خلل دمج/مساحات فارغة من التقاطIAB؛ ليست إثباتًا مرئيًا كاملًا لتخطيط المتصفح. قياساتDOM وفحص العناصر منفصلان عنها.320/390 وSafari/iPhone الحقيقي لم تثبت هنا.

حالة المحاكاة في الذاكرة؛ إعادة تحميل الصفحة تعيد المثال وتمسح مرجعSheets المحلي. البصمات تجريبية وليست شهادة أمان أو حفظ خادم. الحالة الفعلية للخادم وصلاحياته ومعاملاته موثقة بمراحل97–100؛ هذه المرحلة لا تثبت OAuth أو Google الحقيقي.

التغطية العامة ثابتة:126 مسارًا،77 عامًا و32جزئيًا و9تفصيلية و8تحويلات. التالي إغلاق مسارSheets القديم بعد تدقيق المستهلكين، ثم الفئات والخيارات والمتغيرات وبقية السجل. لا ادعاء اكتمال100%.
