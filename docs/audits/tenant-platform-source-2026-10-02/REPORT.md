# مصدر صفحة التكاملات — المرحلة 286

كشف الفحص أن المصدر القديم يبتلع أخطاء التخزين ويعيد عدم وجود ربط، ويستبعد سلة وبيان أثناء التعثر أو المزامنة، وتعرض الصفحة أول منصة فقط. كانت صلاحيات مسارات إدارة التكاملات تعتمد تسجيل الدخول وحده، وأعداد المنتجات تأتي من قائمة محدودة بينما يتحول فشل عد الجمهور إلى صفر.

## الإصلاح

- لقطة قراءة متسقة ومعزولة للتيننت تعرض سلة وزد وووكومرس وشوبيفاي وبيان، مع الحالة المحفوظة ووقت المزامنة والروابط الموجودة والتعارض بينها. لا ادعاء بفحص الاتصال الحي.
- لا اختيار أو فك تشفير لأسرار الاتصال. روابط العرض تقبل HTTP/HTTPS فقط وتحذف الاستعلام والجزء المرجعي وترفض بيانات الدخول المضمنة.
- حالات الفشل والتوقف وانتظار إثبات الملكية تحتفظ بمكان المنصة. فشل أي مصدر يمنع اعتبار المنصة غير مربوطة أو السماح بالربط على أساس معلومات ناقصة. نسخة زد المعطلة في المصدر الأساسي تمنع إحياء بياناتها القديمة.
- عد كامل للكتالوج المرئي ولملفات العملاء، أو المتدربين النشطين عند استخدام بيان، داخل اللقطة نفسها. لا صفر بديل عن فشل القراءة.
- تقييد مسارات القراءة والربط واختبار الاتصال الستة بصلاحية `integrations.manage` وهوية العضوية والتيننت المختار من الخادم، وإخفاء أخطاء المصدر الخام. نتيجة طلب ربط بيان تقتصر على النجاح أو انتظار التحقق والنطاق، دون تفاصيل الاتصال السرية.

## التحقق

نجحت 93 حالة معزولة: عزل الحساب والتيننت، صلاحيات المالك والمدير، رفض العضوية الملغاة والأدوار الأخرى، التحقق من البيانات والروابط، حالات التخزين، تعارض المنصات، مصدر الجمهور وحدود الثقة. نجحت 26 حالة MySQL عبر مجموعتي مصدر التكاملات وسلطة زد؛ أُعيدت حالات المصدر العشر بعد تصحيح بيانات الاختبار. شملت 503 ملفات عملاء و502 متدربًا نشطًا وعزل متجر آخر والعضوية المختارة وإلغائها. نُظفت بيانات الاختبار تلقائيًا.

نجح TypeScript والبناء خلال 17.62 ثانية، وحزمة البداية 424176 بايت و126795 مضغوطة. الأدلة المحلية: `.tmp/tenant-ux/phase286-tests.json` و`phase286-mysql.json` و`phase286-mysql-final.json` و`phase286-types.log` و`phase286-build.log`.

## المتابعة

المصدر جاهز، والصفحة القديمة لم تُستبدل في هذه المرحلة. التالي واجهة التكاملات الفعلية ثم موك أبها وصفحات إدارة المنصات المتبقية، ومنها إصلاح مسار فصل بيان القديم. فحص وجود المنصات قبل الربط لا يمثل قفلًا ذريًا بين جميع مزودي الربط؛ يبقى توحيد قبول الربط المتزامن بندًا مستقلًا. لا تغيير في مخطط البيانات أو ربط خارجي أو إرسال أو نشر.
