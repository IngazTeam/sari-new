# حماية مراجعة سجلات الكلمات — 2026-09-29

وحّدت هذه المرحلة واجهات الكلمات المكررة في `routers.ts` و`routers-keywords.ts` بعقد واحد. لم تكن المشكلة ثبوت تسريب عبر اختيار أول متجر؛ الدالة القديمة تراعي متجر الطلب للمالك، لكنها لا تستخدم صلاحيات أعضاء الفريق ولا تحمي نسخة المراجعة.

## التغيير

- القراءة بصلاحية `analytics.read` ضمن العضوية والمتجر المختار. الكتابة بصلاحية `bot_settings.manage`، فلا يستطيع المشاهد أو مشرف المبيعات تغيير الحالة أو الحذف.
- تصفية صارمة وحد أقصى 100 سجل للطلب، وترقيم مستقر بالتكرار ثم المعرف، والتحقق من المعرفات الصحيحة والحدود وعدم قبول معرف متجر داخل المدخلات.
- قراءة تفاصيل سجل بالمتجر والمعرف مع نسخة محتوى تشمل نص الكلمة والاقتراح وأمثلة الرسائل والتكرار والحالة والتواريخ. تُعرض التواريخ بصيغة UTC صريحة.
- تعديل الحالة والحذف يفحصان النسخة بعد قفل السجل داخل معاملة MySQL، وكل قراءة وكتابة مقيدة بالمتجر والمعرف معًا. تغير الملاحظات أو الاقتراح يستلزم مراجعة جديدة. الحذف يتطلب أيضًا `reviewed: true`.
- إرجاع الحالة إلى «جديد» يمسح تاريخ المراجعة السابق. تعليم سجل بأنه «أنشئ رد» علامة يدوية فقط؛ لا ينشئ أو يفعل ردًا سريعًا ولا يدل على بيع.
- `getSuggested` يعيد الاقتراحات المحفوظة غير الفارغة، دون استدعاء LLM عند تحديث الصفحة. الثقة `null`، والمصدر `saved_unverified_suggestion`؛ لا تُختلق نسبة جودة. توليد اقتراح جديد بمصادره لم يُنفذ في هذه المرحلة.
- غياب قاعدة البيانات أو فشلها خطأ صريح برسالة عامة، لا قائمة فارغة أو نجاح زائف. السجل المفقود أو الأجنبي يُرجع `NOT_FOUND`.

## التحقق

نجحت **67 حالة وحدة وصلاحيات** و**10 حالات MySQL**، تشمل اختبارات الرؤى السابقة، وفحص TypeScript الكامل وبناء الإنتاج. الأدلة في `tests.json` و`mysql-tests.json`. استخدمت اختبارات MySQL متجرين مؤقتين في قاعدة الاختبار المحلية وأزيلت بياناتهما؛ لم يُستدع مزود أو تُرسل رسالة. لم تتغير مفاتيح الترجمة، ولا يلزم ترحيل قاعدة بيانات.

اختُبر تغيير الاقتراح/العداد بعد المراجعة، وكتابتان متزامنتان نجحت إحداهما ورفضت الأخرى بتعارض، وإعادة الحذف دون نجاح زائف، وعزل سجل أجنبي حتى مع معرفة نسخته الصحيحة، وتصفية النصوص المحفوظة والترقيم.

## المرحلة التالية والحدود

إضافة نافذة مراجعة الكلمات إلى واجهة الرؤى والموك أب، مع النص الكامل وأمثلة الرسائل والحالة ومراجعة التعارض والحذف. حتى تنفيذها لا تُحتسب خاصية إدارة الكلمات مكتملة في الواجهة. واجهات التقارير الأسبوعية القديمة والتوليد وصلاحية المصادر وجمع الكلمات من الرسائل تحتاج مراحل منفصلة. تبقى دوال قاعدة البيانات القديمة للاستخدامات الداخلية ولم تُعد واجهة الراوتر تستعمل كتاباتها غير المرتبطة بالنسخة. لا يتغير عداد تغطية المسارات، ولم يحدث دفع أو نشر.
