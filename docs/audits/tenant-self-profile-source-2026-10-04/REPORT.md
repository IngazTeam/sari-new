# المرحلة458 — مصدر الحساب الشخصي وتعديل الاسم

أضيف مصدر محدود باسم المستخدم وبريده وحالة توثيقه وبصمة النسخة. القراءة للمستخدم المسجل نفسه ولا تعتمد على محدد التيننت. لا كلمة مرور أو صلاحية أو حقول حساسة إضافية في الاستجابة. الاسم والبريد غير الصالحين يظهران غير معروفين؛ لا ادعاء توثيق بريد غائب أو دليل غير صالح.

تعديل الاسم يأخذ اسمًا من2إلى120حرفًا بعد التشذيب وبصمة النسخة فقط. تقفل المعاملة سجل المستخدم وتراجع نشاط الحساب، وتمنع الاسم القديم من الكتابة فوق تعديل آخر. يتحقق المصدر من الاسم المخزن قبل إقرار النجاح، ويعامل رد commit المفقود كمجهول. لا يغير البريد أو توثيقه أو الدور أو كلمة المرور.

التحقق:45حالة وحدة وتراجع،25MySQL تشمل راوتر التطبيق مع محدد متجر أجنبي لا يؤثر في الحساب الشخصي، والتزامن وطلب حذف الحساب والحقول المحقونة وحالة التوثيق. الأنواع والبناء ناجحان.

التالي: وصل نموذج الحساب ونموذج المتجر الجديدين بصفحة إعدادات مبسطة مع الروابط والإرسال المنضبط للتحقق وإعادة الويزرد، ثم الموك أب وإغلاق مساري الحفظ القديمين. auth.updateProfile القديم ما زال قائمًا حتى نقل الصفحة؛ لم نرسل بريدًا حقيقيًا أو نغيّر حساب المستخدم الحقيقي، ولا نشر.
