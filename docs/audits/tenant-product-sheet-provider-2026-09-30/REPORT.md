# قراءة مزود Sheets المحدودة — المرحلة 96

أضيف محول داخلي للقراءة فقط من نطاق sheets.googleapis.com الثابت، بمعرّف مصنف مضبوط وقناع حقول محدد. قراءة قائمة الأوراق لا تجلب الخلايا؛ قراءة الورقة تستخدم النطاق المحدود من المرحلة95 وقيمها الأصلية والفعالة. لا يقبل رابطًا حرًا، ولا يتبع التحويلات، ولا يكتب منتجات أو Google Sheet أو المعرفة.

تُراجع دالة assertCurrent التي يقدمها المستهلك قبل OAuth وقبل إرسال طلب البيانات وبعد قراءتها. طبقة صلاحية التيننت وربط هذه الدالة بقاعدة البيانات لم تُنجز في هذه المرحلة؛ لا توجد API عامة تستخدم المحول بعد. نجاح اختبار الدالة المحقونة لا يثبت عزل التيننت وحده.

تجديد OAuth داخل الذاكرة لا يعيد حفظ بيانات اعتماد قديمة فوق اتصال جُدد. مدته20 ثانية وطلب البيانات20 ثانية؛ يُلغى عند المهلة. فُحص مصدر مكتبة OAuth المثبتة لأن إعدادات الطلب الخاصة بها تعيد تفعيل المحاولة رغم إعداد المنشئ؛ أضيف اعتراض للطلب يعطلها ويحدد مهلة ثابتة ويمنع التحويل. يقرأ المحول جسم الرد تدريجيًا حتى8 ميجابايت ويحرر القارئ عند الفشل. لا تمرر أخطاء OAuth أو HTTP الخام إلى المستهلك.

## التحقق

نجحت49 حالة للمزود ولقطة المصدر: وجهة ثابتة، GET واحد، قناع الحقول، الهويات والنطاق، أخطاء401/403/404/429/500، توقف فحص المصدر في مراحله الثلاث، رمز مفقود، محارف ترويسة غير مسموحة، JSON/UTF8 تالف، طول معلن زائد وتدفق زائد. نجح TypeScript. الشبكة وOAuth مزيفان بالكامل؛ لا تجديد فعلي أو وصول لملفات Google أو رسوم. لا تغيير واجهة يستلزم إعادة بنائها في هذه المرحلة.

لا نشر. التالي مصدر اتصال من قاعدة البيانات وفحص العضوية والربط قبل/بعد القراءة، ثم حفظ المراجعة وخطة الإضافة/التحديث والاعتماد الذري والشاشة والموك أب وإغلاق المزامنة القديمة. لم تتغير أعداد التغطية.
