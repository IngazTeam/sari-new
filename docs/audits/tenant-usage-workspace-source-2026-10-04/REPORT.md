# المرحلة 482 — مصدر صريح للاستخدام والموارد

أُضيف usage.workspace بعقد مشترك ومصدر قراءة متسق، مع إعادة التحقق من حساب الممثل ومالك المتجر وحالة التيننت والعضوية داخل المعاملة. يعيد هوية الحساب والتيننت ووقت القراءة. لا يرسل أرقام العملاء أو أسرار اتصال واتساب، ولا يستدعي فك أسرار الاتصال لمجرد عد الأرقام.

يفصل المصدر ثلاثة أنواع من الأدلة:

- عدادات الاشتراك المخزنة: المحادثات والرسائل والصوت، مع حد الباقة الأساسية أو حدود التجربة المعلنة، وآخر إعادة ضبط المسجلة.
- الموارد الحالية: أرقام الاتصال المميزة في المحادثات وعملاء زد النشطين، وأرقام واتساب المسجلة، والمنتجات الظاهرة وفق قواعد الكتالوج. عد المنتجات COUNT(*) كامل وليس طول قائمة من500. حدود الموارد المعروضة تخص الباقة الأساسية؛ ليست حسابًا للإضافات أو قرارًا بتفويض عملية جديدة.
- النشاط المسجل: الحملات المنشأة والرسائل الصادرة المحفوظة، في الشهر الحالي وستة أشهر UTC حتى وقت القراءة. الصادر يشمل ما حفظه النظام ولا يثبت أنه مولّد بالذكاء الاصطناعي أو وصل للعميل أو أدى إلى بيع.

الحد المجهول ليس صفرًا أو غير محدود. الصفر محفوظ كما هو، والاستهلاك المتجاوز يبقى عددًا حقيقيًا مع حصر شريط النسبة عند100. تطابق العقد بين النسبة والباقي والحد إلزامي، وكذلك اتساق الأشهر والمجموع الحالي ووقت القطع. التكرار في الاشتراكات النشطة يظهر ambiguous بدل اختيار سجل بصمت. انتهاء التجربة يظهر كتقييم قراءة دون تعديل الحالة المخزنة أو تصفير العدادات.

## التحقق

نجحت69حالة وحدة للعقد والفترات والعزل، و15MySQL للمصدر الجديد وعضوية الاستخدام، مع TypeScript وبناء التطبيق. تشمل العينة501منتج، وتيننتًا آخر، وحدًا صفريًا وغير محدود ومفقود، واشتراك تجربة بلا باقة، واشتراكين نشطين، ورسائل واردة وصادرة ومستقبلية، وسحب العضوية وحسابًا غير نشط. العينات مؤقتة ونُظفت.

## الحدود والخطوة التالية

هذا مصدر جديد؛ صفحتا الاستخدام القديمتان لم تُنقلا إليه في هذه المرحلة، ومداخل العدادات القديمة لم تُغلق بعد. التالي مكوّن مشترك للصفحتين والموك أب، مع إظهار تعريف كل رقم وحالات التعذر والفراغ والتعارض، وفحص الهاتف واللغتين. لا ترحيل قاعدة بيانات أو تغيير ترجمة هنا، ولا Safari/iPhone فعلي أو مزود خارجي أو push أو نشر.
