# تحمل بيانات المنافسين القديمة وفشل تحميلها

المرحلة 432 بتاريخ 2026-10-03. صُحح عرض المنافسين حتى لا يؤدي رابط قديم غير صالح أو حقل رقمي مشوّه إلى تعطيل الصفحة، وحتى لا يظهر فشل تحميل القائمة كأن التاجر لم يضف منافسين.

## سلوك الصفحة

تعرض القراءة الفاشلة رسالة مترجمة وزر إعادة المحاولة، وتخفي البيانات المخزنة مؤقتًا عند الخطأ. تفشل دالتا قراءة المنافسين بوضوح إذا غاب اتصال قاعدة البيانات بدل إعادة قائمة فارغة أو نتيجة غير موجودة. تتحدث القائمة كل خمس ثوان ما دامت تتضمن تقريرًا معلقًا أو جاريًا، ويتوقف هذا التحديث عندما تكون النتائج نهائية.

لا تعرض البطاقة رابطًا غير HTTP أو HTTPS، أو رابطًا ببيانات دخول. يحافظ العرض على البطاقة مع شرح أن الرابط غير متاح. تبقى الدرجة الصفرية الرقمية صالحة كتقدير موقع، أما القيم الغائبة وغير العددية وخارج نطاق 0 إلى 100 فلا تتحول إلى صفر ولا يظهر لها شريط تقدم. تمنع القيم المشوهة في التاريخ والملاحظات والأسعار من كسر العرض. تختفي ملخصات الأسعار المتناقضة، ولا يُفسّر الصفر القديم على أنه منتج مجاني لأن الاستخراج القديم يستخدمه أيضًا للسعر الغائب.

أصبح النص يوضح أن درجات الموقع لا تقيس احتراف المبيعات، وأن العدد والأسعار ملخص سابق لا يثبت الأسعار الحالية أو تطابق العملات. تظهر التواريخ حسب لغة الواجهة بدل فرض العربية على الإنجليزية.

## التحقق

نجحت 81 حالة عرض وواجهة ومسارات وتراجع، وحالتان لانقطاع التخزين، وفحص الأنواع وبناء التطبيق. تحقق فحص الترجمة من 13465 استخدامًا و854 مفتاحًا ديناميكيًا دون فقد أو أخطاء استبدال.

فُحص التطبيق المحلي ببطاقة تاريخية تتضمن رابط JavaScript ودرجة 145 وأسعارًا غير صالحة وملاحظات JSON ليست قوائم. بقيت الصفحة عاملة، ولم يظهر رابط قابل للتنفيذ أو محتوى الخطأ الخام أو NaN. أزيل السجلان المصطنعان بعد الفحص. الصورة history-ar.png دليل العرض الفعلي؛ لا تدعي اختبار Safari أو iPhone.

## المتابعة

هذا تصحيح لقراءة البطاقات القائمة، وليس اكتمال مصدر المنافسين أو موك أبه. يلزم مصدر كامل بصفحات وفلاتر وتفاصيل المنتجات وفصل العملات وأدلة الأعداد، ثم واجهة مراجعة وحذف آمنة وموك أب تفاعلي مطابق. تبقى حماية تنفيذ الخلفية بعد إعادة تشغيل الخادم مفتوحة. لا ترحيل بيانات أو اتصال بمزود أو نشر.
