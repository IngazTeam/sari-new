# المرحلة457 — مصدر ملف المتجر المراجع

أضيف مصدر محدود لاسم النشاط والهاتف والرد الآلي والمنطقة الزمنية ورابط الشعار. يُحوَّل الهاتف غير المحدد إلى حقل فارغ واضح، ويحفظ false الفعلي للرد الآلي؛ القيم القديمة غير المعروفة تُعلّم للمراجعة ولا تستبدل بقيم افتراضية. تُرفض مفاتيح التكامل والعملة ومعرّفات الملكية ضمن مدخل الحفظ.

لا يقرأ غير المالك حقول الملف أو بصمته؛ تعود حالة canView=false دون قيم. يبقى المالك في متجر pending قارئًا فقط. نُقل فحص حساب المستخدم والمالك وعضوية المتجر إلى معاملة مشتركة مع العملة، مع أقفال وفحص حي وتدمير اتصال commit مجهول النتيجة. يحفظ الملف بخمسة حقول كاملة وبصمة النسخة، ويقرأها قبل إقرار النجاح. لا تعديل للعملة أو ملفات التيننت الآخر.

التحقق: 64 حالة وحدة/واجهة وتراجع، و35 حالة MySQL تشمل مساري الملف والعملات الفعليين، وتزامن الحفظ والحجب لثلاثة أدوار والتعليق والإلغاء والبيانات القديمة. الأنواع وبناء التطبيق ناجحان.

الحدود: الشاشة القديمة ما زالت تستخدم مسار الملف العام. يجب نقلها ثم إغلاق الكتابة القديمة؛ لا ادعاء بأن جميع كتابات ملف المتجر أصبحت مراجعة. البصمة للقيم الحالية وليست سجل تاريخ كامل، ولا يوجد إيصال طلب دائم هنا. حساب المستخدم الشخصي والتحقق من البريد وإعادة الويزرد مسارات منفصلة في صفحة الحساب وتحتاج تغطيتها عند نقل الصفحة. لا نشر.
