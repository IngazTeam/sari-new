# المرحلة 62 — صفحة الطلبات والمراجعة

استُبدلت صفحة الطلبات القديمة بمساحة عربية وإنجليزية تربط مصدر المرحلة 59 ومراجعة الحالة وإيصالات المرحلة 61. التنفيذ محلي على main؛ لا دفع أو نشر أو إرسال خارجي.

## ما نُفذ

| المساحة | المطابقة والسلوك |
| --- | --- |
| القائمة | بحث حرفي، فلتر الحالة والدفع، 25 طلبًا في الصفحة، ملخص ضمن الفلاتر وعملات منفصلة، حالات تحميل وفشل وصلاحية وفراغ |
| التفاصيل | بيانات العميل والعنوان والتتبع والملاحظات والهدايا والبنود والنص القديم؛ لا تخمين لوحدة أسعار البنود التاريخية |
| تغيير الحالة | مراجعة أحدث نسخة، سبب إلغاء مطلوب وخطأ عند الخانة، رقم تتبع للشحن والتسليم، معاينة الإشعار والمستلم وموافقة صريحة |
| المسودة | عزل المستخدم والتيننت، حفظ لمدة 24 ساعة، استبعاد صريح، حماية المغادرة ومسح عند الخروج |
| الاستعادة | الاحتفاظ بمحاولة غير مؤكدة بلا انتهاء؛ طلب الإيصال أو تكرار UUID والمدخلات نفسها، وعدم إسقاط المسودة عند التعارض |
| السجل | إيصالات مرقمة مع السبب والتتبع ووقت الحفظ؛ وصف واضح أنه لا يشمل جميع أحداث الدفع والمنصات القديمة |
| الفاتورة والدفع | الاحتفاظ بمكونات اعتماد الفاتورة والهامش وتفصيل الخصم ومحاولات الدفع وتحرير الخصم ومراجعات سلة وزد؛ تحديث الصفحة بعد الإجراءات |

أُغلقت نقطتا orders.cancel وorders.updateStatus القديمتان، وأثبت فحص HTTP رجوع 404 لهما. الكتابة اليدوية لا تضع الطلب في حالة paid، ولا تعيد الحالات النهائية، ولا تعدل طلب منصة خارجي. حالة الدفع مستقلة، ولا تُعرض قيمة الطلبات كإيراد مسوى أو نسبة احتراف مبيعات.

## التحقق

- tests.json: نجحت 239 حالة معزولة للحدود والصلاحيات والعقود والواجهة؛ page-tests.json: 20 رحلة واجهة أولية.
- final-tests.json: نجحت 189 حالة بعد الإصلاحات الأخيرة، تشمل 132 لحصر وحفظ الخصائص، و20 رحلة واجهة و6 حالات تخزين. المجموعات متداخلة ولا تجمع حسابيًا مع الجولة السابقة.
- mysql-tests.json: نجحت 42 حالة على قاعدة sari_pages_test المحلية، تشمل HTTP والمراجعة والكتابة والإيصال وعزل التيننت والواجهات المتقاعدة.
- TypeScript بلا أخطاء؛ الترجمة 9546 استدعاء و441 مفتاحًا ديناميكيًا، بلا مفاتيح ناقصة أو أخطاء متغيرات؛ بناء الإنتاج نجح، مدخل الواجهة gzip 103408 بايت.
- الحصر الحالي: 126 مسارًا، 281 ملفًا، 1947 عنصرًا، 295 قراءة hook و22 قراءة برمجية و4 طلبات متصفح؛ لا مسارات محذوفة أو ملفات يتيمة. إشارات 137 قراءة بلا معالجة مباشرة و743 تسمية غير محلولة تحتاج مراجعاتها، وليست ادعاء غياب فعلي.

## التجربة الحية

على التيننت المحلي «متجر نواة · تيننت الفحص» عُرضت 10 طلبات اصطناعية. فتح UX-1046 أثبت عرض البنود القديمة والملاحظات. الإلغاء دون سبب أظهر خطأ ونقل التركيز للخانة. بعد إدخال سبب فحص ومراجعة صريحة حُفظ الإلغاء دون إشعار، وظهر الإيصال والسجل وبقيت الملاحظات الأصلية، وتغير ملخص غير الملغى من 1800 إلى 1605 ريال. لقطة local-cancellation-receipt.png التُقطت قبل تحسين صيغة رسالة الإيصال إلى الماضي.

عند العرض الفعلي 480×860 كان clientWidth=scrollWidth=450 للقائمة والمراجعة، وعرض النموذج 422 داخل الصفحة. لقطة list-480.png وstatus-review-480.png توثقان النتيجة؛ أداة IAB تضيف فراغًا إلى الصورة خارج الجزء المرئي. جُربت مراجعة UX-1041 ثم استبعاد مسودتها دون كتابة. أُعيد الحجم المكتبي بعد الفحص.

## ما لم يُثبت بعد

لم يجر إرسال إشعار أو دفع أو مصالحة مع مزود حقيقي. لم تختبر هذه الجولة Safari/iPhone الحقيقي ولا عرضي 320/390. لا تزال قراءات API القديمة تحتاج توحيدًا، والموك أب التفصيلي للطلبات هو المرحلة التالية بعد ذلك. لا تتغير التغطية قبل مطابقته: 83 عامًا، 26 جزئيًا، 9 تفصيلية، و8 تحويلات. ترحيل 171 مطلوب للخادم عند النشر؛ تطبيقه المحلي فقط موثق في المرحلة 61.
