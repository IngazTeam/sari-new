# المرحلة 528 — عزل التقارير المجدولة

تم تثبيت وجهة Google Sheets التي فُحصت قبل توليد التقرير، بحيث يرفض المولد الوجهة المختلفة قبل كتابة التقرير. أصبحت أخطاء التاجر معزولة عن بقية التجار، وحُجبت تفاصيل أخطاء المزود من سجلات هذه المهمة. أضيف منع تداخل تشغيل المهمة نفسها داخل عملية السيرفر، مع تحرير الحارس حتى بعد فشل جلب التجار.

## التحقق

- 76 اختبارًا ناجحًا في حدود مراجعة الجدولة وتسليم التقارير والعمليات المحددة وإلغاء مداخل المزامنة القديمة.
- اختبار استمرار التاجر التالي بعد فشل السابق، وعدم تسجيل رمز مزود حساس.
- اختبار تداخل التشغيل واستعادة الحارس بعد الفشل.
- فحص TypeScript دون أخطاء.

## الفجوات المتبقية

الحارس محلي للعملية، وليس سجل إيصالات دائمًا؛ لا يمنع التكرار بين عدة عمليات سيرفر أو بعد إعادة التشغيل. لم تُحسم في هذه المرحلة سلطة الحساب المالك أثناء الجدولة أو ذرية الآثار الخارجية أو اكتمال الفترة عند توقيت 23:59. لم تُرسل تقارير إلى مزود حقيقي، ولم يحدث نشر.

نجح بناء الإنتاج وفحص مفاتيح الترجمة أيضًا.
