# المرحلة 467 — سجل المدفوعات وتفاصيله في التطبيق والموك أب

استبدلت الصفحتان القديمتان بمكونات فعلية مشتركة، ووُصلتا بمصدر المرحلة466 المقيد بالمالك والتيننت المختار. يشمل ذلك مسار merchant-payments البديل. بقيت روابط الدفع وإعداداته أدوات منفصلة؛ لم تُحذف خصائص عاملة لإخفاء مشكلة.

السجل يدعم البحث الكامل والحالة والفترة بتوقيت UTC والصفحات25/50، ويحفظ المرشحات عند فتح التفاصيل والعودة. أخطاء المرشحات تحدد الحقل وتفتح الخيارات الإضافية وتركز أول خطأ. تلخص الواجهة العدد والحالات الأساسية، وتطوي بقية الحالات ومبالغ SAR/USD لتخفيف الهاتف. لا يجمع المبلغ بين عملتين ولا يساوي التصريح بالتحصيل. القيم القديمة غير الصالحة تظهر غير معروفة. بيانات قديمة مع فشل القراءة لا تعرض كدليل حديث.

التفاصيل تستخدم تسميات ترجمة واضحة بدل المفاتيح الرقمية الملتبسة، وتعرض المبلغ الصحيح والعميل والمرجع الآمن والتواريخ السبعة. أزيل زر إرسال واتساب غير المنفذ. زر الطباعة يفتح آلية المتصفح، وتصدير JSON محدود بالحقول المتحققة المعروضة، مع إشعار بطلب التنزيل دون ادعاء حفظ الملف أو إصدار فاتورة ضريبية.

نجحت104 اختبارات في التشغيل النهائي: واجهة الموك أب والسجل والمبالغ وإعدادات الدفع والمصدر. نجحت الأنواع والترجمة وبناء التطبيق والموك أب. لا مفاتيح مفقودة أو أخطاء interpolation. التغطية تشمل حالات فشل/جلسة/صلاحية/بيانات تيننت آخر/خطأ مع بيانات قديمة، والفراغ والبحث والصفحات والمراجع غير المتاحة والتصدير والطباعة بمحاكاة المتصفح.

فحصت36 حالة عرض:24 للقائمة والتفاصيل في التطبيق العربي والموك أب باللغتين، ثم12 للقائمة الموسعة بعروض320/390/768/1440. لا تجاوز أفقي داخل المكوّن؛ أزرار وروابط وملخصات44px أو أكبر وحقول16px. عندما يظهر شريط التمرير ينخفض عرض محتوى التطبيق الصغير إلى290/360 دون تجاوز. القياسات محفوظة في responsive.json، والصورة mobile-detail-320.png من التطبيق الفعلي. الشريط الفرعي العام مصمم للتمرير الأفقي، وهذه القياسات تخص مكون الدفع.

نجح البحث وفتح التفاصيل والعودة مع المرشحات في التطبيق والموك أب. عُرضت عينة محلية بقيمة12550 وحدة صغرى كـ125.50SAR، ثم حُذف صف العينة186 بسكربت مقيد بقاعدة الاختبار والمالك والقيم الأصلية؛ ظهرت الحالة الفارغة بعد التنظيف. نُظفت صفحات وتبويبات القياس. بدأ طلب تنزيل المثال في المتصفح وظهرت الرسالة الصحيحة، لكن انتظار أداة التنزيل انتهى دون مسار ملف؛ لا يُعد ذلك إثباتًا لحفظ ملف فعلي. الطباعة/PDF وSafari/iPhone الفعلي لم تختبر.

جُدد الحصر إلى126مسارًا و492ملفًا و2706عناصر تحكم، دون روابط غير صالحة أو مسارات محذوفة مكتشفة. الحصر الساكن لا يثبت اكتمال كل تجربة. التالي إغلاق payments.list/getById/getStats القديمة، ثم مراجعة روابط الدفع. لا تحصيل أو استدعاء مزود أو نشر.
