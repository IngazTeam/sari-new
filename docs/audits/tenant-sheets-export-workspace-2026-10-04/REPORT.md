# المرحلة 513 — شاشة تصدير المحادثات المشتركة

2026-10-04 — main، محلي فقط.

## ما تغير

استُبدلت شاشة SheetsExport القديمة بمكوّن التطبيق نفسه داخل الموك أب. تعرض بحثًا بالاسم والرقم و25 محادثة لكل صفحة، مع اختيار حتى100 محادثة عبر الصفحات وإزالة فردية ومسح وتحديد الصفحة الظاهرة فقط. تظهر وجهة Sheets وحالة الربط وروابط الإعدادات والتقارير.

مراجعة صريحة تجمّد اختيار المحادثات والملف وتوضح بيانات العملاء المصدّرة واحتمال الصفوف المكررة. الخادم يرفض الطلب القديم غير المراجع والوجهة المتغيرة، ويرجع إقرارًا يتضمن الحساب والمتجر والملف وعددي المحادثات والرسائل. الواجهة تتحقق من الإقرار وتمنع التأكيد المكرر أثناء الانتظار وبعد قبول أو غموض النتيجة حتى اختيار جديد متعمد.

القراءة تفحص نطاق الحساب والمتجر وكل صف وتخفي البيانات القديمة عند الفشل أو سحب الصلاحية، وتتغير حالة النموذج مع تغير الحساب/المتجر. لا فشل يظهر كقائمة فارغة. مقياس الفراغ مستقل عن فراغ البحث أو غياب الرسائل في المحادثات المختارة.

## التحقق

- 81 اختبار وحدة/واجهة/تحليل مصدر؛133 اختبار حصر وحفظ خصائص إضافيًا؛12 MySQL مع مزود وهمي؛67 تحقق عقد الإصدار.
- TypeScript وبناء الإنتاج نجحا، والترجمة بلا مفاتيح مفقودة أو أخطاء interpolation.
- حصر126 مسارًا و594 ملفًا و2792 عنصر تحكم، دون مسار محذوف أو رابط حرفي خاطئ أو صفحة يتيمة.
- Browser: فتح المكوّن الفعلي من لوحة الموك أب، البحث عنCustomer65، مراجعة رقمها والملف ثم قبول محلي واحد. فحص8 حالات للمقاسات320/390/768/1440 باللغتين، ومثلها لنافذة المراجعة؛ دون تجاوز أفقي، أهداف44px وخط حقل البحث16px. القياسات فيresponsive.json.
- اكتشف الفحص أن بوابة التضمين فيpages.js وbrain-embed.js لم تُحدَّث مع المسار الأول؛ أصلحت ووثقت الفتح الفعلي بدل الاكتفاء بنجاح بناء الحزمة.

## الحدود والخطوة التالية

إقرار المزود ليس تحققًا مستقلًا من محتوى الملف. منع التكرار محلي في الشاشة ولا يبقى بعد إعادة تحميلها؛ يلزم سجل عمليات دائم لاستعادة النتائج الغامضة. المراجعة تختار المحادثات، وجميع رسائلها وقت التنفيذ تدخل التصدير؛ لا لقطة مجمّدة لمحتوى الرسائل. لا تصدير خارجي أو اختبار Google حي أو Safari/iPhone فعلي أو نشر أو ادعاء اكتمال100%.

التالي شاشة تقارير Sheets القديمة، مع مراجعة الوجهة والمستلم ومصدر البيانات، ثم بقية الصفحات العامة المسجلة.
