# المرحلة 515 — إغلاق مزامنة Sheets القديمة غير المراجعة

2026-10-04؛ main؛ محلي فقط.

كان مدخلا sheets.syncOrder وsheets.syncLead يعتمدان أول متجر للمستخدم ويكتبان دون مراجعة وجهة أو الحماية الجديدة. لا تستدعيهما أي صفحة حالية، ولا يحتاجهما مسار سلة الداخلي. استُبدلا برد إيقاف صريح قبل الوصول للبيانات أو المزود، وحُذفت دالة إرسال العميل المحتمل غير المستخدمة.

صار syncOrderToSheets الداخلي يتطلب معرّف متجر وحارسًا قبل إرسال الشبكة في الأنواع وأثناء التشغيل؛ لا يستطيع استيراد قديم دون حارس إعادة فتح المسار. بقيت مزامنة سلة وإيصالاتها كما هي، بخلايا RAW والتحقق من هوية المتجر والربط قبل الإرسال. صارت الأخطاء من الحارس دون hook إيصال أيضًا منقّحة.

نجحت149 حالة وحدة/واجهة/حدود إرسال، و136MySQL تخص آثار سلة ومراجعتها ومراجعة وجهات التقارير، و69اختبار عقد إصدار وTypeScript وبناء الإنتاج. هذه تغييرات خادم فقط؛ لا مفاتيح ترجمة أو مخطط بيانات أو مسارات UI محذوفة.

لا تصدير خارجي ولا نشر. تبقى جدولة التقارير وحفظ إيصالاتها الدائمة والاستعادة، والصفحات العامة السبع: خصوصية التيننت والفريق وإشعارات المتصفح وأربع صفحات الولاء. فحص إشعارات المتصفح كشف أن قراءة الاشتراك المحلية لا تثبت تسجيله بالخادم، وأن حدود مدخلات الاشتراك والوجهة تحتاج مراجعة؛ العمل التالي هناك قبل التصميم. لا اكتمال100% أو Safari/iPhoneفعلي.
