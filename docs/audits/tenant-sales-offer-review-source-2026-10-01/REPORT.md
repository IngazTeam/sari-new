# المرحلة 223 — مصدر مراجعة عروض الخصم

وُحدت قراءة محاولة العرض والإيصال ومصدر طلب العميل والرسالة المسجلة وآخر مراجعة داخل لقطة MySQL للقراءة فقط. لا تُخلط مراجعة جديدة بإصدار سابق للمحاولة أثناء القراءة. وبعد إنهاء المعاملة يُعاد فحص رقم العميل خارج اللقطة؛ تغير الرقم يمنع إعادة عروض العميل السابق، ولا تلغي القراءة المتسقة هذا الحاجز.

أضيف عقد يحمل الحساب والمتجر والمحادثة ومؤشر مصدر الرسالة والصلاحية. تتحقق بنية الصفحة من ترتيب المصادر وتفرد المحاولات وحدود المؤشر والتواريخ واتساق قبول الإيصال وتسجيل الرسالة وتعارضها. أضيف عقد نتيجة للمراجعة يرفض النتائج المتناقضة. بقيت القائمة والكتابة القديمتان، وسُجلت الإجراءات المشتركة في راوتر المحادثات المنفصل أيضًا.

- نجحت 365 حالة للعقود والصلاحيات وحصر الميزات، و78 حالة MySQL لمراجعة العروض وتسويتها؛ المجموع 443 دون فشل أو تخطٍ.
- تختبر الحالات الجديدة مراجعة متزامنة أثناء قراءة القائمة، وتغير رقم العميل داخل القراءة مع رفض النتيجة بعد المعاملة، وفشل قراءة مع rollback وتحرير الاتصال والاستعادة. بقيت حالات المصادر المحذوفة والعرض غير المسجل والتعارض والصفحات والتيننت الآخر ناجحة.
- نجح TypeScript وبناء المشروع. لا واجهة أو مفاتيح ترجمة جديدة في هذه المرحلة، ولا يُدعى لها فحص بصري أو Safari/iPhone.

لم يتغير إرسال العروض أو نظام الخصومات أو عملية التسوية، ولم يُعد تشغيل خدمات خارجية. النقل محاكى في MySQL، ولا نشر. التالي ربط نافذة مراجعة العروض باللقطة وإصلاح حفظ الملاحظات والنتائج المتأخرة، ثم بقية المحادثات والتصميم والموك أب.
