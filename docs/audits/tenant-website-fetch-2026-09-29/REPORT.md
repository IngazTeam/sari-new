# تحصين جلب محتوى المواقع — 29 سبتمبر 2026

كان فحص عنوان الموقع نصيًا قبل الاتصال، بينما تتبع بعض الطلبات التحويلات تلقائيًا، وتستخدم البدائل curl أو متصفحًا خادميًا يمكنه طلب وجهات لم تُراجع. أُزيلت هذه البدائل من محلل الموقع ووُحدت طلباته الرئيسية والفرعية وخرائط الموقع وواجهات كتالوج المتاجر عبر `requestPublicWebsite`.

يفحص المسار HTTPS والمنفذ 443 وغياب بيانات الدخول، ويرفض العناوين المباشرة والمضيفين المحليين. تُفحص جميع إجابات DNS، ثم يُثبّت المقبس على عنوان عام تم التحقق منه مع بقاء التحقق الطبيعي من شهادة TLS. تُفحص كل وجهة تحويل مجددًا؛ الحد ثلاثة تحويلات، 15 ثانية للطلب كاملًا بما فيها التحويلات، خمس ثوانٍ كحد أقصى لمرحلة DNS، و2 MiB للاستجابة. الوكيل البيئي معطل، ولا تمرر ملفات الارتباط أو Authorization. تُحذف بيانات تعريف المتجر وOrigin/Referer عند التحويل إلى أصل مختلف.

لا يشغل المحلل JavaScript ولا يحمّل موارد JSDOM الفرعية. يقبل المستندات HTML/XHTML والنص، ويحافظ على استخراج البيانات المضمنة من HTML دون تنفيذها. المواقع التي تتطلب تنفيذ JavaScript أو دخولًا قد تحتاج ملف معرفة يرفعه التاجر؛ هذا قيد توافق مقصود ومعلن في الواجهة والموك أب. رفض المحتوى غير المقروء لا يتحول إلى نجاح فارغ أو مسار اتصال أضعف.

أُصلح تطابق أصل خرائط الموقع باستخدام URL بدل بادئة نصية، وحساب روابط الصفحة نسبة إلى عنوانها النهائي بعد التحويل، وأُغلقت نوافذ DOM بعد الزحف والتحليل. رسائل الشبكة المرسلة للعميل محددة وآمنة وتشرح البديل، ولا تعرض أسرار عنوان URL أو نص استجابة الخادم.
