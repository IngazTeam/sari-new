# المرحلة 371 — سلامة تجهيز المناسبة والخصم

صار العامل يقفل التيننت ثم الحملة المرتبطة ثم المناسبة، ويتحقق من بقاء الربط بعد الانتظار. يرفض هوية أو مناسبة خارج يومها، متجرًا غير نشط، قالبًا مخصصًا لا يستخدمه المرسل، أو عدادًا/إرسالًا سابقًا أو تعريفًا غير صالح. اسم المناسبة من التقويم الموثوق ونسبة الخصم من السجل المقفل.

تُفحص الحملة المجهزة والخصم الفعليان تحت القفل: حملة مسودة أو مجدولة، نص صالح، جمهور عام كما في المراجعة، دون صورة، خصم نسبي مطابق بلا حد أدنى وبحد2000 استخدام، غير مخصص لعميل، نشط وغير مستنفد، ينتهي في نهاية المناسبة بالضبط. وجود صفوف في طابور الحملة يمنع إعادة التجهيز. تستخدم المراجعة والعامل دالة السياسة نفسها، بما فيها مطابقة موعد الانتهاء؛ كان الاكتفاء بكون الخصم مستقبليًا يسمح بوعد مختلف عن المدة الفعلية.

تُكتب نهاية الخصم بدقة الثانية لتجنب تقريب أجزاء الثانية إلى اليوم التالي في التخزين. أي فشل قبل الحفظ يرجع إنشاء الخصم والحملة والربط معًا. فشل تأكيد commit يُعامل كنتيجة غير مؤكدة، ويُتلف الاتصال دون إعادته للمسبح أو افتراض rollback. إعادة التجهيز اللاحقة تقرأ الربط الموجود ولا تنشئ خصمًا أو حملة أخرى إذا كان الحفظ قد تم.

## التحقق

نجح150 اختبارًا دون تخطٍ، بينها اختبارات النطاق والتقويم وشروط الخصم والمحتوى وترتيب الأقفال والنتيجة غير المؤكدة. نجحت44 حالة MySQL في مجموعات التجهيز والأفعال والمصدر وتعريف الحملة:26 حالة غير متأثرة من التشغيل الأول، ثم10 حالات تجهيز و8 حالات أفعال في التشغيل النهائي. التوقع الأول لوقت الخصم افترض سلسلة نصية بينما يعيد اتصال MySQL كائن Date؛ صُحح الاختبار ليقارن الوقت بدقة دون تغيير نتيجة التطبيق.

يثبت اختبار MySQL طلبَي تجهيز متزامنين ينتجان حملة وخصمًا واحدًا، وفشل الربط يرجع كل الآثار، وفقدان تأكيد commit بعد تنفيذ الحفظ فعليًا لا يكرر الإنشاء عند الاستعادة، وإيقاف المناسبة أثناء انتظار قفل التيننت يمنع إنشاء أي سجل. لا طلبات مزوّد خارجي. نجح فحص الأنواع والبناء في13.36 ثانية؛ ملف الدخول425160 بايت و127085 مضغوطًا، مع تحذير الحزم الكبيرة السابق.

## ما يبقى

هذا فحص عند التجهيز. يلزم حفظ تفويض التفعيل وهوية صاحبه وشروطه، ثم إعادة مطابقته عند القبول والنقل، بما يمنع تغير الحملة أو الخصم بعد فك قفل التجهيز وسحب صلاحية المفوّض. لا تُفسر أعلام enabled القديمة وحدها بوصفها سجل تفويض جديد. لم تُغيّر هذه المرحلة مخطط البيانات أو الواجهة أو مفاتيح الترجمة. لا اختبار اختراق شامل أو Safari/iPhone فعلي أو إرسال خارجي أو دفع أو نشر.
