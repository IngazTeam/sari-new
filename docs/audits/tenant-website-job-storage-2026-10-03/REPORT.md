# حفظ محاولة تحليل الموقع وسلطة تنفيذها

المرحلة 422، 2026-10-03. أضيف الترحيل0200 لحفظ هوية محاولة الموقع وحالتها ونتيجتها وإذن تنفيذها والتيننت وصاحب الطلب ومالك المتجر ورابط الموقع. تمنع قيود قاعدة البيانات وجود محاولتين نشطتين للتيننت نفسه، ويرجع تكرار الطلب الإيصال السابق دون إنشاء عمل جديد. المهلة90ثانية قابلة للتجديد ضمن حد15دقيقة؛ لا يعيد التجديد إذنًا انتهى.

يوفر المصدر بدء المحاولة وقراءة حالتها وتقدمها وإنهاءها وفشلها وحارس كتابة تحت قفل التيننت. يعاد التحقق من الحساب والعضوية والصلاحية والمالك والرابط والإذن في كل كتابة. انتهاء المحاولة ينتج حالة غير مؤكدة، ويحفظ أي أثر سابق دون ادعاء التراجع عنه. يستطيع طلب جديد صريح استبدال المنتهي بعد مهلة الحد، ويبقى الرمز القديم مرفوضًا. لا إعادة تشغيل تلقائية.
