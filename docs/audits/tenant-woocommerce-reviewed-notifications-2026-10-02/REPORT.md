# المرحلة 328 — إشعار عميل WooCommerce بالمراجعة وحماية الناقل

## النتيجة

أضيف طلب إشعار دائم بصلاحية إدارة الطلبات، يتضمن رقم المستلم والنص اللذين راجعهما المستخدم مع بصمتي الطلب والربط. يطبع المصدر تنسيق الرقم الدولي دون اختراع رمز دولة لرقم محلي، ويبين توفر قناة WhatsApp أساسية نشطة دون كشف اعتمادها. لا يكوّن الخادم نصًا ضمنيًا عند الإرسال؛ النص الذي يُرسل هو النص الصريح المراجع.

يحمل النقل حارسًا داخليًا مرتبطًا بالعملية والتيننت والمستخدم والطلب. قبل استدعاء مزوّد WhatsApp مباشرة، تُفحص العضوية والحساب والمهلة وبصمة الربط والطلب والرقم والنص والقناة واعتمادها وسجل التسليم. تبقى هذه الأدلة مقفلة إلى أن ينتهي استدعاء المزوّد المحدود ويُحفظ قبول القناة وإيصال العملية داخل معاملة واحدة.

لا يسمح الناقل بتجريد الحارس أو تبديل الرقم والنص أو خلط العملية بأثر آخر. لا يستخدم إعادة المحاولة التلقائية، ولا يعيد طلب العملية نفسه الإرسال. بعد فقدان تأكيد الحفظ يستعيد الإيصال نجاحًا محفوظًا؛ وإذا تعذر حفظ القبول يبقى سجل التسليم غير محسوم ولا يتحول إلى إذن بإعادة الإرسال.

## التحقق

- 349 حالة معزولة ناجحة للعقود وتنسيق الرقم والمداخل والصلاحيات وحماية الناقل والتراجع في قناة WhatsApp والحملات.
- 74 اختبار MySQL ناجحًا: 20 للإشعار الجديد، و15 لتعديل طلب WooCommerce، و39 لناقل الحملات المشترك. شملت الرقم والنص المتغيرين، معرّف الحارس والمستخدم، سحب الصلاحية وتبديل القناة والربط وانتهاء المهلة بعد قراءة القناة، النتيجة المرفوضة أو المجهولة، منع إعادة الإرسال، الأقفال أثناء إرسال جارٍ، وفشل حفظ الإيصال أو فقدان تأكيد المعاملة.
- صُححت تهيئة اختبار تعطيل القناة لتستخدم الحالة المسموح بها `inactive` وتلغي `is_primary` وفق قيد قاعدة البيانات، ثم أُعيدت المجموعة كاملة بنجاح. لم يُغيّر قيد القنوات.
- فحص الأنواع انتهى بالرمز 0؛ بناء الإنتاج انتهى بالرمز 0 في 15.95 ثانية. الحزمة الرئيسية 424176 بايت و126790 gzip ضمن الميزانية؛ بقي تحذير الحزم الكبير السابق.
- 111 اختبارًا ناجحًا لحارس الإصدار وانتقال النشر والمحدّث، مع قدرة `woocommerce-reviewed-notices-0191` لمنع ناقل أقدم من تجاوز الحارس.
- `git diff --check` ناجح. استُخدمت تيننتات محلية مؤقتة ومزوّد WhatsApp محاكى؛ لم تُرسل رسالة حقيقية.

## الحدود والتالي

قبول القناة ليس إثبات تسليم أو قراءة. رفض القناة أو نتيجة إرسال غير مؤكدة يظهران كعملية تحتاج مراجعة قبل أي طلب جديد؛ لا تنشئ الاستعادة طلب إرسال جديدًا. الرقم والنص يعكسان البيانات المحلية التي راجعها التاجر، ولا يُفترض أن طلب المتجر البعيد لم يتغير منذ آخر مزامنة.

التالي نقل صفحات WooCommerce الأربع ومراجعات أفعالها إلى المصادر الجديدة، وإغلاق المداخل القديمة بعد النقل، ثم الموك أب الفعلي وفحوص العرض والترجمة. لم تُنقل الصفحات بعد، ولم يُجر نشر أو Safari فعلي أو فحص كامل للنظام.
