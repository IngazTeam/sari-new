# المرحلة 517 — حماية عامل الإشعارات ومدخل الشاشة الرئيسية

2026-10-04؛ main؛ محلي فقط.

أصبح عامل المتصفح يقبل التنقل إلى مسارات لوحة التاجر في المصدر نفسه فقط، ويستخدم صورة محلية موجودة بدل صور الحمولة الخارجية، ويحد النص والعنوان ويعرض fallback عند بيانات غير صالحة. أُزيل تسجيل محتويات الإشعارات، وأضيف فتح/إغلاق بالعربية والإنجليزية. يعيد النقر استخدام النافذة المطابقة بعد حل الرابط النسبي، مع fallback عند تعذر التركيز. لا تنقل عند الإغلاق أو إجراء غير معروف.

العامل لا يخزّن التطبيق ولا يعترض طلباته؛ لذلك حُذف حذف الكاشات غير المملوكة له من التفعيل. صار التفعيل والرسائل الموثوقة من صفحات التاجر ينتظران اكتمال skipWaiting/claim.

أضيف manifest للتاجر بوضع standalone ومدخل dashboard وأيقونة موجودة. توثّق [WebKit](https://webkit.org/blog/13878/web-push-for-web-apps-on-ios-and-ipados/) دعم Web Push لتطبيقات الشاشة الرئيسية واشتراط طلب الإذن بتفاعل المستخدم. لا تعني إضافة الملف اختبارًا فعليًا للآيفون.

نجحت135حالة للعامل وحدود النقل والإيصالات، وبناء الإنتاج. أعاد الخادم المحليsw.jsبحالة200والـmanifestبنوعapplication/manifest+json. لا تغييرات TypeScript في هذه المرحلة ولا ترحيل قاعدة. اختبارات العامل شغّلت ملفه الفعلي داخلVM دون منح إذن أو إشعار حقيقي. تبقى إدارة الاشتراكات وشاشتها والموك أب وبقية الصفحات، ولا نشر.
