# سجل أنشطة ساري — المرحلة160

تاريخ2026-10-01، الفرع main، محلي فقط.

استُبدلت واجهة السجل القديمة بمكوّن مشترك للتطبيق والموك أب. تعرض القراءة الحالية المطابقة للتيننت والفلتر فقط؛ تُحجب البيانات السابقة أثناء التحديث وعند فشل القراءة أو اختلاف النطاق. تبقى خيارات الفلترة متاحة مع الخلو والخطأ، ويمكن إزالتها والانتقال مباشرة إلى صفحة صحيحة. يُوضح تجاوز قائمة200 نوع مع إدخال النوع الحرفي دون قصه.

تُعرض أوصاف الأنشطة كاملة كنص آمن، مع ترجمة أنواع المعرفة وعروض الأسعار وأهداف المبيعات، وإبقاء اسم النوع غير المعروف قابلًا للقراءة. التاريخ غير المتوفر يُذكر صراحة، والأوقات تتبع منطقة المتصفح الظاهرة. السجل ليس مقياس دقة أو احتراف مبيعات. لا يغير القراءة أوصاف البيانات التاريخية الأصلية.

الموك أب knowledge-activity.html يستخدم المكوّن نفسه بست حالات و23 سجلًا وثلاث صفحات وعربية/إنجليزية. API معطل فيه؛ لا اتصال خارجي ولا تغيير فعلي للمعرفة.

## التحقق

-296 حالة ناجحة تشمل واجهة السجل وعزل النطاق والعقد والصلاحيات والحصر، و6 اختبارات MySQL ناجحة للقارئ بعد إضافة نطاق الرد والفلتر.
-TypeScript للتطبيق والموك أب، بناء العميل والخادم وحد الحزمة ناجحة.
-فحص10839 استدعاء ترجمة و515 مفتاحًا ديناميكيًا دون مفقود أو غير محلول أو اختلاف interpolation.
-التطبيق المحلي عرض31 سجلًا بأربع صفحات مع أسماء الأنشطة المترجمة. الموك أب: فلتر خالٍ ثم مسحه، انتقال مباشر إلى الثالثة، وتعطيل التالي في الأخيرة، ومنع عرض بيانات تيننت آخر.
-قياس المتصفح الضيق480×844، عرض المحتوى450 دون تجاوز أفقي. لا يمثل هذا اختبار Safari/iPhone أو320/390 الفعلي. أعيد المقاس الافتراضي بعد الفحص.
-الحصر الحالي126 مسارًا و326 ملفًا و2180 عنصرًا؛ لا روابط غير صالحة أو صفحات يتيمة أو مسارات محذوفة.749 تنبيه تسمية آلي ليس حكمًا نهائيًا على سهولة الاستخدام.
