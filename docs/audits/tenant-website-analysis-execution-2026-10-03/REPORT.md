# المرحلة423: تشغيل تحليل الموقع بسجل دائم وإذن كتابة حي

تحليل الموقع من عقل ساري يستعمل الآن جدول0200 بدل خريطة داخل عملية الخادم. تكرار مرجع الطلب يعيد المحاولة نفسها، والطلب المتزامن يلتقط المهمة الجارية دون تشغيل مزود ثانٍ. النتيجة المقيدة بالتيننت تبقى قابلة للقراءة بعد إعادة اتصال قاعدة البيانات.

## الإصلاحات

- ربط بدء المهمة والتقدم والنهاية والفشل بالتخزين الدائم، وتجديد إذن العامل كل30ثانية دون تداخل. انتهاء الإذن أو المهلة المطلقة يمنع الإحياء والكتابات المتأخرة.
- فحص التيننت والمالك وحالة الحساب والعضوية وصلاحية إدارة المساعد ورابط الموقع داخل معاملة كتابة المعرفة نفسها: سجل التحليل والصفحات والأسئلة والأقسام وسجل التغيير والفهرسة وإبطال السياق المخزن.
- فحص الإذن قبل طلب توليد جديد. طلب خارجي بدأ سابقًا لا يمكن إلغاؤه بهذا الحارس، لكن نتيجته المتأخرة لا تتجاوز فحص الكتابة.
- تصحيح قراءة insertId من نتيجة Drizzle في createWebsiteAnalysis. يحفظ السجل والنص المنظف في المعاملة نفسها، بدل تمرير معرف غير معرّف إلى التحديث.
- حفظ نتائج محددة البنية دون رمز التنفيذ أو محتوى خام أو تفاصيل أخطاء المزود. عند الفشل قد تبقى معرفة حُفظت في خطوة سابقة؛ لا ادعاء بتراجع العملية كلها.
- إضافة قدرة إصدار website-analysis-durable-jobs-0200 ودليل التعافي؛ المحدّث يوقف الكتّاب السابقين قبل الترحيل ولا يفعّل إصدارًا غير متوافق.

## التحقق

نجحت78 حالة وحدة/عقد وربط، و157 حالة تراجع إضافية (المجموعان يتداخلان في اختبارات تنفيذ المعرفة والمعاملة، فلا يُجمعان بوصفهما حالات فريدة). نجحت46 حالة MySQL لحارس التنفيذ والفهرسة، و6 حالات للمسار الفعلي، و40 حالة لدورة المعرفة واستيراد الموقع وسجل التقارير، و7 حالات لاستعادة إدخال المعرفة. نجحت42 حالة لحارس الإصدار وTypeScript والبناء وgit diff --check.

اختبارات المسار الستة تستخدم API وقاعدة MySQL وحفظ التحليل والصفحات والأقسام فعليًا، مع استبدال مزودي تحليل الموقع والتصنيف والفهرسة ببدائل اختبار فقط. غطت استمرار القراءة بعد closeDb، ومنع الطلب المكرر، وحفظ الفشل، واستبدال محاولة منتهية، ومنع حفظ نتيجة متأخرة، وبقاء الأجزاء المسموح بها قبل انتهاء الإذن. تفاصيل العدادات في checks.json.

## الحدود والمتابعة

هذا ليس اختبار اختراق شاملًا ولا اتصالًا حقيقيًا بمزودي التحليل. لا استئناف تلقائيًا للعمل المنقطع، ولا مصالحة تكلفة/قبول المزود الجاري. مرجع الطلب في واجهة المتصفح ما زال في الذاكرة، واستعادته بعد إعادة التحميل هي المرحلة424. حارس الزحف ومراجعة بقية مداخل التحليل مستقلان؛ لا ادعاء بتغطية كامل النظام أو Safari/iPhone. لا تغيير مفاتيح ترجمة في هذه المرحلة. شُغّل الخادم المحلي المعدل واستجاب HTTP200؛ لا دفع Git ولا نشر.
