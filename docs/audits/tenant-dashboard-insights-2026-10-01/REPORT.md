# المرحلة 195: مصدر اقتراحات ساري

استُبدلت حسابات الاقتراحات القديمة بلقطة الأرقام الموثوقة لسبعة أيام: العملة ووحدة السعر والفترة والمقارنة غير المتاحة واستبعاد القيم وعينة المنتجات. أعداد المحادثات والحملات والمنتجات النشطة تُقرأ باستعلام مجمّع معزول للتيننت وتوصف بأنها طوال عمر المتجر، ولا تُرسل سجلات العملاء أو نصوص حملاتهم للمزود. لا يستنتج اتصال واتساب من مجرد وجود سجل جهاز.

الفشل في المصدر أو المزود أو تحليل الرد لم يعد يتحول إلى مصفوفة فارغة. يعيد API خطأ عامًا دون تفاصيل داخلية، وتحتفظ النتيجة الفارغة بمعنى النجاح دون اقتراحات. الرد محدود بثلاثة عناصر وأحجام صريحة وروابط داخلية معتمدة؛ تُحذف الإجراءات ذات الوجهة غير المعتمدة بدل تحويلها إلى إجراء مختلف.

أضيف دعم لغة الطلب العربية/الإنجليزية دون تغيير بوابة لغات التطبيق. الكاش والتجميع أثناء التوليد معزولان بالمتجر واللغة، ولا تُحفظ الأخطاء؛ تُنسخ النتائج لمنع تعديل الكاش من المستهلك. الواجهة توضح إعادة استخدام النتيجة حتى6ساعات وتتطلب طلبًا صريحًا عند تبديل اللغة. المسار يقبل الاستدعاء القديم دون مدخلات بالافتراضي العربي.

نجحت72حالة لمحرك الاقتراحات وسياق المزود والواجهة ولقطة البيانات، و136لحفظ الخصائص والحصر، واختبارانMySQL محليان لعزل التيننت والعملات والمنتجات النشطة. شملت الحالات خطأ المصدر والمزود وJSON، التزامن، فصل اللغة والمتجر، انتهاء الكاش، إعادة المحاولة، المدخلات والأرقام غير الصالحة، الروابط الخارجية وطلبات API غير المصرح بها. نجح TypeScript والبناء والترجمة. لا استدعاء مدفوع: اختبارات المزود محاكاة، والفحص الحي محمي بحظر الشبكات الخارجية.

أُعيد تشغيل نسخة الاختبار على3018 ثم طُلبت اقتراحات من الواجهة؛ ظهر فشل صريح وزر إعادة المحاولة بدل «لا توجد اقتراحات». هذا إثبات لمسار الخطأ؛ جودة مخرجات مزود حقيقي لم تُختبر هنا. لا نشر. التالي تصحيح مصدر المزامنة وبانر الاشتراك ثم موك أب الرئيسية وبقية الصفحات.
