# سجل استكمال تصميم لوحة التيننت

تحديث تطبيق 2026-09-28: نُفّذ عزل المعاينة السريعة وربط سياق مختبر الاختبار وتأكيد استبدال الجلسة؛ راجع [تقرير عزل المعاينة](../tenant-isolated-preview-2026-09-28/REPORT.md). أضيف لاحقًا اختبار الشخصية المحفوظة والتوجيه، وحماية مسودتها، وإصلاح أيام العمل والفصل بين مسودة الرسائل واختبار الإعدادات؛ راجع [تقرير الشخصيات والإعدادات](../tenant-persona-preview-2026-09-28/REPORT.md). أغلقت جولة لاحقة ثغرات تزامن حد الشخصيات والافتراضية والقوالب والترتيب، وصدق الحذف، والتحقق من الدوام المدمج بالخادم، وتداخل الحفظ مع تنقل الهاتف؛ راجع [تقرير حماية الحفظ](../tenant-assistant-save-safety-2026-09-28/REPORT.md). أضيفت بعدها استعادة مسودة إعدادات الرد ضمن عمر التبويب ومراجعة التعارض والدمج وفحص النسخة داخل معاملة MySQL؛ راجع [تقرير استعادة المسودة](../tenant-assistant-draft-review-2026-09-28/REPORT.md). الأعداد أدناه تخص تغطية الموك أب السابقة ولم تُرفع تلقائيًا. تبقى المطابقة الكاملة مع تشغيل العملاء، واكتشاف تعارض بقية نماذج النظام، وحفظ التقييمات واستعادة جلسات التجربة مفتوحة.

حالة التصميم مبنية على [سجل التغطية السابق](../tenant-features-2026-09-28/coverage.json)، مع ترقية الحملات لتبويب الأداء وثلاثة مسارات مشتركة للاشتراك إلى «تفصيلي جزئي». الحصر الأخير: 126 مسارًا و186 ملفًا و1642 عنصر تحكم في [السجل المحدث](../tenant-subscription-workspace-2026-09-28/source/FEATURE_REGISTER.md). بعد حذف أربع صفحات في دفعة الحملات، نُقلت عدادات الاشتراك وحُذفت Subscriptions؛ بقي ملف WhatsApp بسبب اختلاف سجلات الربط وتدفق الفصل القديم. راجع [تقرير الباقة والاستخدام](../tenant-subscription-workspace-2026-09-28/REPORT.md). الحصر لا يثبت نجاح تشغيل كل خاصية.

- موك أب عام: **103** مسارات.
- إعادة توجيه: **8** مسارات.
- تفصيلي: **10** مسارات.
- تفصيلي جزئي: **5** مسارات.

P0 أولوية المستخدم: نتائج عقل ساري، المصادر والملفات والفجوات، تفسير تقييم المبيعات، تجربة الرد قبل اعتماده، وبقية إعدادات التعلم والتجارب والتشغيل. P1 التدفقات اليومية وما يغيّر بيانات العميل أو المال أو الإرسال. P2 بقية الإدارة والتحليلات والإعدادات. الأولوية ترتيب عمل؛ لا تعني ثغرة أمنية مؤكدة.

أُصلح فتح الرابط الداخلي عند الاختيار التلقائي للمتجر الوحيد بإعادة تحميل الرابط نفسه. يبقى التبديل اليدوي عازلًا لذاكرة التيننت السابق مع العودة للوحة البداية. تحقق ذلك في تبويب جديد عبر الرابط القديم للشخصية.

## شروط إغلاق أي صفحة

مطابقة الحقول والأزرار والنوافذ والخيارات المشروطة والصلاحيات مع المصدر؛ تجربة دورة القراءة والتعديل والحفظ وإعادة الفتح والفشل دون فقد المسودة؛ اختبار الحالات الفارغة والتحميل والخطأ؛ مراجعة الهاتف ولوحة المفاتيح والاتجاه؛ توثيق الفروق بين الموك أب والخادم. تتطلب خدمات الذكاء الاصطناعي والإرسال والتكاملات تحققًا منفصلًا قبل وصفها بأنها تعمل. يبقى اختبار Safari وiPhone الفعلي مفتوحًا.
