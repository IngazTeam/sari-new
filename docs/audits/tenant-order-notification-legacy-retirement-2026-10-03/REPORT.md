# إغلاق مسارات إشعارات الطلبات القديمة

المرحلة 416، 2026-10-03. أُغلقت قراءات التوافق الأربع `getTemplates` و`getHealth` و`getHistory` و`getByOrderId` بعد التحقق من هوية المستخدم وصلاحية التيننت المختار؛ ترجع طلب تحديث الصفحة إلى المصدر الجديد. كانت القراءات القديمة تعرض سجلًا محدودًا أو ملخص سبعة أيام وتستنتج النجاح من حالة العامل، ولا تطابق الفصل الحالي بين حالة التنفيذ ودليل المزود. لم يبق مستهلك لها في الواجهة أو الموك أب.

أُزيلت عشر دوال عامة غير مستخدمة: أربع من طبقة قاعدة البيانات، وثلاث لتجهيز القوالب القديمة، وملخص العامل القديم، وقراءة الطلب القديمة وكاتبه غير المراجع. يبقى قاموس القوالب الافتراضية ومعرّف الحدث وقواعد انتقال حالة الطلب. إنشاء الإشعار يمر بالقرار المراجع وإيصال القرار والتفويض، والشاشة الحالية تمر بالمصدر الكامل وتفاصيله والحفظ المراجع وإغلاق الحالة المحددة.

## التحقق

- نجحت 142 حالة وحدة وواجهة وموك أب: تشمل الجهات الأربع المسموح لها بالقراءة، الحساب غير المسجل والعضوية المسحوبة، المدخلات المعدلة، أخطاء التخزين، تنسيق العملات والنص، نافذة القالب وسجل الحالات.
- نجحت 90 حالة MySQL تغطي API الحالي والمداخل المتقاعدة، التيننت المختار والعضو المدعو، حجب بيانات مراجع الطلبات المتعارضة، 106 سجلات مع البحث والصفحات، الأفعال المراجعة، والنقل المحمي.
- نجحت 41 حالة لفحص الإصدار. أضيفت القدرة `order-notice-legacy-paths-retired-v1` للحماية من تشغيل الإصدار القديم بعد التحديث.
- نجح فحص الأنواع وبناء الواجهة والخادم والعامل وميزانية الحزمة. بقي تحذير حجم بعض حزم Vite.

هذه إزالة لمسارات غير مستخدمة وإغلاق توافق قديم؛ لا حذف لبيانات التاجر ولا تغيير لمفاتيح الترجمة أو تصميم الواجهة. الاختبارات على تيننتات محلية مؤقتة بمزود محاكى. لا إرسال خارجي أو نشر أو اختبار Safari/iPhone فعلي. المرحلة التالية تحديث سجل التغطية العام بالأدلة الحديثة، ثم متابعة الصفحات والخصائص المتبقية.
