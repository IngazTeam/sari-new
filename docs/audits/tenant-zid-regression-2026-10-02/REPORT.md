# المرحلة316: توسيع فحص التراجع لزد

حُدث اختبار MySQL القديم الذي توقع نجاح `updateSettings`: يثبت الآن رفضه برسالة طلب إعادة التحميل، وبقاء بصمة الربط دون تغيير، ثم نجاح `saveWorkspaceSettings` بالبصمة المقروءة للتيننت المحدد دون تغيير التيننت الآخر. بقي المدخل المتقاعد مغلقًا.

نجحت305حالات معزولة و93حالة MySQL. شملت صلاحيات الراوتر المركب والمباشر، المصدر، إعدادات الربط، OAuth، سلطة المزامنة، الطلبات الدائمة، دفعات الإشعارات، الواجهة والموك أب. نجح TypeScript. هذه المرحلة تعدل الاختبار فقط؛ لا تغيير في كود التشغيل أو الترجمة، ولذلك لا يلزم بناء تشغيل جديد بعد البناء الناجح في315.

الأدلة: `.tmp/tenant-ux/phase316-tests.json` و`phase316-mysql.json` و`phase316-types.log`. الاختبارات تستخدم قاعدة محلية مؤقتة واتصالات خارجية محظورة. لا مزود حي أو Safari/iPhone أو نشر. التالي متابعة سلطة عمليات WooCommerce أثناء انتظار القفل والتعامل مع المزود.
