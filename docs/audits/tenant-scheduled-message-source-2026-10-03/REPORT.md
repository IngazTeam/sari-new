# المرحلة 395 — حصر الرسائل المجدولة ومصدر التيننت

التاريخ: 2026-10-03. فحص مصدر واختبارات محلية، دون تشغيل إرسال خارجي أو نشر.

أضيف مصدر `scheduledMessages.workspace` إلى الراوتر المستقل والمركب: بحث كامل بالعنوان والنص والرقم، تصفية يوم الأسبوع وحالة التفعيل المخزنة، ترتيب وصفحات25 وإحصاءات من لقطة واحدة. تعاد صلاحية العضوية وحالة المستخدم والمتجر تحت المعاملة؛ يقرأ المشاهد ومشرف المبيعات دون صلاحية إدارة الحملات، ولا يسمح للراوتر باستخدام هوية متجر مزروعة في السياق بدل الاختيار الحالي.

تظهر القيم القديمة غير الصالحة كحقول غير معروفة مع أسبابها؛ لا يتحول اليوم أو الوقت المعطوب إلى موعد مفترض. تتضمن بصمة السجل القيم الأصلية حتى عند تغير قيمة معطوبة إلى أخرى. فشل قاعدة البيانات أو إنهاء المعاملة لا يعاد كقائمة فارغة ناجحة.

## نتائج فحص المسار القديم

- المساران القديمان في `routers.ts` و`routers-scheduled-messages.ts` يعتمدان متجر صاحب الحساب بدل التيننت المختار، دون صلاحية إدارة الحملات. الوقت يقبل `99:99` ويوم الأسبوع ليس مقيدًا بعدد صحيح.
- العامل `jobs/scheduled-messages.ts` يستخدم توقيت خادم التشغيل وقائمة كل المحادثات، ثم يستدعي `whatsapp.sendCampaign` دون ربط قناة التيننت. هذا المسار يستخدم إعداد Green API العام.
- `lastSentAt` يحدث حتى إذا لم يوجد مستلمون، وبعد نتيجة مجمعة لا تثبت نجاح كل مستلم. الدالة المجمعة تعد الاستدعاء ناجحًا حتى لو أعادت الدالة الداخلية `success:false`. لا إيصال دائم لكل أسبوع/مستلم، وآلية60 دقيقة لا تمنع السباق بين نسختين من العامل.
- لذلك المصدر الجديد يصف الساعة بأنها وقت خادم قديم غير مسجل، و`legacyLastSentAt` كتاريخ قديم فقط؛ لا نسبة تسليم أو مبيعات مشتقة منه ولا ادعاء معرفته بموعد الرياض.

## التحقق والحدود

نجحت 19 حالة لعقد المصدر وأخطاء المعاملة وصلاحيات الراوتر المستقل والمركب، و5 حالات MySQL تشمل105 تعريفات عبر5 صفحات والبحث الحرفي والترتيب وعزل المتجر والبيانات المعطوبة وإبطال العضوية والحساب. لا فشل أو تخطي. نجح فحص الأنواع وبناء العميل والخادم خلال16.65 ثانية لبناء العميل، مع تحذير حجم الحزم المعروف.

هذه مرحلة مصدر إضافي لا تستبدل الواجهة أو الكتابات أو عامل الإرسال القديم بعد؛ لم يُشغّل العامل على بيانات التجربة. العمل التالي: إغلاق مسار الإرسال العام وربط التعريف الأسبوعي بجدولة ومراجعة وصلاحية وإيصالات قابلة للتتبع، ثم الواجهة الفعلية والموك أب والهاتف. بقاء السلوك القديم هنا مُسجل كعمل مفتوح، وليس إصلاحًا مكتملًا أو اعتمادًا للنشر.
