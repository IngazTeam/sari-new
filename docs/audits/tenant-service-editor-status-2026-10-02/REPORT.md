كانت رسالة «التعديلات لم تُحفظ بعد» تظهر دائمًا، حتى عند فتح سجل محفوظ أو عرضه دون إذن الإدارة. أصبحت الرسالة مرتبطة بحالة النموذج: نسخة محفوظة دون تعديلات، مدخلات تغيرت، عرض فقط، حفظ جارٍ، نتيجة غير مؤكدة، تعارض نسخة، أو تعذر تحديث المصدر. إرجاع جميع المدخلات إلى قيم فتح النموذج يعيد رسالة النسخة المحفوظة. لم تتغير عقود الحفظ أو الصلاحيات أو سلوك الحقول.
