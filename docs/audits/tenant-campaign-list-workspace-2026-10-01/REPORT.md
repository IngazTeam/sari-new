# المرحلة 247 — قائمة الحملات الفعلية

استُبدلت واجهة القائمة القديمة بمساحة عمل متجاوبة مربوطة بمصدر الحملات الجديد. تعرض الأعداد الكاملة منفصلة عن نتائج البحث، وتقدم كل حملة، والانتظار والاستبعاد والمراجعة، مع فلاتر الحالة والاسم والمراجعة والصفحات. يستعيد الرابط الفلاتر والتبويب ويحفظ المعاملات الأخرى. تُعرض الأوقات بمنطقة المتجر، وتوصف العدادات بأنها قبول مسجل لا تسليم أو قراءة أو مبيعات.

تُراجع هوية الحساب والتيننت والفلاتر والعقد قبل عرض اللقطة، وتختفي الأرقام القديمة عند فشل القراءة. صلاحية العرض لا تكشف أزرار الإدارة. تُفتح نوافذ واضحة للإرسال والحذف والمراجعة، ويتطلب إغلاق المراجعة إقرارًا، وتُمنع الإجراءات عندما تتغير بيانات البطاقة أو تجري القراءة. تُهمل نتائج الإجراءات المتأخرة بعد تبديل الحساب أو الرابط. أضيفت تسميات سياقية، وترجمة إغلاق النافذة واتجاهها، واستعادة التركيز، وصُححت ألوان CSS لتستخدم رموز النظام مباشرة.

نجحت **533 حالة معزولة و11 حالة MySQL متأثرة، بإجمالي544** دون اختبارات أو مجموعات فاشلة. نجح TypeScript والبناء وفحص الترجمة دون مفاتيح مفقودة. اختبارات القائمة القديمة نُقلت إلى المكوّن الفعلي الجديد، ومنها الخطأ والقائمة الفارغة. عُدلت أداة فحص الوصول لتتعرف على دالة الترجمة group الموجودة في لوحة المصادر؛ كان الإخفاق إنذارًا كاذبًا لزر ذي نص ظاهر.

فُحص التطبيق المحلي بتيننت الاختبار وثلاث حملات مؤقتة ثم نُظفت بيانات هذه الجولة. ثبت العرض المكتبي2560، وعرض المحتوى الفعلي480 داخل إطار محلي بعد عدم تطبيق أداة المتصفح لتغيير عرض التبويب. في إطار480 كانت مساحة المستند450 مع شريط تمرير، والبطاقات عمودًا واحدًا بعرض422، وخط الإدخال16بكسل وكل روابط وأزرار القائمة44بكسل على الأقل. نافذة المراجعة418بكسل دون تجاوز داخلي، واستُعيد التركيز إلى زر الحملة بعد إلغائها. البحث أعاد حملة واحدة وحفظ q في الرابط. حُذف إطار الفحص المؤقت. لا يمثل ذلك اختبار Safari أو iPhone فعليًا أو عرض320/390.

الأدلة: `.tmp/tenant-ux/phase247-tests.json` و`phase247-source-mysql.json` و`phase247-types.log` و`phase247-build.log` و`phase247-translations.json` و`phase247-mobile-dialog.png`. حُدث سجل انتقالات API وجرد126مسارًا دون فقد مسارات أو ملفات يتيمة. الأعداد الساكنة مؤشرات مراجعة وليست شهادة نجاح كل خاصية.

حدود باقية: تبويب الأداء ما زال يستخدم المصدر القديم غير المرتبط بهوية الاستجابة؛ ستعالجه المرحلة التالية. مراجعة الحملة ما زالت تغلق جميع الحالات القائمة وقت التنفيذ، والنص يصرح بذلك؛ الربط بكل إيصال يحتاج مرحلة مستقلة. الإرسال الحالي لا يربط تعريف الرسالة الذي شاهده المستخدم بالتأكيد، رغم حراسة التعريف داخليًا على الخادم. التفاصيل والتقرير والمحرر والموك أب الفعلي لم تكتمل بهذه المرحلة. لا نشر أو إرسال خارجي.
