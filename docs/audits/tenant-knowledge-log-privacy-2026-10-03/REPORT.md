# حماية محتوى المعرفة في سجلات المعالجة

المرحلة 427 بتاريخ 2026-10-03. أزيلت مقتطفات محتوى الملفات ونتائج النموذج وعناوين الأقسام ورسائل الأخطاء الخام من سجلات محرك المعرفة. بقيت أطوال النصوص وأعداد الأقسام ومراحل المعالجة لتشخيص الأعطال دون نسخ المعرفة إلى السجل التشغيلي.

## السلوك المحفوظ

لم تتغير النصوص المرسلة للتحليل ولا النتائج المحفوظة ولا سجل تغييرات المعرفة الخاص بالتاجر. اختُبر حفظ القسم الأصلي وإرشادات المبيعات وفرص التطوير التي تبقى مخصصة للتاجر مع تعطيل استخدامها في البوت. رسائل الفشل التشغيلية أصبحت ثابتة، مع بقاء سلوك الإرجاع الحالي عند فشل التصنيف أو تحليل المبيعات.

## التحقق

أضيفت 8 حالات تستدعي دوال محرك المعرفة الفعلية مع بدائل محلية للنموذج والتخزين. فشلت 7 حالات قبل الإصلاح بسبب ظهور البيانات الاختبارية الحساسة في السجلات، ثم نجحت الحالات الثماني. تغطي النجاح والنوع غير المقبول وJSON غير صالح وأخطاء المزود ومكدس الخطأ والنتيجة الفارغة ومسار الإدخال الكامل. نجحت معها اختبارات تراجع المعالجة والفهرسة وحراس التنفيذ: 52 حالة إجمالًا. نجح فحص الأنواع وبناء التطبيق وفحص فروق Git.

## حدود هذه المرحلة

لم تتصل الاختبارات بمزود خارجي ولم تعدل السجلات التاريخية. الحماية هنا تخص محرك المعرفة نفسه؛ مسار تقارير المواقع وطبقات النقل الأخرى لها سجلات منفصلة، وتليها مراجعتها. لا تغيير واجهة أو مفاتيح ترجمة أو ترحيل قاعدة بيانات أو نشر.
