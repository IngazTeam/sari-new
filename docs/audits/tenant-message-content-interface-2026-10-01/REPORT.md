# المرحلة 231 — الرسائل والمرفقات والتواريخ

استُخرج عرض الرسالة الفعلي إلى ConversationMessage. أضيف مشغّل صوت أصلي بتحكم المستخدم دون تشغيل أو تحميل تلقائي. تظهر المرفقات المفقودة أو غير الآمنة والفشل برسائل واضحة بدل إخفاء الصورة، مع إعادة تحميل صريحة. تُفتح الصورة بزر حقيقي في حوار قابل للإغلاق يعيد التركيز، وتحتفظ المعاينة بحالة فشل قابلة للاسترداد. لا يُستنتج نوع الرسالة من امتداد رابط مستند. بقي دعم الصور القديمة المحفوظة في voiceUrl.

تتحقق الواجهة من بروتوكول الرابط وتمنع البيانات البرمجية والتفويض المضمن والعناوين المحلية الواضحة ومسارات إجراءات التطبيق. تُقبل HTTPS العامة ومسارات uploads المحلية المحددة. هذا تحقق من صيغة الرابط وليس فحصًا لمحتوى الملف أو حل DNS. روابط الملفات تفتح بتبويب جديد مع noopener/noreferrer، دون الادعاء بتنزيل ملف لم يُنزّل.

تظهر هوية العميل أو الموظف أو المساعد أو المرسل غير المحدد بالنص والأيقونة المناسبة. لا يُظهر الصادر المجهول أيقونة المساعد. يظهر التاريخ الكامل والمنطقة الزمنية للمتجر، ويُعلن استخدام UTC إن كانت منطقة المتجر غير صالحة، مع معالجة التاريخ المفقود دون انهيار. النصوص وأسماء المستندات الطويلة تبقى كاملة وتلتف. أضيفت نصوص العربية والإنجليزية ومفاتيحها للنوع المشترك.

كشف المتصفح مشكلتين أصلحتا: حاوية القياس الجدولية في Radix كانت تتسع إلى نحو2393px داخل منطقة386px رغم أن عرض الصفحة480px، وقاعدة RTL عامة كانت تلغي عكس صف الرسالة الصادرة. صارت حاوية الرسائل386/386px دون امتداد داخلي، والوارد بمحاذاة اليمين والصادر باليسار في العربية. يحد عرض الفقاعة المكتبية من امتداد السطر.

- نجحت206حالات للمرفقات والاتصال وحصر الميزات، دون فشل أو تخطٍ. تتضمن الروابط الخطرة، الأدوار، التاريخ غير الصحيح، النص الكامل، تغير المرفق، فشل التحميل واستعادة التركيز.
- نجح TypeScript والبناء. فحص11392استدعاء ترجمة و883مفتاحًا ديناميكيًا بلا فقد أو خطأ استيفاء.
- اختُبرت الصفحة الحقيقية بمحادثة محلية تضم5رسائل اختبار: نص طويل، رابط غير آمن، صورة محلية، صوت صامت لمدة ثانية، وصورة مفقودة. سجل الصوت duration=1 وreadyState=4 دون خطأ. المعاينة448pxداخل480px واستعاد الإغلاق التركيز.
- القياس الفعلي480×844، ثم2560px على سطح المكتب: client/scroll=2530/2530 ومنطقة الرسائل1128/1128. محاولة طلب عرض أصغر بقيت480px بسبب قيد المتصفح؛ لا ادعاء بفحص390أو320أوSafari/iPhone حقيقي.
