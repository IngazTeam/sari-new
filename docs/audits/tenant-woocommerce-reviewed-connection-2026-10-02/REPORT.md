# المرحلة 326 — ربط WooCommerce وفحصه وفصله بالمراجعة

## النتيجة

أضيف `requestReviewedConnection` بثلاثة أفعال صارمة: الربط، فحص الاتصال، والفصل. يحمل كل فعل معرّف طلب وبصمة الربط التي شاهدها المستخدم. تُحفظ بصمة محتوى تعتمد HMAC دون حفظ الاعتمادات في سجل العمليات؛ يبقى التنفيذ محكومًا بالتيننت والعضوية والمهلة والقفل وفحص تعارض المنصات.

فحص الاتصال الجديد يقرأ API وتسجيلات webhook الحالية فقط؛ لا ينشئ أو يحذف تسجيلًا. الإيصال يميّز فحص API عن فحص API والتسجيلات معًا، ولا يدّعي وصول حدث فعلي. بيانات الاعتماد الجديدة تُحفظ عبر التشفير المعتمد مع التسجيلات والمصدر والإيصال داخل معاملة واحدة. عناوين المتجر المتكافئة بعد التطبيع لا تؤدي إلى حذف النسخ المحلية.

تغيير وجهة المتجر يتطلب اعتمادين جديدين واختيار `replaceLocalCopies=true`. الفصل يحتفظ بالسلوك الوظيفي القائم لحذف النسخ المحلية، لكنه يتطلب `clearLocalCopies=true` صراحة. يجب أن تعرض الواجهة هذا الأثر في المراجعة قبل الإرسال. لا تنحذف إيصالات العمليات عند الفصل، ولا تطال الكتابة تيننتًا آخر.

تأكيد التنظيف البعيد منفصل عن تأكيد الحفظ المحلي. فشل حذف تسجيلات قديمة أو تلف اعتمادها يظهر `unconfirmed`؛ 404 موثّق من المزوّد يعني أن التسجيل غائب بالفعل. يمكن إصلاح اعتماد تالف بإدخال اعتمادين جديدين، مع بقاء التنظيف القديم غير مؤكد. فقدان تأكيد المعاملة النهائية لا يحذف التسجيلات الجديدة ولا يتراجع عن اتصال قد يكون حُفظ بالفعل.

## التحقق

- 297 حالة معزولة ناجحة: العقود، المدخلات والصلاحيات للمسارات المستقلة والمركبة، منع عنوان غير آمن، الأدلة السابقة ونقاط تحقق المزوّد.
- 41 اختبار MySQL ناجحًا، منها 14 جديدة للمسار الفعلي: ربط متزامن لمرة واحدة، تشفير، تبديل الوجهة، حفظ النسخ عند تطابق الرابط، فحص دون كتابات بعيدة، API فقط، فصل مع تنظيف غير مؤكد، 404، تعارض المنصات قبل الشبكة وبعد التسجيل، تغيّر الربط، سحب العضوية، فقدان تأكيد النجاح، تراجع حذف البيانات، وإصلاح اعتماد تالف أو الفصل به.
- أول اختبار تشفير كشف أن إعداد الاختبار لم يحدد مفتاح التشفير المحلي؛ أُضيف مفتاح اصطناعي خاص بالاختبار، وأعيدت المجموعة كاملة بنجاح. لم تتغير سياسة الإنتاج التي تشترط مفتاح التشفير.
- فحص الأنواع وبناء الإنتاج انتهيا بالرمز 0؛ البناء النهائي 14.67 ثانية، والحزمة الرئيسية 424176 بايت و126790 gzip ضمن الميزانية. بقي تحذير أحجام الحزم السابق.
- `git diff --check` ناجح. DNS وHTTP محاكيان والتيننتات مؤقتة؛ لا ربط أو فصل لمتجر حي ولا نشر.

## الحدود والتالي

أثر المزوّد والحفظ المحلي لا يشكلان معاملة موزعة. إذا نجح إنشاء أو حذف بعيد وفشل حفظ محلي، يبقى الإيصال غير محسوم ويتطلب مراجعة صريحة، دون إعادة تلقائية. الأدلة الأقدم التي تفتقد معلومات الحذف المحلي تُقرأ كغير معروفة بدل افتراض أن البيانات حُفظت أو حُذفت.

المسارات الجديدة لم تُربط بالشاشة بعد، وتبقى الكتابات القديمة لحين نقلها وإغلاقها معًا. التالي مراجعة تغيير حالة الطلب وإشعار العميل، ثم الصفحات الفعلية والموك أب وفحص الموبايل. لا ادعاء بفحص Safari فعلي أو اكتمال كل النظام.
