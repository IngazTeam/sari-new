# المرحلة 448 — حفظ تفضيلات الإشعارات

أضيف حفظ كامل للخيارات العشرة المطبقة، مربوط بالمستخدم والتيننت المختار وبصمة النسخة المقروءة. تُراجع العضوية وحالة الحساب والمتجر داخل معاملة مع أقفال؛ لا يستطيع المشاهد أو المشرف حفظ الإعدادات، ولا تتجاوز عضوية مالك ملغاة بالفولباك القديم. يرفض التبويب القديم الكتابة فوق نسخة أحدث، ويعيد قراءة النتيجة قبل اعتماد الحفظ. فشل الاتصال أثناء commit نتيجة غير مؤكدة، وليس دليل تراجع.

أضيف الترحيل 0204 بفهرس فريد لكل تيننت وحارس إصدار وفحص وجود الفهرس قبل الكتابة. لا يزيل الترحيل أي بيانات مكررة ولا يختار نسخة عشوائية؛ يتوقف عند التكرار حتى تُراجع السجلات مع نسخة احتياطية. طُبق مرة على قاعدة sari_pages_test المحلية فقط. لم تُفحص بيانات الإنتاج ولم يُنشر شيء.

تُرفض الأوقات غير الصالحة والهدوء بفترة صفرية، وتُحفظ القيم false كما هي. يمكن إصلاح الحقول المطبقة غير الصالحة دون تعديل قيم التجميع والإرسال الفوري القديمة غير المستخدمة. تعرض القراءة السابقة التكرار إن وُجد في مخطط لم يهاجر بعد.

التحقق: نجحت 86 حالة عقد/صلاحيات/أخطاء/تراجع للناقل، و29 حالة MySQL بينها حفظان متزامنان ورفض النسخة القديمة وعزل تيننت آخر، و47 اختبار حارس إصدار، وفحص TypeScript وبناء الإنتاج. لا اختبار إرسال خارجي أو اختبار اختراق شامل.

التالي: توصيل الشاشة الجديدة والموك أب بالحفظ المراجع، ثم تقاعد المسارات القديمة. المسارات get/update القديمة ما زالت قائمة مؤقتًا حتى نقل الواجهة؛ هذه المرحلة لا تدعي إغلاقها.
