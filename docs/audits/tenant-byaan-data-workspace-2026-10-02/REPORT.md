# واجهة بيانات بيان — المرحلة 295

استُبدلت صفحة بيان القديمة بمساحة موحدة من خمسة أقسام: نظرة عامة، المتدربون، أسئلة المعرفة، صفحات الأكاديمية، ونشاط المبيعات. تبقى أدوات مراجعة العمليات وإثباتاتها واستعادة نتيجة التسجيل السابقة متاحة. تُظهر العضوية الأقسام المسموح بها فقط. تُعزل الصفحة بهوية الحساب والتيننت، وتُرفض استجابات النطاق والفلاتر غير المطابقة، ولا يُعرض المحتوى القديم بدل خطأ القراءة أو الصلاحية.

القوائم مرتبطة بالمصدر الكامل: بحث، حالات، عدّ المخزون والمطابقات والنتائج، وصفحات25. تشمل المتدربين المؤرشفين والدورات وأخطاء البيانات؛ والأسئلة المعطلة والمستبعدة والمؤهلة؛ وجميع أنواع صفحات الأكاديمية. يُعرض المحتوى كنص عادي في بطاقات وتفاصيل قابلة للتمرير. لا يُنفذ HTML القادم من المصدر.

اختيار المعرفة يُراجع قبل الحفظ ويرسل بصمة السؤال، ثم يُتحقق من القراءة المحفوظة. تُحجب المحاولة التالية عند نتيجة غير مؤكدة حتى تحديث صحيح. تُغلق التفاصيل عند فشل الصلاحية، وتُهمل نتيجة الحفظ المتأخرة بعد تبديل التيننت. توضّح النصوص أن الاختيار للمزامنة القادمة ولا يثبت تحديث المعرفة الحالية.

طلب المزامنة يراجع نطاق الأكاديمية، ويحفظ معرّف الطلب محليًا قبل الإرسال. يدعم الاستعلام عن النتيجة ومتابعة المعرّف نفسه دون إعادة إرسال طلب محفوظ، وإنهاء المتابعة المحلية مع توضيح أنها لا تلغي طلبًا وصل للمزود. تتوقف المحاولة قبل الإرسال إذا تعذر حفظ المعرّف في المتصفح. تُعرض نتيجة آخر طلب للحساب نفسه، مع تمييز إيصال ربط سابق. لا تُسمى موافقة الطابور اكتمالًا للمزامنة.

- نجحت200حالة معزولة، ثم أُعيدت25حالة واجهة بعد معالجة عرض خطأ تخزين المتصفح. شملت اللغتين، الأقسام، الصلاحيات، العزل، HTML كنص، تغير البصمة، التحقق بعد الحفظ، الاستعادة، التكرار بالمعرّف نفسه، فشل التخزين، والنتائج المتأخرة.
