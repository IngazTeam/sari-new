# المرحلة 444 — تحقق مخرجات تحليل المعرفة

التاريخ: 2026-10-04. main. فحص محلي بمزود محاكى.

كان التصنيف يفحص نوع القسم فقط، ويعيد قائمة فارغة عند فشل المزود أو JSON، ويُرجع تحليل البيع JSON دون التحقق من حقوله. أُضيف عقد صارم للأقسام والحقول والثقة والأبناء المباشرين ومصفوفات نقاط القوة وإرشادات البيع والفرص. أي عنصر غير صالح يرفض النتيجة كاملة، قبل مرحلة الكتابات. يُقبل تغليف JSON واحد فقط وتُحفظ علامات الكود الموجودة داخل النص كما هي. يُرفض التداخل الأعمق من مستوى الأبناء الذي كان الكاتب يتجاهله، ويطلب prompt المستوى المدعوم صراحة.

فشل المزود أو التحليل أصبح خطأ ثابتًا لا يحتوي المحتوى أو رسائل المزود. التصنيف الصحيح الفارغ يظل قابلًا للتمييز، لكن الاستيعاب لا يعتبره معالجة مكتملة. مصفوفات البيع الصحيحة الفارغة مقبولة دون اختلاق إرشادات. أُضيف تحقق تفويض بعد رجوع كل استدعاء؛ فإغلاق المحاولة أثناء الانتظار يمنع الاستمرار إلى استدعاء آخر أو الكتابة.

راجعنا مستهلكي ingestContent: عقل ساري يسجل knowledge_processing_incomplete، ومسار تقارير الموقع يسجل تحذير knowledge، ومزامنة بيان ترجع فشلًا. لا نشر أو مزود حقيقي أو نسبة مبيعات مثبتة.

## التحقق

- 58 حالة أولية، ثم 135 حالة تراجع متداخلة ناجحة للعقد والمحرك والتشخيص ومسار الموقع والفهرسة والنافذة والتفويض.
- 16 حالة MySQL محلية ناجحة: لا أقسام محفوظة لمخرجات التصنيف أو البيع غير الصالحة؛ حفظ صحيح للمصدر والإرشادات مع فرص خاصة بالتاجر؛ منع النتائج المتأخرة والاستعادة.
- TypeScript والبناء ناجحان. لم تتغير مفاتيح الترجمة أو تخطيط الواجهة.

## المتبقي

قبول البنية لا يثبت صحة معلومات النموذج. لا تزال مراجعة قرارات دمج المعرفة والتعامل مع أبناء الأقسام الموجودة ضرورية؛ كانت بعض الفروع تتجاوزهم. الكتابات بعد بدء الدمج ليست معاملة واحدة، فلا ادعاء بتراجع كامل عند فشل مرحلة لاحقة. بقية الفجوات في سجل REMAINING، ولا تدقيق اختراق شامل.
