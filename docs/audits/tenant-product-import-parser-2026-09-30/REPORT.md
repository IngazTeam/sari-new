# المرحلة 84 — قراءة ملفات المنتجات ومراجعة أخطاء الصفوف

أضيف قارئ مستقل للمعاينة فقط؛ لا يكتب المنتجات ولا يستدعي مزودًا خارجيًا. لم يتحول مسار الرفع القديم بعد، وسيتم ذلك بعد حفظ المراجعة وإيصال الاعتماد وتحويل الشاشة والموك أب. لا نشر ولا تغيير في أعداد تغطية الصفحات.

## السلوك المحقق

- CSV: BOM، عناوين عربية وإنجليزية، فواصل مختارة صراحة، اقتباسات وفواصل وأسطر داخل الخانة، وتتبع رقم السطر الفعلي. رفض الاقتباسات المعيبة بدل تقسيم الصف خطأً.
- XLSX: فحص Base64 وحاوية Office وحدود الضغط قبل القراءة، اختيار ورقة محددة مع إظهار اسمها وحالة إخفائها. لا تُنفذ معادلات ولا تُقبل نتائجها المخزنة كقيم حقول. الروابط تُقرأ كنص عرض فقط.
- ربط 17 حقلًا تلقائيًا بالعناوين المعروفة أو بخريطة صريحة، مع كشف الحقول المكررة والاسم/السعر المفقودين والأعمدة غير الموجودة. الأعمدة غير المربوطة محفوظة في المعاينة ولا تُدمج خفية في الوصف.
- السعر نص عشري يتحقق منه عقد المحرر؛ السعر الفارغ خطأ مستقل والتكلفة لا تعوضه. الصفر الصريح مقبول، والمخزون الفارغ مجهول وليس صفرًا. العملة اختيار لازم، وحالة الاستيراد الافتراضية مسودة.
- أخطاء منفصلة لكل صف وحقل؛ الصف غير الصالح لا يحتوي بيانات قابلة للاعتماد. تكرار SKU داخل الملف بعد إزالة المسافات الطرفية وتجاهل حالة الأحرف يمنع جميع الصفوف المتكررة، دون اختيار فائز ضمني.
- حدود 5 MiB لـCSV و10 MiB لـXLSX، و5000 صف بيانات و60 عمودًا و16000 محرف للخلية و20 ورقة. بصمة SHA-256 تربط المحتوى والخيارات والعناوين والصفوف والأخطاء.

## التحقق

نجحت 49 حالة في `product-import-preview.test.ts` و`upload-boundary-pentest.test.ts`، تشمل ملفات Excel فعلية منشأة للاختبار وحدود الصفوف والخلايا، منع المعادلات، أخطاء القيم، الربط، تكرار SKU والأسعار الدقيقة. التشغيل معزول عن الشبكات الخارجية. لا يتطلب هذا القارئ قاعدة بيانات.

نجح فحص TypeScript وبناء التطبيق والخادم والعامل. ملفات التشخيص المحلية: `.tmp/tenant-ux/product84-tests.json` و`product84-ts.log` و`product84-build.log`.

## التالي وحدود الإثبات

حفظ مراجعة محددة العمر والنطاق، ترقيم المعاينة بدل إعادة إرسال الملف الكامل، إعادة فحص الصلاحية والمصدر وSKU عند الاعتماد، إدخال ذري وإيصال يمنع التكرار، ثم الواجهة الفعلية والموك أب وإغلاق الرفع القديم. لا يثبت هذا الفحص قابلية استخدام الشاشة أو Safari/iPhone أو استيراد Google Sheets أو التحليل الذكي؛ تبقى مراحلها مفتوحة.
