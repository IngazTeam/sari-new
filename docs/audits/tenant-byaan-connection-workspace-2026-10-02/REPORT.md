# واجهة إدارة بيان — المرحلة 290

استُبدلت صفحة ربط بيان القديمة بمساحة من التصميم الجديد: حالة الأكاديمية وخطوتها التالية، حفظ النطاق بأخطاء بجانب الخانة، تواريخ التوثيق والمزامنة، الأعداد الكاملة، أدوات فحص الاتصال والفصل، ودليل الربط والمسميات الست. روابط المتدربين والمعرفة وعمليات البيع وتجربة ساري متاحة بوضوح.

أُزيلت أصفار العمليات والإيرادات والسجل الفارغ المصطنع. تحيل الصفحة إلى مساحة بيان لقراءة العمليات الفعلية، وتوضح أن أعداد البيانات ليست إيرادات محصلة أو نسبة تحويل. لم يُحذف أي مصدر بيانات؛ لم يكن السجل القديم موصولًا بمصدر أصلًا.

لم يعد الفصل يحتاج مفتاح API مخزنًا في المتصفح أو طلب REST من الصفحة. يستخدم جلسة التاجر وصلاحياتها ومراجعة النطاق والبصمة، ويؤكد القراءة بعد التنفيذ. تحتفظ البيانات بعد الفصل. تُحفظ المدخلات عند الخطأ، وتُمنع إعادة الإجراء إذا كانت النتيجة غير مؤكدة حتى ينجح تحديث الحالة المعزولة. تتجاهل الصفحة الردود المتأخرة عند تغيير التيننت، ولا تثق برسائل المزود الخام. حالة إشعار التعطيل تعني الانتظار، لا وصول الإشعار.
