# المرحلة 324 — مزامنة WooCommerce المراجعة

## النتيجة

أضيف `requestReviewedSync` للمنتجات والطلبات، مع استعادة الإيصال وقراءة العملية المانعة وإقرار مراجعة النتيجة غير المحسومة. يشتق الخادم نوع العملية وبصمة محتواها؛ لا يقبل هوية تيننت أو مستخدم أو بصمة محتوى يختارها العميل.

قبول الطلب محفوظ قبل إطلاق التنفيذ. تكرار المعرّف نفسه يعيد الدليل المحفوظ دون إطلاق ثانٍ. بعد انتظار قفل WooCommerce، يعاد فحص العضوية والحساب وبصمة الربط والمهلة قبل فك الاعتمادات، وقبل DNS، وقبل إرسال كل طلب وبعد رده، وقبل الحفظ النهائي.

اللقطة الكاملة وسجل النجاح وتوقيت المزامنة والإيصال تُحفظ في معاملة واحدة. استُخرج كاتبا اللقطات المشتركان مع إبقاء حواجز الصلاحية وترتيب تحديث المزوّد في المسارات السابقة. إنهاء العملية المتعثرة لا يعدّل سجلًا ناجحًا بعد فقدان تأكيد المعاملة. لا يُستبدل المخزون المحلي بلقطة ناقصة أو عند سحب الصلاحية.

## التحقق

- 287 حالة معزولة ناجحة: العقد والمدخلات، بوابات المسارات المستقلة والمركبة، الصلاحيات ونقاط تحقق عميل المزوّد، والسجل والحماية السابقة.
- 40 اختبار MySQL ناجحًا، منها 12 للمسار الفعلي الجديد: منتجات وطلبات، قبول متزامن وإعادة الطلب، عزل التيننت، تغيير الاعتماد أثناء الانتظار وبعد DNS، سحب العضوية بعد الرد، انتهاء المهلة، لقطة ناقصة، فشل سجل النجاح، فقدان تأكيد القبول أو النتيجة، وفشل إطلاق العمل.
- `tsc --noEmit` انتهى بالرمز 0؛ بناء الإنتاج انتهى بالرمز 0 في 15.73 ثانية. بقي تحذير أحجام بعض الحزم المعروف؛ الحزمة الرئيسية ضمن الميزانية (424176 بايت، 126790 gzip).
- 108 اختبارات ناجحة لحارس الإصدار وانتقال النشر وأداة التحديث. أضيفت قدرة `woocommerce-reviewed-sync-0191` وتعليمات الترحيل والاستعادة إلى دليل الإنتاج.
- `git diff --check` ناجح. الاختبارات تستخدم تيننتات محلية مؤقتة وDNS وHTTP محاكيين؛ لا اتصال بمتجر حي ولا رسائل خارجية.

## الحدود والعمل التالي

واجهة WooCommerce القديمة لم تنتقل إلى المسار الجديد بعد، ولم تُغلق كتاباتها السابقة. حد جلب المزوّد الحالي 2000 سجل؛ تجاوز الحد أو نقص اللقطة يرفض الاستبدال. أعداد الإيصال تمثل السجلات المتحقق منها في اللقطة، وقد يحتفظ حاجز التوقيت بنسخة محلية أحدث لسجل موجود. اكتمال المزامنة لا يثبت لحظية المخزون البعيد.

بعد توقف العملية قسرًا قد يبقى سجل بدأ قبل التوقف بحالة running؛ الإيصال المنتهي يعرض نتيجة غير محسومة ولا يسمح بإعادة تلقائية. مراجعة الإشعارات يجب أن تحدد السجلات المقصودة بدل إغلاق جميع الحوادث. يليها الربط والفصل وأفعال الطلبات، ثم الصفحات الفعلية والموك أب وفحص العرض. لا ادعاء بفحص كل النظام أو Safari فعلي، ولا نشر.
