# سجل إشعارات الطلبات ودليل المزود

المرحلة 410، بتاريخ 2026-10-03. أضيف مصدر قراءة جديد للواجهة والموك أب، دون تغيير شاشة الإنتاج القديمة بعد: بحث حرفي، حالات الطلب والعامل والدليل، سلامة المراجع، ترتيب ثابت وصفحات من 25 سجلًا. لا يقتصر المصدر على أحدث 50 أو 100 إشعار. الإحصاءات تخص السجل كله ولا تتغير مع الفلاتر.

يعيد المصدر فحص صلاحية المستخدم وعضويته وحساب المالك وحالة المتجر داخل معاملة قراءة واحدة. تحفظ اللقطة توافق الإحصاءات والقوالب والصفحة. لا تُحوّل أخطاء المصدر إلى نجاح فارغ، ولا تُرسل تفاصيل أخطاء قاعدة البيانات للعميل. المدير يستطيع الإدارة؛ المشاهد ومشرف المبيعات يقرآن فقط؛ المتجر المعلق للتهيئة يقرأ دون إدارة. سحب العضوية أو تعليق المتجر أو إغلاق حساب المالك يمنع القراءة.

تُفصل حالة العامل `sent` عن دليل المزود. يتطلب الدليل إيصالًا للتيننت ومفتاح الإشعار نفسه، واتجاهًا صادرًا، وقناة تابعة له، ومطابقة حرفية للرقم ونص الرسالة ونوعها، ومعرف مزود ووقت متسقين. قبول المزود والتسليم والقراءة والفشل اللاحق حالات منفصلة. إيصال `mock` محاكاة فقط. لا يثبت أي منها دفع الطلب أو توصيله أو تحقيق بيع. رفض الإيصال لا يمحوه؛ يظهر السجل بلا دليل متحقق. هذا قارئ للدليل المسجل وليس فحصًا حيًا لدى المزود.

السجلات ذات طلب أجنبي أو مفقود تبقى معدودة كمرجع متعارض، مع حجب نصها ورقمها ودليلها ومراجعها عن القائمة والتفاصيل والبحث. تُحفظ القوالب الستة الافتراضية كاقتراحات غير مفعلة عند غيابها فقط، وتظهر القوالب الإضافية القديمة والقيم غير الصالحة بدل استبدالها تلقائيًا.

## التحقق

- نجحت 53 حالة للعرض الآمن، وعقود المدخلات والمخرجات، والصلاحيات والراوتر، والقوالب والعمليات السابقة.
- نجحت 27 حالة MySQL بلا تخطٍ، منها تغطية 106 إشعارات عبر خمس صفحات، البحث الحرفي، ثبات الإحصاءات، القوالب القديمة، الردود ذات نص أو رقم أو حالة أحرف مختلفة، الاتجاه الوارد، القناة الأجنبية والمفقودة، إيصال أجنبي، المحاكاة، تاريخ مستقبل أو أقدم من الإشعار، وطابور لم يثبت قبوله. تطابقت القائمة والتفاصيل والفلاتر والمجاميع. نُظفت المتاجر المؤقتة.
- نجحت أنواع التطبيق والبناء. لا ترحيل SQL أو إرسال خارجي أو نشر.

التالي منع الكتابة فوق تعديل متزامن، وإغلاق مجموعة مراجعة محددة، واستبدال الشاشة والموك أب ثم فحص الهاتف. العامل القديم ومسارا الكتابة القديمان ما زالا يحتاجان الاستكمال؛ وجود مصدر القراءة لا يعني اكتمال حمايتهما أو اكتمال تصميم الصفحة.
