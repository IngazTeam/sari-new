# موك أب إدارة بيان الفعلي — المرحلة 291

يستخدم مسار `/merchant/integrations/byaan` مكوّن التطبيق نفسه داخل الموك أب المركزي. يشترك مع مركز التكاملات في بيانات الربط والأعداد؛ يظهر تسجيل النطاق والفصل في الشاشتين، وتبقى البيانات المحفوظة عند الفصل. يقتصر التنفيذ على الذاكرة، بلا قاعدة تطبيق أو اتصال مزود أو إشعار خارجي.

أصبحت أمثلة الربط11مثالًا، منها بيان الموثق والمعلق والموقوف والمعطل وخطأ المزامنة والحالة غير المعروفة، مع تعارض المنصات وعدم الربط. تعمل مع20حالة عامة وتيننتين ولغتين. تتطلب الإجراءات المدخلات والبصمة نفسهما، ويحاكي التأخير والنتيجة غير المؤكدة والاستعادة؛ الانتقال بين الشاشتين يحفظ بيانات المثال، وتغيير المثال أو التيننت أو الحالة وإعادة التحميل يعيد البيانات.

كشفت المحاكاة تحذيرًا غير صحيح عند تحديث بيانات الربط بسرعة بعد حفظ النطاق. صُحح التحقق في المكوّن الفعلي ليؤكد النطاق والهوية والقراءة النهائية، دون اعتبار تحديث النسخة الناتج عن الحفظ تعارضًا بذاته. كما صُحح ترتيب CSS في بناء الموك أب وقوة قاعدة رابط النطاق لضمان ارتفاع44px.

## التحقق

- نجحت240حالة للمكوّن الفعلي ومحاكاة بيان ومركز التكاملات والخدمات والتنقل المركزي، ثم78حالة لعزل رسائل الإطار والوجهات والأمثلة الإضافية. التشغيل الأول كشف حالة الحفظ السريع، وصارت ناجحة بعد الإصلاح.
- نجح TypeScript للتطبيق ولحزمة المحاكاة. أُعيد بناء المحاكاة؛ نجح بناء التطبيق النهائي خلال12.09ثانية، وحزمة البداية424176بايت و126793مضغوطة. لم تضف المرحلة مفاتيح ترجمة؛ فحص المرحلة290 السابق12300استدعاء و880مفتاحًا ديناميكيًا ما زال مرجعها.
- فُحصت18حالة عرض صحيحة بالعربية والإنجليزية في480/390/320 وارتفاع568: الشاشة الموثقة، مراجعة الفصل، وحفظ نطاق جديد بانتظار التوثيق. جُرب الفصل وإعادة التسجيل في الحالات الست، وبقيت أعداد601/501/35/5 كما هي. المحاكاة لا تثبت عمليات حقيقية بهذه الأعداد.
- عرض محتوى الصفحة426/336/266 دون تمدد أفقي؛ أصغر زر/رابط44px بعد الإصلاح. نافذة الرابط الموثق تبقى داخل ارتفاع568، وتسمح بالتمرير الرأسي عند طول النص؛ لا تمدد أفقي في اللغتين. تحفظ الأدلة أيضًا القياس الأول35px قبل إصلاح ترتيب CSS حتى لا يُسجل نجاحًا.
- جُرب تبديل مثال التعطيل إلى خطأ المزامنة للتيننت270، والتنقل إلى المركز والعودة، ثم فتح تجربة ساري في الغلاف المركزي والعودة دون إطار لوحة مكرر. فُحصت المصادر والوجهات المسموحة آليًا، واستُخدمت Enter على روابط الإطار المتداخل في التحقق الحي.
- الأدلة في `.tmp/tenant-ux/phase291-tests.json` و`phase291-embed.json` و`phase291-responsive.json` وصور المراجعة والفصل والتسجيل. أُزيل ملف الإطارات وتبويبه المؤقت، وبقي الموك أب المركزي مفتوحًا.
