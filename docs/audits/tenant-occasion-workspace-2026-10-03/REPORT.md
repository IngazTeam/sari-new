# المرحلة 368 — واجهة حملات المناسبات

استُبدلت الواجهة القديمة بالتصميم المشترك للوحة التيننت. تعرض المناسبات الجارية والقادمة، ثم سجل التعريفات الكامل مع البحث والحالة والسنة وصفحات من25سجلًا. التاريخ بتوقيت الرياض، والسنة ميلادية، والمناسبات الهجرية وفق أم القرى.

حُفظت إمكانية عرض كل حقول السجل: التفعيل والحالة والخصم والكود والعداد القديم والقالب والأوقات والحملة المرتبطة، مع تفاصيل حالات طابور الإرسال. قبول المزوّد منفصل عن العداد القديم والتسليم والقراءة والمبيعات. القيم غير المعروفة لا تتحول إلى نجاح أو صفر افتراضي.

يُراجع تجهيز المناسبة قبل حفظها غير مفعّلة. يتطلب التفعيل أو الإيقاف مراجعة حديثة وإقرارًا، وتبقى تفاصيل العرض والجمهور والنص داخل قسم يمكن فتحه. لا تنفذ الواجهة إرسالًا فوريا. الخادم يعيد فحص الصلاحية والبصمة قبل الحفظ؛ الواجهة ترفض مراجعة أو نتيجة تخص حسابًا أو تيننتًا أو سجلًا آخر، وتوقف إعادة الطلب بعد نتيجة ملتبسة حتى تحديث الحالة.

فشل المصدر يخفي بياناته القديمة وتفاصيله المفتوحة. تغيير التيننت أو الفلاتر أو اللغة يلغي المراجعة المحلية، ولا تُقبل نتيجة مراجعة وصلت بعد تغيير السياق. أُضيفت العربية والإنجليزية بمفاتيح متطابقة، مع تسمية عربية لزر إغلاق النافذة وتركيز للعودة إلى العنوان والنتائج.
