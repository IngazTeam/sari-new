# المرحلة 521 — شاشة الفريق والمراجعات المشتركة

2026-10-04. التطبيق والموك أب محليان؛ لا نشر أو إرسال بريد حقيقي.

## النتيجة

أُزيل مكوّن الفريق القديم المعطل لفحص الأنواع، واستُبدل بمكوّن فعلي مشترك مع الموك أب. العربية والإنجليزية، أرقام الفريق والأعضاء المتاحين، بحث بالاسم والبريد، تصفية الأدوار، قائمة الدعوات وتصفية المعلقة والمنتهية، دليل الصلاحيات، وحالات تحميل وخطأ وجلسة وصلاحية صريحة.

حُفظت أسماء الأعضاء وبريدهم وأدوارهم وتواريخ الانضمام ومواعيد انتهاء الدعوات. لم يعد فشل القراءة يعرض فريقًا فارغًا. توثّق مطابقة الخصائص انتقال team.list إلى team.workspace دون تعديل خط الأساس.

## الإجراءات

| الإجراء | المراجعة والحماية |
| --- | --- |
| دعوة عضو | بريد متحقق بنفس قواعد الخادم، دور افتراضي مشاهد، شرح أثر الصلاحية، ثم مراجعة للمستلم والدور قبل الإرسال |
| تعديل الدور | إظهار الحالي والجديد، منع منح مالك من المدير، وحماية آخر مالك نشط قبل التنفيذ |
| إزالة العضو | توضيح فقدان الوصول لهذا المتجر وإلغاء الدعوات المرتبطة؛ حسابه الشخصي يبقى؛ منع حذف النفس |
| إلغاء الدعوة | توضيح تعطيل الرابط وأن العضوية المقبولة لا تُحذف بهذا الإجراء |

يشترط الخادم إقرار المراجعة لكل الإجراءات الأربعة، والدور السابق عند تعديل العضو أو إزالته. تتحقق الواجهة من الحساب والتيننت والهدف في الإقرار. لا تُعاد الكتابة تلقائيًا؛ النتيجة غير المؤكدة تقفل الإجراءات في الزيارة نفسها حتى يراجع المستخدم الحالة. قبول خدمة البريد لا يُعرض كإثبات لوصول البريد أو قبول العضوية.

الموك أب يستخدم نفس المكوّن مع بيانات داخل الذاكرة: الدعوة والتعديل والإزالة والإلغاء محاكاة فقط. لم يُرسل بريد أو تُمنح صلاحية فعلية عبر المتصفح. التطبيق الفعلي فُحص قراءةً بحساب التيننت المحلي.

- جرد 126 مسارًا و604 ملفات و2815 عنصر تحكم، دون مسار محذوف. بقيت أربع صفحات بموك أب عام، كلها للولاء.

## حدود الإثبات
