# مصدر Sheets المعزول — المرحلة 97

أضيفت products.sheetImport.connection/list لقراءة حالة الربط وقائمة الأوراق. تعتمد هوية المستخدم والتيننت من الجلسة، وتطلب products.manage مع إعادة فحص العضوية والحساب داخل المعاملة. لا يُقبل معرّف مصنف أو بيانات اعتماد من العميل. يُقرأ المصنف من سجل ربط التيننت فقط، والسجلات المتكررة تُرفض بدل اختيار أول واحد.

تحتوي هوية المصدر على رقم الربط والمصنف وبصمة تتغير عند تبدل رموز الاتصال أو إعداد OAuth. تُراجع الهوية والصلاحية قبل المصادقة وقبل جلب بيانات Google وبعدها، ويعيد المستهلك فحصها قبل إرجاع النتيجة أيضًا. مصدر كتالوج خارجي يمنع بدء الاستيراد. حالة الربط تميز غير المرتبط عن غياب بيانات الاعتماد وتعطيل OAuth؛ لا تدعي الحالة وحدها نجاح اتصال Google.

قائمة الأوراق لها حد30 قراءة جديدة في الساعة للتيننت. أخطاء الخادم والمزود ترد برسالة عامة دون SQL أو رموز. قارئ اللقطة الداخلية يستخدم الورقة المحددة وخياراتها ويعيد بياناتها من المزود فقط؛ لم تعرض له API عامة تسمح بحقن صفوف من المتصفح. لا كتابة منتجات أو معرفة أو بيانات Google.
