# المرحلة175 · تقاعد محاكاة الشخصيات القديمة

أزيل محرر الشخصيات اليدوي ومسارات إنشائه وتعديله وحذفه وترتيبه ومراجعته ومحاكاة توجيهه من assistant.js، مع أنماط CSS الخاصة به. صفحة الشخصيات المركزية تستخدم محرر التطبيق الفعلي المضاف في المرحلة174. لم تتغير صلاحيات التطبيق أو قاعدة البيانات.

بقيت صفحات خيارات المساعد واللغة والتدخل البشري وسياسات البيع ومركز الأدوات. تُقرأ إعدادات النسخة القديمة وسجل السياسات دون اشتراط وجود قائمة الشخصيات القديمة. معاينة المساعد مثال ثابت مستقل يحتفظ بالسؤال عند الفشل، مع توضيح أنه لا يستخدم نموذجًا ولا يقيس جودة المعرفة أو المبيعات.

التحقق: نجحت106حالات في سبعة ملفات، وفحص JavaScript. تضمنت حفظ خيارات الرد واللغة وسياسات البيع والتعارض، وعزل محرر الشخصيات الجديد واستعادته والإيصال. أضيف تحقق لقراءة الإعدادات القديمة ولسؤال يتضمن HTML دون تنفيذه. جرى فتح المعاينة فعليًا على4329 ومحاكاة الفشل ثم نجاح إعادة المحاولة مع بقاء السؤال. [لقطة النتيجة](store-preview.png).

لا تغيير في ملفات التطبيق يستدعي إعادة بناء الإنتاج في هذه المرحلة. لا ادعاء فحص Safari/iPhone الفعلي أو استدعاء مزود ذكاء. الخطوة التالية استعادة مسودات خيارات المساعد. لا دفع أو نشر.
