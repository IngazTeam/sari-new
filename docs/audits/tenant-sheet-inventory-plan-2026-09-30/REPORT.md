# المرحلة 104 — قواعد لقطة المخزون وخطة التغيير

أضيف قارئ وخطة خاصة بكميات المخزون، دون ربط API جديد أو كتابة بيانات في هذه المرحلة. فُصل قارئ خلايا Google المحدود والمتحقق من هوية الورقة والنطاق ليخدم مراجعة المنتجات ومراجعة المخزون معًا، مع الحفاظ على تفسير وبصمة لقطة المنتجات القائمة.

المخزون يطابق معرّف المنتج الصريح فقط. لا يعتمد الاسم ولا ينشئ منتجًا ولا يغيّر سعرًا. يعرض الإجراء والكمية الحالية والجديدة وبصمة المنتج، ويمنع المعادلات وخلايا الأخطاء والتواريخ والقيم المنطقية والأرقام الكسرية والسالبة والصيغ العددية الملتبسة. تقبل الأرقام العربية والفارسية والأعداد الصحيحة حتى 2147483647. الصفر قيمة فعلية، والفراغ ليس صفرًا.

المطابقة التلقائية تتطلب عمود معرّف وعمود كمية فريدين؛ يمكن تعيينهما صراحة مع منع اختيار العمود نفسه. العناوين الناقصة أو الملتبسة تمنع جميع الصفوف. كل تكرارات معرّف المنتج تمنع حتى لو كان أحد الصفوف غير صالح. المنتج غير الموجود في كتالوج التيننت يمنع دون كشف اسم أو بيانات منتج خارجي. يمنع المنتج الذي تديره منصة أو المخزون الحالي غير الصالح. المخزون الحالي null يبقى «غير معلوم» ويمكن مراجعته مقابل كمية محددة.

تبقى أرقام الصفوف الفعلية والقيم الأصلية، وتُذكر حدود 5001 صفًا شاملة العناوين و60 عمودًا. البصمة تشمل الأعمدة غير المربوطة والخلايا المعادلة وخريطة الأعمدة؛ لا تتغير لمجرد وقت القراءة. تغيير بصمة المنتج يغيّر خطة الاعتماد. لا يُسمح بنتيجة نجاح وهمية لورقة فارغة.

## التحقق

- 210 حالات ناجحة: 35 للمخزون و80 لقارئ/خطة/مزود المنتجات و95 لنموذج وحزمة استيراد الملفات وSheets.
- 41 اختبار MySQL لعزل المصدر والمعاملة والإيصالات القديمة ناجح بعد فصل القارئ المشترك.
- TypeScript وبناء التطبيق والخادم والعامل والموك أب ناجحة. لم تتغير مفاتيح الترجمة أو الصفحات؛ حزمة البداية ضمن الميزانية.
- رُصد اختلاف تمثيل boolean: بقي مقبولًا لحقل تتبع المخزون في استيراد المنتجات، ومرفوضًا ككمية في استيراد المخزون. أُصلح استخدام Set ليناسب target الحالي للمشروع دون تغيير إعدادات TypeScript.

لا مزود خارجي ولا ترحيل جديد ولا نشر. التالي حفظ مراجعة المخزون ومعاملة الكميات والإيصال ثم الواجهة والموك أب وإغلاق مسار الاستيراد المباشر القديم. ما زال القديم موجودًا حتى اكتمال بديله؛ لا ادعاء بأن جميع كتابات المخزون أصبحت مراجعة. يلي ذلك تصحيح DataSync ثم الفئات والخيارات والمتغيرات وبقية السجل.
