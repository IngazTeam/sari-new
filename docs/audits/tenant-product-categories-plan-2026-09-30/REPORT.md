# قواعد مراجعة فئات المنتجات — 2026-09-30

كشف الحصر أن CRUD الفئات موجود في الخادم دون أدوات إدارة مقابلة في الشاشة الحالية. الحقول: الاسم والاسم الإنجليزي والأب والترتيب والتفعيل. ربط الأب السابق لا يفحص التيننت أو الدوران، والحذف لا يفحص استخدام الفئة في المنتجات والفروع. هذه المرحلة تضع عقد الإدخال وخطة المراجعة المشتركة قبل ربط الخادم والشاشة.

الخطة تمنع الأب المفقود أو الأجنبي، والدورات، وتجاوز8 مستويات عند نقل شجرة، وتفعيل فرع تحت أب غير فعال أو تعطيل أب له فروع فعالة. تمنع تكرار أسماء الأشقاء بعد تطبيعUnicode، والمدخلات غير الصالحة والتغييرات الفارغة. حد اللقطة1000 فئة؛ تجاوز الحد يحتاج تعاملًا صريحًا في مصدر القراءة ولا يجوز إخفاء الباقي.

الحذف يتوقف عند وجود منتجات مرتبطة، بما فيها غير النشطة، أو فروع. إعادة التسمية تعرض عدد المنتجات المرتبطة، ولا تعيد كتابة أسماء الفئة النصية المخزنة في المنتجات أو البيانات الخارجية ضمنيًا. إصلاح رابط أب مفقود ممكن بنقله إلى الجذر. لا تغيير قاعدة بيانات أو نشر في هذه المرحلة؛ الخادم القديم باقٍ حتى ربط مصدر القراءة والكتابة الذرية وإيصال الطلب ثم إغلاقه.

التحقق:28/28 حالة تشمل النطاق والدورات والأب غير الفعال وعمق الفروع والتكرار وارتباط المنتجات وتصحيح البيانات السابقة؛ TypeScript ناجح. الخطة غير مربوطة بمداخل الإنتاج بعد.
