# المرحلة 114 — ربط Sheets بطلب صريح وجلسة محددة

كان getAuthUrl يعيد Promise غير منتظر ويعمل عند فتح الشاشة، وكان رابط العودة `/api/oauth/...` لا يطابق تركيب الراوتر `/api/auth/oauth/...`. استخدمت الحالة رقم التاجر، مع مدخل RPC منفصل يقبل الكود وحده. استُبدلت هذه المداخل ببدء صريح عند الضغط، بصلاحية integrations.manage ومعرّف جلسة فعّالة، وطلب عشوائي محدود بعشر دقائق يُحفظ ببصمته ويستهلك مرة واحدة قبل تبادل الكود.

مسار العودة الجديد هو `/api/auth/oauth/google/sheets/callback` على أصل التطبيق المعتمد في إعدادات الخادم. يجب تسجيل عنوانه الكامل في Google Cloud قبل تشغيل ربط جديد؛ لم نغيّر إعدادات Google الخارجية. إرشاد عنوان العودة القديم في صفحة إعدادات Google الإدارية يحتاج مواءمة في المرحلة التالية. توصي [وثائق Google الرسمية](https://developers.google.com/identity/protocols/oauth2/web-server) بمطابقة state قبل معالجة العودة لمنع تزوير الطلبات.

تُعاد قراءة صلاحية المستخدم والجلسة والاتصال وإعدادات OAuth قبل الاستهلاك وقبل حفظ النتيجة. محاولة قديمة لا تستبدل اتصالًا تغيّر أثناء انتظار Google. التبادل محصور في نطاق Google الثابت، بمهلة15 ثانية وحجم64KiB، دون تحويلات أو إعادة إرسال تلقائية، مع رفض رد دون رمز تجديد أو صلاحية Sheets معلنة مخالفة. لا تُعاد نصوص المزود أو الكود أو بيانات الاعتماد إلى صفحة العودة أو أخطاء العميل. الإلغاء يستهلك الطلب دون تغيير الربط.

عند نجاح تفويض جديد تُصفّر وجهة الجدول وجدولة التقارير السابقة لمنع توريثها إلى حساب Google آخر، مع توضيح ذلك للتاجر قبل بدء الربط. تظل بيانات الاعتماد بالتنسيق السابق المتوافق مع القارئات؛ هذه المرحلة لا تضيف تشفيرًا لقواعد البيانات ولا تدّعيه.

الترحيل178 يضيف جدول الطلبات فقط، وطبق في قاعدة الفحص المحلية دون تغيير سجل ترحيلات النسخة القديمة. نجحت36 حالة للمزود والراوتر والعودة وردود الواجهة، و20 حالة MySQL تشمل ست عودات متزامنة ورفض الجلسة المختلفة والإعادة والتقادم وسحب الصلاحية وتغيير الاتصال أثناء التبادل. نجح فحص الأنواع والترجمة (9995 استدعاء و451 مفتاحًا ديناميكيًا دون فقد) وبناء التطبيق والخادم والعامل وفحص حجم الحزمة. بقيت126 مسارًا و2023 عنصرًا محفوظة دون رابط غير صحيح أو يتيم.

التالي مصدر حالة الاتصال وإعدادات التقارير والفصل، ثم تصميم الشاشة والموك أب وإعداد الجدول، ثم بقية حصر التيننت. لم يحدث ربط Google فعلي أو نشر.
