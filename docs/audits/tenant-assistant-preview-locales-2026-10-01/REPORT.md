# المرحلة 182 — قواميس معاينات المساعد

كان بناء معاينتي الشخصيات وخيارات المساعد يطلب `merchantUx` من JSON القديم، بينما التطبيق يحمّله من وحدة منفصلة. أُضيف محمّل بناء مشترك للمعاينات الثلاث: الشخصيات، خيارات المساعد، سلوك المساعد. يقرأ القاموس الفعلي للعربية والإنجليزية، ويوقف البناء عند طلب نطاق غير موجود بدل إسقاطه بصمت. أزيل نطاقان غير مستخدمين كانا مطلوبين بأسماء غير موجودة في بناء سلوك المساعد.

فُحصت أنماط تحميل القواميس في موصلات المعاينة السبعة عشر؛ الويزرد يدمج وحداته المنفصلة بالفعل، ومعاينة الطلبات تستورد قاموس التاجر مباشرة. التعديل الحالي يصلح القواميس الثلاثة المذكورة؛ لا يُعد إثباتًا لتجربة كل حالة مرئية في جميع المعاينات الأخرى.

- 88 اختبارًا ناجحًا: القواميس الفعلية والنطاق المفقود، نماذج الشخصيات وخيارات وسلوك المساعد وتكامل السياسات والتنقل المضمّن.
- نجح بناء المعاينات الثلاث وفحص TypeScript للمسار الذي تغير وفحص JavaScript.
- فحص حي لتبويب المجموعات: ظهرت أوصاف الإشارة والموضوعات والتحويل والخصوصية كاملة، دون مفاتيح `merchantUx` خام. [الشاشة](groups-ar.png).
- لم تتغير ملفات التطبيق أو الحصر بهذه المرحلة، ولم يُشغّل مزود خارجي أو نشر.

التالي تقاعد محرر السلوك اليدوي ومطابقة مركز المساعد، ثم مراجعة مسودات سياسات البيع وبقية السجل.
