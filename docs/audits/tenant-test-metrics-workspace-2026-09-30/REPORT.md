# واجهة نتائج تجارب المساعد — 2026-09-30

استُبدلت شاشة MetricsDashboard القديمة في المسارين `/merchant/metrics-dashboard` و`/merchant/try-sari-analytics` بمساحة نتائج مشتركة. تقرأ لقطة واحدة من `testMetricsWorkspace.read` للتيننت المحدد بصلاحية `analytics.read`، وتخفي البيانات السابقة أثناء التحميل أو تغيّر الفترة أو المتجر أو فشل القراءة.

## مطابقة الخصائص

| الخاصية | العرض الحالي |
|---|---|
| اليوم / الأسبوع / الشهر | اليوم من منتصف الليل UTC، آخر سبعة أيام تقويمية، والشهر الحالي؛ البداية وآخر وقت مشمول ظاهران |
| المقاييس الخمسة عشر | سبعة عدادات وصفية لجلسات الاختبار، وثمانية مؤشرات عملاء غير مقاسة مع سبب غياب الدليل |
| القيمة وزمن الرد | القيمة التجريبية بوحدتها المحفوظة دون افتراض عملة أو قسمة على 100؛ الزمن المحفوظ بالمللي ثانية |
| العينة والمقام | ظاهران لكل مقياس مؤهل؛ المقام الصفري ينتج «غير متاح» وليس نسبة صفر مصطنعة |
| تقييمات الاختبار | الإيجابي والسلبي وغير المقيم من السجلات القديمة، دون تحويلها إلى CSAT أو NPS |
| جودة السجلات | عدد علامات الاتفاق الصالحة والتكرار والقيم المستبعدة وزمن الرد غير الصالح |
| احتراف المبيعات | غير مقاس؛ مع توضيح الحاجة إلى تقييم ردود ونتائج بيع موثقة |
| CSV | اللقطة المعروضة كاملة بمعاني المؤشرات والعينات والوحدات؛ دون نصوص المحادثات |
| التحديث والفشل | إعادة القراءة بنجاح مؤكد، منع التكرار، وعدم إظهار نجاح متأخر بعد تبديل الاختيار |
| الخطوات التالية | روابط تجربة المساعد، أداء السجلات الفعلية، ومصادر المعرفة |

## التحقق

- نجحت 28 حالة لاختبارات المكون والتصدير والمصدر في `tests.json`؛ تشمل منع البيانات القديمة/الأجنبية/ذات الفترة الأخرى، فشل التصدير والتحديث، المقام الصفري، والمحافظة على المقاييس الخمسة عشر.
- فحص TypeScript الكامل ناجح. الترجمة: 9032 استدعاءً و412 مفتاحًا ديناميكيًا دون مفاتيح مفقودة أو أخطاء استبدال.
- بناء Vite ناجح؛ تحذير حجم بعض الحزم قائم ومعروف.
- فُحص المساران في IAB على تيننت الفحص المحلي. اليوم فارغ؛ الأسبوع عرض 58 جلسة و4 رسائل وردين واتفاقًا تجريبيًا واحدًا بقيمة 149.5. تغيير الشهر والتحديث أظهرا نتيجة نجاح، وCSV أظهر «تم تجهيز ملف اللقطة»؛ حفظ الملف على الجهاز غير مثبت.
- قياس DOM الفعلي 2560 بكسل ثم 480 بكسل دون تجاوز عرض الصفحة. اكتُشف تداخل اختيار الفترة مع التحديث في العرض الضيق، وأُصلح بوضع الفترة في صف مستقل؛ جميع الأدوات بارتفاع 44 بكسل. الصورة `mobile-480.png` توثق الشكل المصحح.

## المتبقي

الموك أب للمسارين هو المرحلة التالية، ولذلك لا تتغير تغطية المسارات بعد. يلي ذلك توحيد `testSari.getMetrics` والحسابات القديمة. Safari/iPhone الفعلي و320/390 بكسل غير مثبتة في هذه الجولة، والنسخة الحية لا تتيح تبديل الإنجليزية؛ تحقق مفاتيحها واختبارات النصوص لا يساوي فحصها بصريًا. لا قياس مزود حقيقي أو نشر أو دفع تغييرات في هذه المرحلة.
