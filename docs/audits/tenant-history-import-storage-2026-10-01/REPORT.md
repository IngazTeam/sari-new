# المرحلة 230 — حفظ سجل المحادثات وعزل التيننت

استُبدل مسارا syncFromWhatsApp المكرران بخدمة واحدة وراء صلاحية whatsapp.manage، مع رفض أي تيننت أو رقم أو عنوان يحقنه العميل. بقي اسم المدخل وعقد نتيجته متوافقين مع الواجهة الحالية؛ وجود errors يعني نتيجة جزئية حتى مع success=true، وتعرضها النافذة الحالية كذلك.

تستخدم الخدمة الرقم الرئيسي النشط حصريًا، وتتحقق من تفويض المزود ورقم الجلسة قبل قراءة السجل. تتحقق مجددًا من هوية الرقم والرمز والمزود والتيننت داخل معاملة الحفظ. تغيير الاتصال أو تعليق المتجر يمنع كتابة السجل القديم. يرفض قفل MySQL تشغيل استيرادين متزامنين للمتجر نفسه، ويُحرر بعد الفشل أو النجاح.

كل محادثة تُحفظ مع رسائلها ضمن معاملة واحدة. لا تُحسب الإدراجات الملغاة، ولا تنشأ محادثة فارغة عند فشل المزود. يُحفظ النص كاملًا ضمن سعة التخزين والمرفق الآمن والتاريخ الحقيقي؛ التاريخ القديم لا يُرجع آخر نشاط المحادثة إلى الخلف، ولا يغير اسمًا اختاره التاجر أو حالة التدخل البشري. تحدد الخطة أو صلاحية التجربة الحالية سقف العملاء الجدد مع احتساب عملاء زد النشطين، ولا تُنشأ آثار إرسال أو توليد ذكاء اصطناعي من الاستيراد.

ترتبط هوية الوارد بالتيننت وحساب المزود وتتوافق مع طابور الاستقبال. تُفحص المعرّفات القديمة داخل التيننت، فلا يخفي تشابه معرّف متجر آخر رسالة هذا المتجر. لا تستهلك الخدمة رسالة جارٍ تنفيذها أو تنتظر المراجعة. يستخدم رد الموظف الحي وهوية الصادر المستورد المعرّف نفسه؛ اختُبر ترتيب الوصول في الاتجاهين. كشف MySQL أن Drizzle يغلف خطأ التكرار داخل cause، فأُصلحت معالجته بدل إعادة الخطأ بوصفه فشلًا غير معروف.

- نجحت 259 حالة للواجهة والعقد والصلاحيات وحصر الخصائص، و84 للاستقبال والتصعيد والتدخل البشري، و46 على MySQL تتضمن 26 للاستيراد؛ المجموع389 بلا فشل أو تخطٍ.
- نجح TypeScript والبناء. بقي126مسارًا دون إزالة مسارات أو روابط غير صالحة في الحصر. لم تتغير واجهة أو مفاتيح ترجمة.
- اختبارات المزود محاكاة، وقاعدة البيانات محلية ببيانات اختبار نظفت بعدها. لا استيراد من حساب حي ولا نشر، ولا فحص Safari فعلي في هذه المرحلة.

الحدود الباقية واضحة: الخدمة تستعيد ما يوفره المزود من آخر50رسالة متاحة لكل محادثة فردية؛ لا استرجاع كامل أو مزامنة حذف وتعديل، ولا مجموعات. العملية ما زالت مرتبطة بطلب HTTP؛ الحسابات الكبيرة تحتاج وظيفة خلفية مستديمة وتقدمًا قابلًا للاستئناف في مرحلة لاحقة. حُفظ الفاصل السابق200ms بين طلبات السجل. الرسائل غير المدعومة أو المحذوفة أو غير المؤكد إرسالها تجعل النتيجة جزئية. عدد المحادثات هو عدد المحادثات الجديدة المحفوظة، وليس عدد كل المحادثات التي فحصها المزود.

التالي: تدقيق عرض الرسائل والمرفقات والتواريخ على الهاتف، ثم ربط حالات المحادثات الحقيقية بالموك أب، ومتابعة بقية سجل الصفحات المفتوحة.
