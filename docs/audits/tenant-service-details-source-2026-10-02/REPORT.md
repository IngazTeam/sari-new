# المرحلة 267 — لقطة تفاصيل الخدمة

أُضيف `services.detailsWorkspace` بعضوية التيننت الحالية ومعرّف خدمة موجب صارم. يعيد تعريف الخدمة والبصمة وعلاقاتها وإجماليات الحجوزات وآخر10سجلات والتقييمات في معاملة قراءة واحدة بمستوى repeatable read، بدل القراءات المنفصلة في الصفحة القديمة. بقي API القديم للتوافق، ولم تُستبدل الواجهة بعد في هذه المرحلة.

- تعريف الخدمة يطابق عقد الكتالوج الحالي؛ `canManage` مشتق من إذن الإدارة عند الراوتر.
- الإحصاءات لجميع حجوزات الخدمة والتيننت، بما فيها حالة مجهولة صريحة. تُجمع في SQL؛ تُحد قراءة السجلات المعروضة بعشرة وبترتيب تاريخ الموعد ثم المعرّف تنازليًا.
- القيمة المالية هي مجموع السعر النهائي المسجل للحجوزات المكتملة ذات حالة الدفع `paid`، وليست إثبات تحصيل أو تسوية دفع. لا تدخل الحجوزات الملغاة أو غير المكتملة أو المستردة. إذا كانت إحدى القيم المؤهلة غير صالحة يصبح المجموع غير متاح ويُعاد عدد القيم غير الصالحة؛ لا يُعرض مجموع جزئي بوصفه كاملًا.
- التقييمات تشمل السجلات العامة الصحيحة من1إلى5 المرتبطة بحجز من الخدمة والتيننت نفسيهما. تُجمع بست مجموعات كحد أقصى، مع عدد المستبعد بسبب علاقة أو درجة تالفة. لا تعاد نصوص التقييمات أو هواتفها. يعبّر العدد عن سجلات التقييم؛ لا تدعي القراءة تفرّد العميل أو الحجز.
- آخر الحجوزات تعيد الاسم والهاتف المستخدمين في العرض، دون البريد أو الملاحظات أو بيانات التكامل. التاريخ يبقى يومًا تقويميًا دون تحويل المنطقة الزمنية. القيم غير الصالحة للوقت والتاريخ والمدة والسعر تُعاد فارغة صراحةً.
- عقد الاستجابة يفحص تطابق الخدمة، ومجموع الحالات، وحجم وعدد السجلات الفريد، وأعداد التقييمات، ودلالة المبالغ الفارغة. أعطال المصدر تُعاد برسالة آمنة.

نجح **149 اختبارًا معزولًا و16 اختبار MySQL**، مع فحص العضوية والمعرّفات ومحاولة تمرير تيننت مزور، واستبعاد حجوزات وتقييمات أجنبية، وحد10من13، وسعر صفر صحيح ومبلغ سالب وتقييم خاص ودرجة تالفة وعلاقات متناقضة. أُدخلت حالة/تاريخ موروثان غير صالحين في بيانات مؤقتة فقط، وأُعيد إعداد جلسة SQL فورًا ثم نُظفت البيانات. أثبت اختبار تزامن فعلي أن إدخال حجز وتغيير اسم الخدمة بعد أول قراءة داخل المعاملة لا يغيران اللقطة الحالية، بينما تظهر التغييرات في اللقطة التالية. نجحت الأنواع والبناء، دون تغييرات ترجمة أو مخطط قاعدة البيانات.

أدلة الفحص في `.tmp/tenant-ux/phase267-{tests,mysql}.json` و`phase267-types.log` و`phase267-build.log`. لا نشر أو اختبار Safari أو ادعاء اختبار اختراق شامل. التالي ربط وتصميم صفحة تفاصيل الخدمة ثم الموك أب الكامل للمسارات الست.
