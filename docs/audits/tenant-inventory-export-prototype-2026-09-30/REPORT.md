# المرحلة 113 — موك أب تصدير المخزون المطابق

تستخدم صفحة `/merchant/data-sync` مكوّن التطبيق الفعلي وخطة إسقاط المنتجات نفسها بعد نقل القواعد النقية إلى shared، مع19 حالة تشمل الاتصال والصلاحية وتغير الوجهة وحدود الكتابة وفقد الرد والإقرار غير المطابق. توجد25 عينة محلية، وبقاء تنبيه المحاولة عبر التنقل، وإعادة مثال بتأكيد صريح. تعرض روابط الجدول وجهة محلية قابلة للفحص مع إعادة التركيز إلى الرابط عند إغلاقها؛ لا تفتح Google ولا تنفذ أي طلب شبكة.

نجحت36 حالة جديدة للنموذج والحزمة المبنية، و272 حالة رجعية للاستيراد والتصدير والتخزين والواجهات، و132 حالة لحفظ المسارات والخصائص والحصر. نجح فحص أنواع التطبيق والموك أب وبناء التطبيق والخادم والعامل وحد الحزمة. في المتصفح بعرض DOM يبلغ480 ظهرت الكتابة المحلية ثم تنبيه فقد الرد، وتعطلت إعادة الإرسال، وعرضت الوجهة25 صفًا مع صفر صريح وكمية مجهولة وسعر غير موثّق فارغين، دون تجاوز أفقي. دليل الصورة: [الوجهة التجريبية](local-destination.png).

الحصر126 مسارًا و306 ملفات و2023 عنصرًا، دون مسار ساقط أو رابط غير صحيح أو ملف يتيم. التغطية75 موك أب عامًا و34 تفصيليًا جزئيًا و9 تفصيلية و8 تحويلات؛ هذه درجات تصميم وليست نسبة نجاح النظام.

الموك أب لا يثبت OAuth أو كتابة Google أو تشغيل Safari/iPhone. بيانات الوجهة التجريبية في الذاكرة؛ تنبيه المحاولة في sessionStorage ولا يعوض إيصال خادم دائمًا. لم يحدث نشر أو اتصال خارجي. التالي إعدادات الربط ثم الفئات والخيارات والمتغيرات وبقية سجل الصفحات.
