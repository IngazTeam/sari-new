# المرحلة 68 — إزالة مرسل التقارير المتروك وصدق أخطاء التخزين

أثبت البحث في مراجع التطبيق والخادم والعامل والسكربتات أن `server/notifications/scheduled-reports.ts` غير مستورد وغير موصول بعامل التشغيل. شاشة الإعدادات كانت تصرح أصلًا بأن الإرسال التلقائي غير متاح. لم تكن الأصفار المضللة في هذا الملف دليلًا على إرسال تقارير خاطئة للتاجر.

أزيل المرسل المتروك بدل تحويله إلى مسار إرسال جديد. كان يقرأ حقول `newToday` و`revenue` غير موجودة ويمررها إلى صفر، ويعامل الإجماليات بلا فترة فعلية، ويستخدم استيرادًا غير موجود تحت ts-ignore. أزيل معه `getOrderStats` الذي يحمل جميع الطلبات ويجمع العملات، والقارئان غير المعزولين `getScheduledReportById` و`getDueScheduledReports`. لم يوجد مستهلك فعلي بعد استبعاد هذا المرسل؛ استبدل اختبار MySQL قراءة المعرف بقراءة التاجر المعزولة.

حُفظت شاشة إعدادات التقارير وواجهاتها وسجلاتها. أصبح غياب قاعدة البيانات خطأً في القراءة والإضافة والتعديل والحذف، بدل قائمة فارغة أو معرف0 أو نجاح صامت. لا يُقبل إقرار إضافة دون معرف صحيح، وصار معرف التاجر إلزاميًا في التعديل مع فحصه قبل الوصول للتخزين وشرط ملكية دائم في SQL. بقيت حماية حذف سجلات التاجر نفسه.

## التحقق

- 60 حالة ناجحة لتخزين التقارير وحدود الصلاحية وموك أب الإشعارات وقراءة التقارير الحالية.
- 5 حالات MySQL ناجحة على تيننتين مؤقتين: حفظ مفاتيح false والقيم الجزئية، رفض أثر الكتابة على تيننت آخر، الحذف المعزول، وعقود الإعدادات المجاورة.
- فحص TypeScript نجح، ولم تبق مراجع المصدر للدوال والمرسل المزالين.
- بناء التطبيق والخادم والعامل نجح؛ لا تغيير في حزمة البداية للواجهة (103406 بايت gzip).
- فشل أول تشغيل لاختبارات موك أب الإشعارات الـ12 بسبب غياب MessageChannel في بيئة JSDOM بعد تحميل حزم React الجديدة. أُكملت بيئة الاختبار بـMessageChannel وTextEncoder/TextDecoder على غرار الاختبارات المجاورة؛ نجحت إعادة التشغيل دون تعطيل اختبارات أو اتصالات حقيقية.

## التالي والحدود

هذه المرحلة لا تشغّل إرسال التقارير ولا تغيّر البيانات التاريخية. السباقات بين قراءة إعداد وتعديله، ومراجعة النسخة وإيصالات الإنشاء الدائمة، وجدولة المناطق الزمنية، والإرسال الحقيقي ليست مكتملة بهذا التغيير. فشل إقرار الإضافة لا يثبت تراجع الكتابة؛ الإيصال الدائم يحتاج مرحلة مستقلة.

انتقل الفحص إلى تقارير المبيعات المستخدمة فعلًا: تجميع المبالغ بوحدتها الصحيحة، وعدم وصف قيمة طلب أو نسبة أعداد كتحصيل أو تحويل مثبت، ومصدر بنود المنتجات القديمة. التغطية والحصر البصري ثابتان؛ لا نشر.
