# المرحلة 106 — شاشة مراجعة المخزون

استُبدل نموذج استيراد المخزون المباشر بشاشة متوافقة مع تصميم اللوحة: اختيار الورقة، مراجعة كميات المنتجات المعروفة بمعرّفها، ثم موافقة صريحة وإيصال. تعرض أخطاء الصفوف والقيم الأصلية والكمية الحالية والجديدة، مع تمييز الكمية المجهولة من الصفر. ربط الأعمدة محصور في عمودين مختلفين للمعرّف والكمية؛ تغيير الربط يلغي الموافقة ويتطلب قراءة جديدة.

مرجع الاستعادة معزول بالمستخدم والتيننت في sessionStorage، ويُحذف عند تسجيل الخروج. يُحفظ UUID قبل التحضير وقبل الاعتماد؛ بعد فقد الرد، تبقى قراءة المراجعة والإيصال وإعادة الطلب نفسه متاحة. لا تُعرض بيانات مراجعة أو إيصال أثناء فشل المصادقة أو التحقق من نطاق التيننت. لا تسمح الشاشة بإزالة طلب اعتماد معلّق. المراجعات والإيصالات مرقمة بحد 20 صفًا في الصفحة.

أزيل النموذج القديم من صفحة المخزون. التصدير متاح برابط واضح لصفحة DataSync الحالية، ويحتاج مساره إلى التصحيح في مرحلة مستقلة؛ لم يُنفذ تصدير فعلي أو اتصال Google. كذلك ما زال API الاستيراد القديم موجودًا في الخادم لحين مرحلة إغلاقه بعد فحص المستهلكين.

## التحقق

- 244 حالة ناجحة: 27 لتفاعل شاشة المخزون والاستعادة، و20 رجعية لشاشة Sheets للمنتجات، و65 لقواعد المخزون وAPI، و132 لحصر الخصائص والحفاظ عليها.
- نجحت95 حالة رجعية لنموذج وحزمة موك أب استيراد الملفات وSheets بعد إعادة البناء بالتنسيق المشترك. موك أب المخزون نفسه هو المرحلة التالية.
- نجح TypeScript وبناء التطبيق والخادم والعامل وفحص ميزانية الحزمة. فُحص 9986 استدعاء ترجمة و451 مفتاحًا ديناميكيًا بلا مفاتيح مفقودة أو أخطاء استبدال.
- الحصر الحالي 126 مسارًا و304 ملفات و2015 عنصرًا و301 استعلامًا و32 قراءة صريحة و4 طلبات متصفح. لا روابط غير صالحة ولا ملفات صفحات يتيمة. ما زالت 132 إشارة خطأ غير مكتشفة آليًا و743 تسمية غير محلولة؛ هذه أرقام حصر وليست إثبات فشل أو اكتمال تفاعل.
- عوينت حالة التيننت المحلي غير المرتبط على 2560 ثم 480 بكسل فعليًا، دون تجاوز عرض المستند. روابط الإجراءات بارتفاع 46 بكسل. قياس 195 المطلوب من أداة المتصفح نتج عنه 480 فعليًا؛ لا ادعاء باختبار 320 أو390. صورة `local-480.png` تحتوي مساحة إضافية من أداة التصوير خارج مساحة المحتوى.

التغطية العامة بقيت 77 صفحة عامة و32 جزئية و9 تفصيلية و8 تحويلات. التالي مطابقة موك أب المخزون تفاعليًا ثم إغلاق API الاستيراد القديم وتصحيح DataSync. Safari وiPhone لم يختبرا فعليًا، ولا نشر.
