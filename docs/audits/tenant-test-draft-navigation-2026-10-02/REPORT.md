# مرحلة 348 — مسودة «جرّب ساري» عند التنقل

تحتفظ الصفحة الآن بالرسالة غير المرسلة وقيمة الصفقة غير المحفوظة والسيناريو في ذاكرة التبويب عند الانتقال إلى صفحة أخرى والعودة. يعزل المفتاح الحساب والتيننت، ويُراجع مرجع الجلسة قبل الاستعادة حتى لا يُنقل سؤال إلى جلسة مختلفة. الاستعادة لا تنشئ جلسة ولا ترسل رسالة أو تولّد ردًا.

عند الإرسال تُزال المسودة المرسلة؛ وعند تأكيد الصفقة تُمسح قيمتها غير المحفوظة. تسجيل الخروج يمسح الذاكرة ويمنع عمليات الكتابة المتأخرة من إعادتها. يظل تنبيه مغادرة المتصفح فعالًا حتى عند عرض صفحة أخرى فيها مسودة محفوظة في الذاكرة. النص لا يدخل localStorage أو sessionStorage أو الخادم.

أضيف شرح عربي وإنجليزي يوضح أن إعادة التحميل أو إغلاق التبويب يمسح المسودة. لا يشمل هذا الإصلاح استعادة عملية توليد غير مؤكدة أو استكمالها بعد مغادرة الشاشة؛ تلك مرحلة مستقلة ما زالت مفتوحة.

## أدلة الفحص

- 53/53 اختبارًا للواجهة والتحكم في جلسة التجربة والمسودة: التنقل، عدم الإرسال التلقائي، فصل الهويات والجلسات، نسخ القيم، إغلاق المتصفح، إزالة النص المرسل، ومسح الخروج ورفض الكتابات القديمة.
- 16/16 حالة إضافية لاستعادة الجلسة ومسح المعرفة ناجحة؛ تفاصيلها في `phase348-recovery.json`.
- TypeScript والترجمة والبناء ناجحة. فُحص 12,805 استدعاءات ترجمة و880 مفتاحًا ديناميكيًا دون نقص أو أخطاء معاملات. بناء التطبيق 18.98 ثانية مع تنبيه أحجام الحزم المعروف. أعيد بناء معاينة العقل لتتضمن نصوص الترجمة الحديثة.
- فحص التطبيق المحلي حيًا: كتابة مسودة، الانتقال إلى مركز المساعد، العودة إلى تجربة المساعد، وبقاء النص دون إنشاء جلسة. [لقطة الاستعادة](restored.png).
