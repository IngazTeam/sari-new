# ربط أدلة الاتفاق المحلي والقبض والاسترجاع

استكمال على `main` بعد `4c8c9c8c`. أضيف فاحص موحّد لأدلة طلب واحد يربط إنشاء الطلب المحلي بقبض Tap واسترجاعه الكامل. تبقى الخطة **4 مكتملة / 59 جزئية / 8 مفتوحة**؛ هذه قراءة مالية محدودة للأدلة المرصودة، وليست تقرير تحويل أو حكمًا بفوز تجربة.

## التنفيذ

- يقرأ `inboundOperations.salesOrderSettlement` دليل إنشاء الطلب ثم أدلة الدفع التي تطابق **النشاط ومعرّف الطلب المحلي ونوع الهدف**. لا يستخدم الهاتف أو رقم العرض أو metadata أو قيمة الفاتورة لدمج الطلبات. يعيد التحقق من بصمات الأدلة وحقولها المفهرسة وهوية العميل المجمدة والعملة وتسلسل أوقات التحقق المحلي.
- يفصل قيمة العرض عن المقبوض الفعلي ويعرض فرق الفاتورة بينهما؛ الفرق لا يثبت وحده خطأ محاسبيًا أو خصمًا أو ضريبة. يتبع مبلغ القبض دليل Tap، ولا يستبدله بسعر الكتالوج.
- يعرض دليل قبض واحدًا واسترجاعًا كاملًا واحدًا لنفس الدفعة والمبلغ والعملة والهدف. يرفض الاسترجاع اليتيم والتكرار وتراجع الساعة والتعارض؛ يقرأ صفًا إضافيًا لكشف السجل المتجاوز بدل اختصاره وجمع جزء منه. هذا الحد يتبع عقد المصدر الحالي ولا يدّعي دعم دفعات متعددة أو استرجاع جزئي.
- غياب القبض يعني `payment_not_measured` والمبالغ `null`، ولا يعني عدم الدفع أو إيرادًا صفريًا. بعد القبض يبقى الاسترجاع غير المقاس `null`؛ `observedNetMinor` صافي الأدلة المتاحة في القراءة فقط. الاسترجاع الكامل المثبت يعطي صافيًا مرصودًا صفرًا. تبقى اكتمالية المصادر وحالة الطلب الحالية والمساعدة البشرية والسببية غير مقاسة.
- طلب زد يعاد بحالة `external_link_unverified` دون البحث عن طلب محلي يحمل الرقم نفسه. ما زال اعتماد الرابط بين حساب زد وإسقاطه المحلي مطلوبًا؛ لا يجمع هذا الفاحص أموال سلة وبيان أو مصادر أخرى.
- يحمي الإجراء صلاحية السوبر أدمن في الجلسة، ثم يعيد فحص دور المستخدم وحالته النشطة من SQL ويحتفظ بقفل قراءة على صلاحية المستخدم حتى نهاية العملية. يستخدم قراءة مقفلة ومتسقة للأدلة تحت معاملة قصيرة. الأخطاء المعروضة بالعربية لا تكشف تفاصيل SQL أو بيانات العميل.
- لا يستدعي الذكاء الاصطناعي أو المزوّد أو واتساب، ولا يعيد تشغيل الإسناد، ولا يغير الدفع أو الطلب أو تخصيص التجربة أو الحصص. لا يحتوي الرد على الهاتف أو النص أو المفاتيح أو بصمة العميل. يمكن قراءة الدليل بعد حذف مصدر الطلب أو العرض أو الدفعة.
- تعرّف `evidenceSetDigest` محتويات مجموعة الأدلة المرصودة. إذا التحق استرجاع بعد قراءة الصفوف، تحتفظ القراءة الأولى بأساسها وتظهر بصمة جديدة في القراءة التالية؛ لا يصف الفاحص القراءة السابقة بأنها حالة نهائية مضمونة.

اختبارات المزوّدين محاكاة، وMySQL محلي ببيانات اصطناعية مع حجب الشبكة الخارجية. فحص الأمان عدائي محلي، وليس اختبار اختراق مستقلًا على الإنتاج أو إثباتًا لرفع المبيعات. لا واجهة جديدة أو رحلات متصفح جديدة لهذه الدفعة.

## التفعيل والمتبقي

لا ترحيل جديد؛ يعتمد الفاحص جداول الأدلة القائمة حتى `0126`. لم يُغيّر منطق الدفع أو سقف المنصة 100 دولار يوميًا أو اختيار OpenAI/ZahyPi. لم يحدث دفع أو نشر. التراجع بالكود لا يزيل بيانات ولا يحتاج عكس ترحيل.

1. اعتماد الروابط بين مصادر زد وسلة وبيان والطلب المحلي، وتغطية جميع مصادر الدفع بدل دمجها بالتخمين.
2. الإلغاء والتعديل وانتهاء الطلب، والمبلغ النهائي، والدفعات المتعددة والاسترجاع الجزئي والمساعدة البشرية وإثبات اكتمال المصادر.
3. واجهة التقرير الجامع والإسناد التجريبي بمقام وقطاع وعملة ونافذة ثابتة، وحفظ الحكم التجاري، وإثبات التسليم/القراءة والتعلم المعتمد والأثر الحقيقي.
