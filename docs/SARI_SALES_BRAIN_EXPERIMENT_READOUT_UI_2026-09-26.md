## العرض والتفاعل

- يبدأ التقرير بمرجع التاجر والخطة والقطاع ووقت اللقطة، ويفصل الخطة المسجلة عن المنسحبة دون اعتبار التسجيل دليل تشغيل حالي.
- تعرض بطاقتان مقام مجموعتي المقارنة والسياسة المرشحة، والحد الأدنى المجمد، والمتابعة المكتملة والمعلقة، ونقص العينة. لا استبعاد لعميل غير متعرض ولا اعتبار نافذة معلقة خسارة.
- تعرض التفاصيل القابلة للفتح تواريخ التسجيل ومدة متابعة كل عميل وموعد القرار بتوقيت UTC. بلوغ الموعد أو الحد الأدنى لا يولد نسبة تحويل أو إعلان فائز.
- تفصل بطاقات المال المجموعة والعملة والطلبات والحجوزات، وتعرض القبض والاسترجاع قبل القرار والصافي، ثم الاسترجاع اللاحق والصافي الذي يشمله. غياب الدليل يظهر بنص مستقل عن الصفر المثبت.
- حالات الإسناد المعلقة والتي تحتاج مراجعة وغير المسندة داخل النطاق تحجب المال، مع عرض أعداد الوقائع غير المحسومة. لا تعيد الصفحة معالجة الدفع أو الإسناد.
- تنسق SAR بالريال والهللة دون فقد آخر هللة حتى أكبر عدد صحيح آمن. تعرض العملات الأخرى بوحداتها الصغرى المسجلة مع تسمية صريحة؛ عقد المصدر لا يثبت مقياس تحويل كل عملة، لذلك لا يفترض العرض عدد منازل عشرية أو تحويلًا إلى ريال.
- تعرض ست بطاقات مالية في الصفحة، مع الوصول إلى كل البطاقات وأرقام موضعها. التصفح لا يغيّر مقام التجربة ولا يجمع العملات أو العملاء المتداخلين. اللقطة الجديدة تعيد موضع التصفح حتى إن صار عدد البطاقات أقل.
- تحفظ تفاصيل العد والبصمات مساحة العرض داخل أقسام قابلة للفتح بلوحة المفاتيح، ويوجد رابط للانتقال إلى أدلة طلبات التاجر نفسه. لا تصدير أو تشغيل أو اعتماد أو إرسال من هذه الصفحة.

## حماية القراءة

يستخدم المكوّن hooks `tRPC` و`React Query` الفعلية مع إلغاء الطلب عند الإزالة، ومنع الاحتفاظ بنتيجة قابلة للعرض بعد التحديث الفاشل أو توقفه لانقطاع الشبكة أو سحب الصلاحية. تعديل التاجر أو الخطة يزيل النتيجة فورًا، والتنقل برابط جديد يعيد النموذج والسياق معًا. إعادة تركيز النافذة تعيد القراءة والتحقق من صلاحية SQL. لا تعرض الواجهة تفاصيل الخطأ الداخلية.

يفحص عقد العرض الإصدار والهوية والنطاق والتواريخ والقيود والمجموعتين، واتساق العينة والمتابعة مع النافذة المجمدة، وحالة الإسناد، وتفرد المجموعات المالية، وحساب الصافي بالأعداد الصحيحة الدقيقة. يرفض أرقامًا مالية متناقضة أو مقياس تحويل أو فائزًا لم يدعمه العقد. هذا فحص توافق للعرض، ولا يستبدل صلاحيات SQL أو تحقق البصمات على الخادم.

أُضيف المسار إلى قائمة الخادم أيضًا، مع طلب HTTP فعلي يؤكد فتح الرابط المباشر بحالة 200. يبقى الوصول إلى بياناته محميًا في API حتى لو عُرض غلاف الصفحة.

## التحقق

نجحت **644 حالة دون فشل أو تخطٍ**: 467 حالة للعقود والأمان والعرض والمسارات، و177 حالة MySQL. منها **66 حالة عرض جديدة**. نجحت **105 رحلات متصفح حديثة**: 57 لواجهة التجارب و48 لصفحة أدلة الطلبات. نجحت فحوص الأنواع و7355 استدعاء ترجمة و244 مفتاحًا ديناميكيًا دون نقص أو خطأ استيفاء، وسجل الترحيلات والبناء. ثبتت بصمات **1920 ملف مصدر** قبل القبول النهائي وبعده؛ لا تُنسب هذه الأرقام إلى كامل اختبارات المشروع.

تستخدم اختبارات العرض بيانات باني التقرير الحقيقي: مجموعتان وعملات وأنواع عمليات، وعينة فارغة، وغياب قياس، واسترجاع كامل أو لاحق، وإسناد غير محسوم، ومتابعة معلقة، وبلوغ الحد الأدنى، ومبالغ كبيرة وتصفح عدة صفحات. حالة الانسحاب في fixture العرض تغيير وصفي فقط؛ إثبات انسحاب البروتوكول محفوظ في اختبارات MySQL.

يغطي المتصفح العربية والإنجليزية بعروض 320 و375 و390 و768 و1440 بكسل، ومدخلات عربية وفارسية، والقراءة بلوحة المفاتيح، وأهداف لمس لا تقل عن 44 بكسل وحقول 16 بكسل، وعدم التمرير الأفقي والحركة المخفضة. تشمل الحالات ردودًا متأخرة، وتغيير التاجر أو الخطة، والتصفح ثم التحديث إلى لقطة أصغر، وانتهاء الجلسة وسحب الصلاحية واستعادتها، والتوقف دون اتصال، والتحديث عند العودة للنافذة، ورفض نص حقن واستجابة غير متوافقة. تُمنع الطلبات الخارجية وتُرفض أي عملية كتابة من المكوّن المختبر.

أُعيدت اختبارات العقود والصلاحيات ومسارات SQL المتأثرة وفحوص الأنواع والترجمة وسجل الترحيلات والبناء، كما أُعيدت رحلات صفحة أدلة الطلبات القائمة. المشغّل `scripts/testing/verify-sales-experiment-readout.cjs --with-ui` يتحقق من ثبات بصمات المصدر قبل التشغيل وبعده ويحفظ أسماء الحالات وبصمات سجلاتها. تحتاج اختبارات SQL عنوان `SARI_TEST_DATABASE_URL` لقاعدة محلية مؤقتة فقط.

توقفت المحاولة الأولى للمتصفح لأن fixture لم يحمّل كتالوج `merchantUx`، فظهر مفتاح اسم القطاع الخام. كان المفتاح موجودًا في موارد التطبيق وفحص الترجمة ناجحًا؛ أُكمل تحميل الكتالوج في fixture بما يطابق التطبيق، ثم أعيد التحقق. لم يُتجاهل فحص المفاتيح ولم يُستخدم نص احتياطي لإخفاء المشكلة.
