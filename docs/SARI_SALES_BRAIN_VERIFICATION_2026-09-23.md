# مراجعة التنفيذ والمنطق والترجمة والأمان قبل الكوميت

آخر استكمال، 25 سبتمبر 2026، بعد 91f91fc9: **4 مكتملة / 59 جزئية / 8 مفتوحة**. أضيف حفظ إيصال وظائف ردود ZahyPi واسترجاع النتيجة والتكلفة من الوظيفة الأصلية بطلب قراءة فقط، مع عزل المهام والمتاجر ومنع تكرار التوليد. [التنفيذ والأدلة والحدود](./SARI_SALES_BRAIN_REPLY_RECOVERY_2026-09-25.md). ربط المحادثات الحية والتفعيل والإرسال والتعرض والدفع وقياس الأثر ما زالت مفتوحة. الأرقام أدناه تاريخية.

## النتيجة

راجعت بنود الخطة B001–B071 مقابل التنفيذ واختبارات النسخة المحلية، وأصلحت عيوباً إضافية في الطلبات والشخصيات والموافقة. **الحالة المحدثة: 4 بنود مكتملة، 56 جزئية، و11 لم تُغلق. لا اعتماد 10/10 ولا تصريح بجاهزية نشر كامل.** الاختبارات الناجحة تثبت الحالات المحددة، ولا تثبت أن نموذجاً فعلياً يبيع بإقناع أو أن كل الرحلات التجارية سليمة. التفاصيل التالية سجل المراجعة الأولى؛ نتائج الدفعة الحالية في التقرير المربوط أعلى الملف.

[مصفوفة البنود الكاملة](./audits/sales-brain-implementation-2026-09-23/acceptance-matrix.md) تعرض لكل بند المطلوب، والتنفيذ، وحدوده، والاختبار. ويحفظ [JSON المصفوفة](./audits/sales-brain-implementation-2026-09-23/acceptance-matrix.json) نص المتطلب الكامل. تبقى علامة البند غير محددة إذا لم تستوفَ شروطه المركبة كلها.

**3,711 نتيجة نجاح خام، تعادل 2,964 حالة فريدة بعد إزالة التكرار بين المجموعات.** الحزمة الأمنية تجمع اختبارات سلوك وهجمات على مدخلات ودوال فعلية مع عقود تفحص المصدر؛ ليست 2,231 محاولة اختراق لشبكة إنتاج. لم يُخف فشل فعلي أو يُتخطَّ اختبار حرج للحصول على العدد.

نتائج إضافية:

- TypeScript: نجاح دون أخطاء. البناء: نجاح للواجهة والخادم والعامل. حزمة الدخول 572,779 بايت، و171,282 بعد gzip، ضمن السقف.
- الترجمة: 5,781 استدعاء و213 مفتاحاً ديناميكياً؛ صفر مفاتيح ناقصة، وصفر أخطاء متغيرات، وصفر تعبيرات غير محلولة. هذا فحص مفاتيح، وليس اعتماداً لغوياً لكل نص المنتج.
- واجهة المكوّنين الحقيقيين: 16 حالة ناجحة في Chromium، RTL وعروض 320/375/390/768/1440، وحالات تحميل وفشل وإعادة محاولة وموافقة. لم يختبر Safari على جهاز iPhone ولا الرحلات المسجلة كاملة.
- MySQL محلي ببيانات مصطنعة: المهاجرات 0000–0063 مطبقة على قاعدتين معزولتين، إحداهما أُنشئت فارغة أثناء التنفيذ. `drizzle-kit check` ناجح.
- لا تغييرات في قفل الاعتمادات؛ Node 22.23.2 وpnpm 10.4.1. اختبارات المحاكاة تمنع الشبكة الخارجية ولا تستخدم مفاتيح الإنتاج.

يحفظ [ملف الأدلة](./audits/sales-brain-implementation-2026-09-23/evidence.json) أسماء الحالات، نتائجها، بصمات السجلات والملفات، ومعرفات Git blobs التي تسمح بمطابقة المصدر داخل الكوميت رغم تحويل نهاية الأسطر على Windows.

## نطاق الاختبار الأمني وحدوده

شمل التحقق المحلي تبديل معرف التاجر والعميل والمحادثة والرسالة والعرض؛ SKU من نشاط آخر؛ محاولات حقن SQL كقيم؛ أسعار وحقول وكميات مزورة؛ موافقة مشروطة أو سؤال؛ رفض متأخر؛ عرض غير مُرسل أو منتهي؛ تغيير الكتالوج وطريقة الدفع؛ تدخل موظف أثناء انتظار المزوّد؛ تزامن عاملين؛ إعادة الأحداث؛ انقطاع النتيجة؛ واستجابة مزوّد بمتجر أو عميل أو عملة أو رابط مخالف. شملت الحزم السابقة كذلك صلاحيات API، الويبهوكس، الملفات، الميزانية، عزل المعرفة، وعدم تضاعف نتائج Tap.

أُجريت قراءات عامة محدودة على الإنتاج دون تسجيل دخول، ضمن التصريح السابق. في [الفحص النهائي](./audits/sales-brain-implementation-2026-09-23/public-surface.json): الرئيسية وتسجيل الدخول 200؛ لوحة المخ وقائمة الطلبات 401/UNAUTHORIZED؛ رؤوس HSTS وCSP وnosniff ظاهرة. نتيجة 404 لمسار قديم في جولة أولى لم تُحسب إثبات منع صلاحيات؛ استُخدم مسار القائمة الصحيح في الجولة النهائية.

لم تُختبر حسابات الإنتاج أو عزل التجار عبر جلسات حية، ولم ترسل رسائل WhatsApp أو طلبات شراء أو أحمال أو هجمات أعطال إلى الإنتاج. لا يمكن لهذا الفحص العام أن يعتمد حماية كل النظام أو الإصلاحات المحلية التي لم تُنشر.

## نقاط تشغيل النسخة

تشغّل المهاجرات قبل العمال والنسخة الجديدة؛ فحوص البدء ترفض المخطط الناقص. لا يوجد push أو نشر ضمن هذا العمل. اتفاق زد ينشئ طلباً غير مدفوع لمراجعة فاتورته، ولا يضمن أن مجموع الكتالوج هو فاتورته النهائية أو أن المخزون محجوز. المنتجات ذات تخصيصات أو هدايا وبيانات غير مكتملة تحتاج توضيحاً ومراجعة، ولا تُخمن.

حالة زد `unknown`، أو `processing` المتروكة بعد تعطل العملية، توقف المحاولة الآلية التالية. يلزم فحص الطلب في زد قبل أي تسوية؛ **لا يُعاد ضبط الحالة إلى ready عشوائياً**. واجهة التسوية الآمنة لم تكتمل، وهذا قيد تشغيلي يمنع إعلان G5 مكتملة. كذلك ما زالت الجملة الواحدة الكاملة مطلوبة في استخراج عنوان زد؛ جمع التفاصيل متعددة الأدوار لم يعتمد.

إعادة التحقق محلياً:

```powershell
# اضبط SARI_TEST_DATABASE_URL على قاعدة MySQL محلية مصطنعة واسمها يحتوي test.
node scripts/testing/run-sales-brain.mjs --with-database --regression --security
node scripts/testing/verify-sales-brain-ui.cjs
node scripts/testing/write-sales-brain-acceptance.cjs
node scripts/testing/write-sales-brain-evidence.mjs
```

كاتب الأدلة يتطلب سجلات نجاح الأنواع والبناء والترجمة وفحص المخطط كما يوضح سجل التنفيذ. فحص الموقع العام أداة منفصلة ولا يعمل ضمن الاختبارات المعزولة أو CI.
