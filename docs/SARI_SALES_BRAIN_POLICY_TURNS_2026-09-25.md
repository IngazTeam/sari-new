# سجل اختيار سياسة التفاعل — 25 سبتمبر 2026

استكمال بعد `1711c834` للبنود B044 وB045 وB062 وB065. أضيفت طبقة تحفظ قرار السياسة لكل رسالة وتعيد بناء النص المختار من أدلته الحالية. هذا تحضير داخلي؛ التفويض السابق لا يبدأ إرسالًا تلقائيًا.

## التنفيذ

- يأخذ التحضير معرّف التخصيص وبصمته، والمحادثة والرسالة، وتقدير النية والنص الأساسي من مسار الخادم. المجموعة والمرشح والمصدر والوقت تُقرأ من التخزين المملوك؛ لا يقبل الطلب حقولًا تفرض المجموعة أو تمنح صلاحية توليد أو إرسال.
- تُقرأ حالة التفويض والمراجعات والمخرجات والسياسة والمزوّد والقطاع مجددًا، ويُطابق التخصيص مع نافذة الخطة وبصماتها. تعتمد صلاحية الاستخدام على نافذة ملاحظة العميل الأصلية، حتى بعد إغلاق التسجيل، دون إعادة شروط إدخال العميل أو إسقاطه من المقام عند تغير مرحلة الصفقة.
- يُبنى مقطع السياسة بواسطة `buildSalesTurnPolicy` نفسه، ويضاف اقتراح المرشح المراجع لمجموعته فقط. تُستبعد الإضافة عند رفض العميل أو مشكلة في طلب قائم؛ لا يتجاوز تقدير نية قديم هذه الإشارات في الرسالة المخزنة. لا يُستخدم كلام الموظف كسؤال سابق للبوت يمنح موافقة شراء.
- يحفظ السجل المجموعة والنية والهدف وسبب استخدام الأسلوب أو حجبه، وبصمات التخصيص والسياسة والمزوّد والقطاع والمصدر والنص المركب. يُخزن مقطع السياسة المراجع؛ أما النص الأساسي والرسالة الأصلية والرقم فلا تُنسخ إليه كحقول خام، ويجب التعامل مع البصمات كمعلومات مستعارة وليست إخفاءً مطلقًا للهوية.
- النص الأساسي هو سياق الخادم **قبل** إضافة السياسة المشتركة. الحد 128 ألف وحدة نصية و256 ألف بايت UTF-8. تُحفظ بصمته فقط، وتلزم البايتات نفسها عند إعادة البناء؛ تغيير المسافات أو النية تحت UUID محفوظ يرفض الطلب ولا يعيد كتابة القرار.
- قيود SQL وقفل المتجر يضمنان قرارًا واحدًا لكل رسالة وطلبًا واحدًا لكل UUID. ربط محادثة أخرى بالرقم نفسه والقرار الجديد يُحفظان في معاملة واحدة دون إعادة توزيع العميل. يبقى السجل بعد حذف الرسائل أو المحادثة؛ حذف أصل التخصيص أو المتجر يخضع لقيود الحذف التابعة.
- استرجاع إيصال قديم منفصل عن إعادة بناء النص للاستخدام. يظل الإيصال قابلًا للاسترجاع بعد فقد تأكيد commit أو الإلغاء، مع `eligibility: not_checked`. إعادة البناء تفحص المصدر والتفويض والحسابات والنافذة والمجموعة والمقطع المولد مجددًا؛ تلف النص المحفوظ لا يتحول إلى تعليمات مقبولة حتى مع إعادة حساب بصمته.
- تُرفض الرسالة القديمة أو الصادرة أو غير النصية أو الفارغة، والهاتف المختلف، والمحادثة غير النشطة أو المحولة لموظف، وتغير حد التحويل أو نسخته، والرسالة الأحدث. تُرفض أيضًا الرسالة المعالجة أو التي يوجد رد صادر بعدها، منعًا لتحضير قرار بأثر رجعي. تغيّر السؤال السابق للبوت يبطل النص المحضر.
- يُضاف الترحيل `0114` لسجل قرارات التفاعل دون backfill أو تفعيل أو تغيير سقف المنصة اليومي 100 دولار أو اختيار OpenAI/ZahyPi المركزي.

## الحدود والمتبقي

الخدمة داخلية، وليست endpoint جديدًا أو استدعاءً من مولّد الرد الحي. نجاح إعادة البناء يثبت اختيار النص عند لحظة القراءة فقط؛ تظل `generationAllowed` و`dispatchAllowed` و`exposureRecorded` بقيمة `false`. لا أدوات أو طلبات إلى المزوّد أو رسائل عملاء في هذه الدفعة.
