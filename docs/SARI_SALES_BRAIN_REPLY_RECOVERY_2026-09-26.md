# الاسترجاع الدوري لسجل الرد المعتمد

التاريخ: 26 سبتمبر 2026. الأساس: `beb969e6`، الفرع `main`.

تضيف هذه الدفعة عاملًا يسترجع سجل المحادثة من إيصال النقل المحفوظ بعد تعثر الحفظ أو إعادة تشغيل العملية. العامل لا يرسل إلى واتساب ولا يتصل بمزوّد الذكاء الاصطناعي، ولا يحوّل قبول النقل إلى نتيجة بيع أو تعلم.

## التنفيذ

1. أضيفت حالة استرجاع مستقلة عن حالة تفويض النقل في `ai_sales_reply_deliveries`: `pending` و`projected` و`review`. الترحيل `0121_sales_reply_projection_recovery` يضيف حالة الاسترجاع والمهلة والعداد والموعد والخطأ ووقت الاكتمال؛ لا يستهلك تفويضًا ولا يغيّر تاريخ الإرسال السابق.
2. يفحص العامل حتى عشر مهام كل دقيقة، ويعمل عند بدء العملية. يحجز المهمة داخل معاملة SQL قصيرة باستخدام `FOR UPDATE SKIP LOCKED` ورمز عشوائي ومهلة دقيقتين. لا تتداخل دوراته داخل العملية، ولا يستطيع عامل قديم متابعة حجز استبدله عامل آخر.
3. تُفحص مهلة العامل قبل قراءة دليل النقل، ثم مجددًا داخل كتابة الاكتمال نفسها. حفظ الرسالة ومرجعها وحالة معالجتها وحالة الاسترجاع يجري في معاملة واحدة؛ انتهاء المهلة أثناءها يعيد كل الكتابات، دون إسقاط جزئي.
4. يعتمد الاسترجاع على خدمة التحقق السابقة للنص والمستلم والحساب والتفويض والإيصال وحجز الرد. لا يستخدم النص أو رقم الهاتف من طابور العمل كتعليمات جديدة. الرد المقبول يُسجل مرة واحدة؛ قبول المزوّد ليس إثبات وصول أو قراءة أو شراء.
5. عند تعذر التخزين أو بقاء النقل مجهولًا، تؤجل المحاولة تدريجيًا، بحد أقصى ثماني محاولات. تنتقل الأدلة المتناقضة أو النقل المرفوض أو الفاشل إلى `review`، وكذلك الحجز المستنفد. لا يوجد إعادة إرسال أو توليد أو تحرير تلقائي للرد أو فتح حجز بديل.
6. إذا ضاع إقرار حفظ الحجز لا يبدأ إسقاط غير مثبت؛ تبقى المهلة قابلة للاسترجاع. وإذا ضاع إقرار حفظ المحادثة بعد الالتزام، تبقى الحالة `projected` ولا تنشأ نسخة ثانية. أُثبت الاسترجاع من عملية Node جديدة دون محاكاة قناة النقل داخل تلك العملية.
7. رُبط العامل بعامل الرسائل القائم، مع فحص الجداول والقيود قبل التشغيل. ينتظر الإغلاق عمله الجاري، وتُغلق العوامل السابقة إذا فشل تشغيله. لا تُطبع تفاصيل أخطاء التخزين أو بيانات العملاء في السجل.
8. أضيفت قراءة تشغيلية `inboundOperations.salesReplyRecoveryHealth` للسوبر أدمن، مع إعادة فحص دور الحساب وحالته من SQL. تعرض أعداد المهام والحالات المستحقة وعمر أقدم سجل فقط؛ لا نصوص أو أرقام أو معرفات تفويض أو رموز مهلة. تُحجب الجلسات غير الإدارية وتُختصر أخطاء التخزين برسالة عامة.
9. لم تُمدد سياسة الاحتفاظ ببيانات النقل. إذا حُذف `request_json` وفق التنقية الحالية قبل الاسترجاع، يرفض العامل اختلاق الدليل ويُحيل السجل للمراجعة. اكتمال الاسترجاع يمنع اختياره مجددًا، لكنه لا يحل تلقائيًا سياسة الأرشفة وإثبات النقل التاريخي بعد التنقية.
