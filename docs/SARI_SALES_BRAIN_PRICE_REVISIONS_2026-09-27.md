# إصدارات أسعار الذكاء الاصطناعي وتدقيق اعتمادها

التاريخ: 27 سبتمبر 2026. أساس الدفعة: `1271987fb31add5c840237aa9669a800cbedf71c`. تستكمل هذه الدفعة البند **B052** في [خطة مخ المبيعات](./SARI_SALES_BRAIN_10_OF_10_PLAN_2026-09-23.md).

## المشكلة والنتيجة

كان السوبر أدمن يستطيع استبدال بطاقة سعر، بما فيها سعر إصدار سبق استخدامه، دون تاريخ تعديل أو هوية مشرف أو مرجع اعتماد. لم يكن النموذج يمنع الكتابة فوق تعديل مشرف آخر. حجوزات الاستدعاءات كانت تحفظ أسعارها الأصلية بالفعل؛ لم يُعد تصميم هذا السلوك أو تغيير تكلفتها.

أصبحت كل كتابة جديدة معاملة تحفظ إصدارًا مؤرخًا ومرجع اعتماده وهوية المشرف، وتحدّث البطاقة الحالية معًا. جدول `ai_price_card_revisions` سجل إضافي؛ لا توجد واجهة لتعديل صفوفه أو حذفها. يتأكد الحفظ من صلاحية المشرف وحالة حسابه في قاعدة البيانات، ويحتفظ بقفل الصلاحية أثناء المعاملة.

| الحالة | السلوك |
|---|---|
| أول بطاقة | `expectedRevision: null`، مع إصدار جديد ومعرّف طلب ومرجع اعتماد |
| تعديل بطاقة | يجب أن تطابق بصمة البطاقة التي فتحها المشرف آخر بطاقة محفوظة |
| مسودتان متعارضتان | تُقبل واحدة فقط؛ تُرفض الأخرى دون تغيير البطاقة أو سجلها |
| إعادة طلب مطابق | تعاد نتيجة الإصدار المحفوظ نفسه؛ لا يكرر السجل ولا يعيد تفعيل إصدار قديم |
| استخدام معرّف الطلب بمحتوى أو مشرف مختلف | يُرفض كتعارض |
| إعادة اسم إصدار سابق | يُرفض؛ العودة إلى أسعار سابقة تحتاج إصدارًا جديدًا |
| فشل كتابة البطاقة | تتراجع كتابة السجل والبطاقة معًا |
| فقد تأكيد المعاملة بعد حفظها | يثبت الطلب نفسه النتيجة دون تكرارها |
| سعر قديم قبل هذه الهجرة | تُؤرشف حالته عند أول تعديل؛ لا ينسب إلى مشرف أو تاريخ اعتماد غير معروفين |
| حجز استدعاء سابق | تُستخدم نسخة الأسعار المثبتة داخل الحجز، حتى لو تغيّر السعر أو عُطلت البطاقة لاحقًا |

السجل يعرض أحدث 20 إصدارًا مع تنقل إلى الأقدم. تصدير JSON يشمل **الصفحة المعروضة فقط**، ويصرح بنطاقه ومعيار الصفحة. لا يصدّر مفاتيح المزوّد أو محتوى المحادثات أو بيانات طلبات الذكاء الاصطناعي. تفاصيل السعر مركزية للسوبر أدمن ولا تنتقل إلى شاشة التاجر أو العميل.

## الواجهة وحالات الفشل

فصلت إضافة البطاقة عن إنشاء إصدار تعديل. عند تعديل بطاقة تُثبت هوية المزوّد والنموذج وتُطلب تسمية إصدار جديدة. النموذج يقبل ست منازل عشرية ويعرضها دون تقريب السعر الصغير إلى صفر.

تُقفل المسودة عند الإرسال وعند فقد تأكيد النتيجة. إعادة المحاولة تستخدم المحتوى ومعرّف الطلب نفسيهما. يوجد إجراء صريح لإلغاء المسودة وإعادة تحميل الحالة الحالية؛ فشل التحديث يبقي النموذج مقفلًا. بعد نجاح طلب محفوظ سابقًا توضح الرسالة أن الإجراء لم يعد تفعيل سعر قديم. إذا تعذر التحقق من السجل تُخفى بياناته السابقة ويتعطل تصديرها.

أضيفت مفاتيح إدارة الميزانية الإنجليزية التي كانت مفقودة، مع مفاتيح السجل والاعتماد باللغتين. راجعت الواجهة على عروض 320 و375 و390 و430 و768 و1440 بكسل، مع مناطق لمس 44 بكسل، وإدخال مناسب للجوال، ولوحة المفاتيح، والنصوص الطويلة، وHTML معروض كنص.

## الترحيل والتشغيل

الهجرة `0134_ai_price_revisions` إضافية. لا تعيد تسعير الحجوزات، ولا تعدل البطاقات القديمة، ولا تغيّر سقف المنصة **100 دولار يوميًا**. يسجل فحص المخطط الجدول الجديد، وتحميه قائمة الجداول في أدوات التشغيل. البيانات التاريخية تبقى عند حذف البطاقة أو حساب المشرف؛ لا توجد علاقة حذف متسلسل تمحو التدقيق.

بعد النشر تُستخدم شاشة إعدادات الذكاء الاصطناعي للاعتماد. أدخل الأسعار من المرجع المعتمد فعليًا؛ لا توجد أسعار GPT أو ZahyPi مخمنة أو مزروعة في هذه الدفعة. يحتاج حتى تعطيل البطاقة إلى إصدار جديد ليبقى سبب التغيير موثقًا.

البديل التشغيلي `scripts/configure-ai-price.ts` يقبل الآن ملفًا يحوي حقول السعر السابقة إضافة إلى `requestId` بصيغة UUID و`expectedRevision` من القراءة الحالية أو `null` للبطاقة الجديدة و`reference`. يتطلب التطبيق `--apply --actor-id <active-admin-id>` في بيئة تشغيل محملة بمتغيراتها؛ يتحقق من الحساب في قاعدة البيانات. الاعتماد بالـCLI عملية لمشغل ذي وصول إلى قاعدة البيانات؛ رقم المشرف ليس وسيلة تسجيل دخول مستقلة. التشغيل دون `--apply` يتحقق من الملف فقط. يجب عدم تغيير محتوى ملف طلب غير مؤكد أو معرّفه قبل مراجعة نتيجته.

## التحقق

تسجل البوابة `scripts/testing/verify-ai-price.cjs` بصمات المصدر قبل وبعد التنفيذ، واختبارات الصلاحيات وعقود الأسعار والميزانية ومزوّدي الذكاء الاصطناعي والتسوية، واختبارات MySQL، والأنواع والترجمة والمخطط والبناء وحارس النشر، ورحلات المكونات الحقيقية مع API اصطناعي.

اكتملت البوابة على المصدر الثابت: **379 حالة اختبار ناجحة** (258 للوحدات والأمان و121 على MySQL)، و**46 رحلة متصفح** بالعربية والإنجليزية. نجحت الأنواع والبناء وحد حزمة الواجهة وفحص Drizzle، و20 اختبارًا لحارس النشر. تحقق مدقق الترجمة من 7,622 استدعاء و248 مفتاحًا ديناميكيًا دون فقد أو خطأ استيفاء. نجحت خمس حالات ترحيل تشمل إنشاء قواعد فارغة حتى 135 ترحيلًا، والترقية من 0131 للصوت، ومن 0132 لمراجعات الفريق، ومن 0133 للأسعار، مع إعادة تشغيل DDL وحفظ البيانات. تحفظ [الأدلة التفصيلية](./audits/sales-brain-implementation-2026-09-23/price-revisions-verification.json) 2,010 بصمة مصدر والنتائج وأسماء الحالات.

شُغلت أيضًا ثلاثة [فحوص CLI محلية](./audits/sales-brain-implementation-2026-09-23/price-revisions-cli.json): التحقق الجاف دون قاعدة، رفض التطبيق بلا مشرف قبل الاتصال، ورفض حقول هوية مشرف داخل بيانات السعر. لا تدخل هذه الفحوص الثلاثة في عدد اختبارات Vitest أعلاه.

مصفوفة الخطة أصبحت **4 مكتملة / 60 جزئية / 7 مفتوحة**؛ لم يغلق البند المركب B052 بالكامل.

تعيد هذه الأوامر الفحص باستخدام قواعد **اختبار محلية اصطناعية فقط**، مع خادم الترحيلات المملوك على المنفذ 33089 والدليل `.tmp/staff-migration-mysql/data`:

## الحدود والمتبقي

السجل إضافي وغير قابل للتعديل عبر واجهة التطبيق، وبصماته تكشف اختلاف البيانات المفحوصة. ليس مخزنًا خارجيًا لا يمكن لمسؤول قاعدة البيانات تغييره، ولا يستطيع إعادة بناء تاريخ أسعار حُذف أو استُبدل قبل هذا الإصلاح. تعديل البطاقة مباشرة خارج مسار الاعتماد يؤدي إلى رفض التعديل التالي عند اختلافها عن آخر إصدار محفوظ؛ لا يُصلح هذا الاختلاف تلقائيًا.

أثناء تحديث إصدار قديم، أوقف تعديلات الأسعار الإدارية حتى تحميل الواجهة والخادم الجديدين. الكتابة من كود قديم أو SQL مباشر تتجاوز سجل الاعتماد الجديد. الرجوع إلى كود قديم لا يحذف السجل، لكنه لا يوفر ضمانات الحفظ الجديدة؛ راجع أي اختلاف قبل اعتماد سعر آخر.

يبقى **B052 جزئيًا**: لم تُنفذ تنبيهات الاستهلاك الداخلية عند 70% و90% في هذه الدفعة، ولم تُعتمد أسعار المزوّد الفعلية أو فعالية حد التكلفة على الإنتاج. لا يمثل اختبار Chromium اختبار Safari أو جهاز iPhone فعليًا. اختبارات الأمان هنا محلية محددة النطاق، وليست فحص اختراق إنتاجي مستقلًا.

تبقى بقية بوابات الخطة، ومنها التكامل الحي وقياس النتائج البيعية، مفتوحة حسب مصفوفتها. لم يتم Push أو نشر على الإنتاج في هذه الدفعة.
