# تسوية الاستهلاك المحفوظ بعد توقف العامل — 24 سبتمبر 2026

استكمال بعد الكوميت 0d758fdb. كان فشل تسوية التكلفة بعد حفظ الرد يترك مبلغًا محجوزًا يحتاج تدخلًا ماليًا منفصلًا، لأن أرقام الاستهلاك قد تضيع بموت العامل. أصبح الاستهلاك يُحفظ على حجز الميزانية نفسه قبل التسوية، ويتولى عامل SQL إتمام المحاسبة من هذا السجل.

## التنفيذ

- إيصال ثابت للتوكنات الداخلة والخارجة ووقت استلامها، مرتبط بمفتاح الحجز ومعرّف الطلب والنشاط والمزوّد والنموذج والعقد. لا ردود أو محادثات أو أسرار في السجل المالي.
- الحفظ يرفض الأرقام السالبة والكسرية وغير الآمنة، وتغير هوية المحاولة، وتغيير الاستهلاك المحفوظ ولو بقي مجموع التكلفة مساويًا بسبب السعر الثابت. التكرار المطابق لا يحرك موعد التسوية أو حجز العامل.
- قيد SQL يمنع الإيصال الجزئي، ويحد القيم إلى الأعداد الصحيحة الآمنة. الحفظ محدود بثلاث محاولات SQL إجمالًا للأعطال المؤقتة، بفاصل 100 ثم 300 مللي ثانية خارج المعاملات. لا تكرار لتوليد الرد.
- مسار الميزانية المشترك يحفظ الاستهلاك بعد محاولة تسليم الرد للتطبيق وقبل التسوية. حتى إذا فشل تسليم الرد، يُحفظ الاستهلاك المتاح ثم تعاد رسالة خطأ مالية آمنة؛ يحتفظ العامل بأهلية تسوية الاستهلاك الفعلي. غياب الاستهلاك لا يتحول إلى صفر.
- مسار استرجاع نتائج ZahyPi يحفظ الاستهلاك أيضًا بعد قبول الرد المحفوظ. لم يعد استبدال خانة التعلم بعد الإنجاز يفقد أهلية التسوية، لأن السجل المالي مستقل عنها.
- عامل يبدأ ويتوقف مع runtime، بدورة كل دقيقة، ودفعات حتى 20، وحجز ثلاث دقائق وSKIP LOCKED. المعالجة SQL فقط، دون HTTP أو إنشاء حجز مالي أو إرسال رسالة. تعطل تسوية يؤجلها تدريجيًا حتى ساعة دون منع بقية الدفعة.
- التسوية تستخدم أسعار الحجز الأصلية وفترته الأصلية، حتى بعد عبور اليوم أو تغيير بطاقة السعر. تحديث مبالغ النشاط والمنصة وحالة الحجز ومسح الجدولة يتم في معاملة واحدة.
- حراسة العامل تُفحص بعد أقفال المحاسبة: رمز الحجز والطلب والنطاق والاستهلاك ومدة الصلاحية. العامل المنتهي لا يسوي ولا يؤخر محاولة بديلة. فشل أو فقد إقرار commit لا يكرر الخصم.
- التسوية الموثقة التي اعتمدها السوبر أدمن تبقى كما هي، بقيمتها ومرجعها وهوية منفذها. إذا سبقت العامل، لا يعيد استبدالها باستهلاك النموذج. التعارض يبقى محافظًا على السجل القائم.
- اختيار OpenAI/ZahyPi وسقف المنصة اليومي 100 دولار لم يتغيرا. تسوية استهلاك سابق عملية محاسبية محلية تستمر حتى لو تغير إعداد المزوّد؛ لا تنشئ استدعاءً جديدًا.
