# ساري — مقترح لوحة التاجر

موك أب عربي RTL مستقل، قابل للتصفح والتفاعل، مع تقرير فحص التطبيق الحالي. تاريخ الفحص: 23 سبتمبر 2026.

هذه الوثيقة تخص مرحلة المقترح. نُفذت مساحة العمل في التطبيق لاحقًا؛ راجع [تقرير التنفيذ](../../docs/design/TENANT_WORKSPACE_IMPLEMENTATION_2026-09-24.md) و[مراجعة الأمان والتحقق](../../docs/audits/TENANT_WORKSPACE_SECURITY_REVIEW_2026-09-24.md).

## الروابط المحلية

- الموك أب: http://127.0.0.1:4329/
- التقرير المقروء: http://127.0.0.1:4329/report.html
- التطبيق الفعلي بتيننت الاختبار: http://127.0.0.1:3017/
- حساب التيننت التجريبي: `ux-merchant@example.test`
- بيانات الدخول المحلية محفوظة في `.tmp/tenant-ux/test-account.json` المتجاهل من Git.

بيانات الموك أب مستقلة عن بيانات تيننت التطبيق. الأسماء والطلبات والمحادثات توضيحية. الحساب أعلاه مخصص لقاعدة الاختبار المستقلة، وليس حسابًا في الإنتاج.

## تشغيل الموك أب

من جذر المشروع:

```powershell
node prototypes/tenant-dashboard/serve.mjs
```

الخادم يستمع على loopback فقط، والمنفذ الافتراضي 4329. لا يحتاج تثبيت حزم إضافية أو مفاتيح مزودين. يدعم تغيير المنفذ بمتغير `PORT`.

## إعادة تشغيل التطبيق التجريبي الموجود

قاعدة الاختبار في `.tmp/tenant-ux/mysql-preserve-case` وبيئتها الخاصة في `.tmp/tenant-ux/local.env`، داخل مسار متجاهل من Git. لا تعد تشغيل سكربت التهيئة أو البذر على قاعدة موجودة؛ هذان السكربتان لإنشاء بيئة جديدة فقط. أبقِ الخوادم الحالية إن كانت تعمل.

في نافذة PowerShell أولى، إذا توقف MySQL التجريبي:

```powershell
$auditDbDir = Join-Path (Get-Location) '.tmp\tenant-ux\mysql-preserve-case'
& 'C:\Program Files\MySQL\MySQL Server 8.0\bin\mysqld.exe' --no-defaults --lower-case-table-names=2 '--basedir=C:\Program Files\MySQL\MySQL Server 8.0' "--datadir=$auditDbDir" --port=3317 --bind-address=127.0.0.1 --mysqlx=0 --console
```

ثم في نافذة ثانية:

```powershell
$env:SARI_ENV_FILE = Join-Path (Get-Location) '.tmp\tenant-ux\local.env'
node --env-file=.tmp/tenant-ux/local.env --require ./scratch/tenant-ux-local-guard.cjs --import tsx server/_core/index.ts
```

قاعدة `sari_ux_test` معزولة على 3317. يحظر المشغل الاتصالات الخارجية، ويوقف إعداد الاختبار العمال الدوريين. لم يُعدّل ملف `.env` الأصلي. يوجد حارس لصلاحية اسم قاعدة الاختبار في سكربت البذر. لا تنقل ملف البيئة الخاص إلى Git أو الإنتاج.

## ما يمكنك تجربته

- نظرة عامة بمؤشرات مشتقة من الطلبات التوضيحية، وفترة مشتركة مع التحليلات.
- بحث المحادثات يشمل 65 عميلًا، بما في ذلك `ux-customer-065`. افتح المحادثة، أضف ردًا محليًا، وانتقل لملف العميل.
- في الجوال: قائمة محادثات ثم محادثة مستقلة بزر عودة، مع بقاء حقل الرد أعلى شريط التنقل.
- الطلبات: البحث والمرشح وعرض التفاصيل وتحديث الحالة محليًا.
- عروض الأسعار وروابط الدفع: إنشاء مسودات محلية؛ لا تنشئ روابط تحصيل فعلية.
- الكتالوج: منتجات وخدمات وحجوزات توضيحية؛ إضافة وتعديل سجل محلي. سجلات سلة تُعرض مع توضيح مصدرها دون تحرير بيانات المصدر.
- العملاء: البحث وملف موحد وملاحظات داخلية وحفظ محلي.
- المساعد: المعرفة والسلوك والدوام والتجربة والتشغيل. الرد في ساحة التجربة محاكاة حتمية مع مصدر ظاهر، وليس استدعاء نموذج ذكاء اصطناعي.
- التسويق: إنشاء أو تعديل حملة عبر الجمهور ثم الرسالة ثم المراجعة. حفظ مسودة أو جدولة توضيحية دون إرسال.
- التحليلات: تغيير الفترة، توليد CSV ومعاينته ثم تنزيله. الملف يطابق سجلات الفترة.
- الإعدادات: هوية المتجر والتفضيلات المحلية، ومعاينة تنظيم التكاملات والأدوار والاستخدام.
- «جميع الأدوات»: خريطة لكل ملفات الصفحات الـ102، مع المسارات الحالية ومقترح التحسين ومكانها في التنظيم الجديد. الأدوات المتخصصة موثقة هنا وليست كلها شاشات تنفيذ كاملة.
- البحث العام من رأس الصفحة أو `Ctrl+K`، وإغلاق النوافذ بـ `Esc` مع إعادة التركيز.
- زر «جرّب الحالات»: بيانات، فراغ، تحميل مؤقت، خطأ مع إعادة محاولة، وإعادة ضبط بيانات النموذج بعد تأكيد.

الحفظ عبر localStorage بالمفتاح `sari-tenant-concept-v1`. لا يغادر أي من مدخلات الموك أب المتصفح. سياسة CSP تمنع اتصالات الشبكة من الصفحة.

## حدود التسليم

التقرير يقيّم لقطة المشروع المشار إليها بمرجع Git في بدايته؛ حدثت تغييرات متزامنة في المستودع أثناء إعداد الموك أب. لا ينسب التقرير لتلك التغييرات نتيجة فحص جديدة. لم تُعدّل ملفات التطبيق الإنتاجية في هذا العمل.

التصميم مقترح قابل للمراجعة، وليس إثباتًا أن التطبيق خالٍ من العيوب. يلزم تنفيذ الإصلاحات وربط الخادم والتحقق من الصلاحيات والمزودين قبل النشر. الخط Expo Arabic مستخدم كأصل عرض تجريبي موجود في المشروع؛ راجع `site/assets/FONT-SOURCE.json` واستبدله بخط مرخّص للإنتاج أو امتلك الترخيص المناسب قبل نقل الأصول إلى منتج منشور.
